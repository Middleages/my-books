## 상태 계약 보완

05는 식품군 필터가 원래 기록을 지우지 않고 시각 강조만 바꾼다. ‘제시함’과 ‘섭취를 확인함’ 모드의 관계는 포함 관계다. 섭취 여부 모름은 별도 ?로 남기고, 식품군 칸이 비어 있어도 영양소 부족으로 판정하지 않는다. 가상 일주일은 전체 식사를 빠짐없이 기록한 자료가 아니라고 명시한다. 식품 이름은 사례 식별용이며 사진이나 실제 조리 형태·한입 크기를 그리지 않는다. 철의 역할은 짧은 별도 설명으로 두고 식품군 색깔로 흡수량을 예측하지 않는다.

06은 재료/섭취 사실/시각/관찰/확진 상태를 따로 보존한다. 같은 시간순 배열이 원인 확정을 뜻하지 않는다는 끊긴 경계를 넣는다. 고정 사례의 정보가 늘어도 모델의 diagnosis와rechallengePlan은 항상null이다. 상호작용은 기록 단계 보기/초기화만 제공하며 원인 음식 투표·증상 체크 진단·새로운 음식을 먹여 확인하는 버튼은 없다. 응급 우려 시 즉시119 등 도움 요청이라는 고정 경계는 접힌 상세 설명 안에 숨기지 않는다.
