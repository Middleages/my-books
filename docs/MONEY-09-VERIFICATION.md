## 모델과 출처

본문 MDX / React·TypeScript UI / 독립 `risk.mjs` 및 선언 파일. 첫 실험은 100만원 집중·분산, 둘째는 1,000만원의 같은 출발 자금에서 보험 유무 비교다. 서로 다른 실험의 금액을 직접 비교하지 않는다.

공식 SEC Investor.gov 분산 교육, CFPB 비상자금, NAIC 보험 작동 원리를 확인했다. 본문에 URL·확인일·외국 제도 적용 제외를 기록했다. 가상 충격이며 확률이나 전망이 아니다. 보험료·한도는 독립 교육 입력이지 실제 견적이 아니다. 지연 지급 대상 금액은 도착 현금·자산으로 계산하지 않는다. 매각은 이동, 실제 지출만 자산 차감이다. 미충당 지출은 별도 표시하며 남은 자산을 순자산으로 부르지 않는다.
