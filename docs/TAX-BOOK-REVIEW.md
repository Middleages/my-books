## 실제 제도와 교육용 모델의 경계

- 모든 계산 금액은 가상 단위다. 소수는 계산에 유지하고 표시에서만 반올림한다. 법정 단수 처리를 재현하지 않는다.
- 실제 한국 세율표·공제한도·간이세액표·신고기한·보험료율을 코드에 넣지 않는다. 기본 가상 누진 구간은0–100에10%,100–300에20%,300초과30%다.
- 세액공제는 산출세액까지만 쓰는 비환급 모형이며 초과분 이월을 생략한다. 소득공제도 과세 바탕0까지다. 현실의 모든 공제 제도를 일반화하지 않는다.
- VAT는 첫 단계 공제매입0, 후속 증빙·공제요건 충족, 마지막 영세율 또는 면세의 단순 비교다. 간이과세·의제매입·공통매입 안분·가산세는 생략한다.
- 계좌의 자료 확인✓는 적격·비과세 확정이 아니다. 미확인은 실패나0과 구분한다. 연금의 과거 예시와 ISA 법령의 확인 범위를 현재 개인에게 통째로 옮기지 않는다.
- 증여/상속의 단순 합산은 실제 과세대상·공제·기간·상속인별 배분을 재현하지 않는다. 평가 조건이 미확인이면 수치 대신 보류한다.
- 시간표는 Y년의 세금만 추적하며 Y+1년의 새 소득과 새 원천징수를 생략한다. 가상 정산월은 실제 법정기한 또는 지급 보장이 아니다.
- 실제 개인정보·계좌·소득 입력, 신고·납부·외부 서비스 전송은 없다.

## 공식 근거 확인
