## 1. 목적: 집값 맞히기보다 주거 선택의 구조 읽기

**사거나 빌릴 때 비용·대출·위험은 어떻게 달라지나?**

비전공 성인이 집을 소유하는 것과 거주할 권리를 얻는 것, 당장 내는 현금과 되돌아올 자산, 예정된 돈과 실제 사용할 돈을 구분하도록 한다. 월세·보증부월세·전세·매수를 같은 기간과 생활 조건에서 비교하고, 계산에 없는 권리·시간·입지·이동 가능성까지 확인하는 책이다. 어느 한 형태를 성인의 정상 경로나 모두의 정답으로 제시하지 않는다.

읽은 뒤 할 수 있어야 할 일:

1. 주거 계약에서 누구에게 돈을 내고 무엇을 얻으며 누가 누구에게 돌려줘야 하는지 그린다.
2. 보증금·매매대금·대출 원금·이자·수수료·유지비를 자산, 부채, 비용, 현금흐름으로 나눈다.
3. 대출의 담보 기준, 소득 기준, 가계의 실제 월 여력과 잔금일 현금을 별도로 읽는다.
4. 같은 시작자금·거주기간·주거서비스를 전제로 비교하고, 종점의 집·보증금·남은 빚을 빠뜨리지 않는다.
5. 반환 지연·가격 하락·수리비·소득 감소·이사 시차가 서로 다른 위험임을 설명한다.
6. 계약·등기·건축물 자료·보증 약관·대출 설명·통계에서 확인된 사실과 아직 모르는 것을 구분한다.

제외: 특정 지역·단지·매물·대출·보증상품 추천, 적정 집값·미래 가격·매수 타이밍 예측, 개인별 승인/안전/법적 유효성 판정, 경매 입찰·권리분석 실무 자격 대체, 청약 당첨/정비사업 투자, 세금·공제 계산기, 실매물 수집·개인 계좌/주소/소득/등기·계약서 업로드·신청·외부 저장. 공공임대·주거급여는 선택지가 민간 임대와 매수만이 아님을 짧게 안내하되 자격 계산기는 별도 범위다.

### 4.2 공통 표현 규칙

돈의 이동은 **실선·원형 표식**, 거주/반환/소유의 권리는 **점선·문서/열쇠 표식**, 부채는 **갚을 방향의 화살표와 빗금**, 미확인은 **끊긴 선·물음표**로 구분한다. 실제 돈 이동과 장부의 자산 분류 변경을 같은 애니메이션으로 그리지 않는다. 선 굵기·마커 속도·집 면적은 금액에 비례하지 않으면 그렇게 적는다. 금액 비교는 동일 눈금의 막대·축·정확한 표로 맡긴다.

보증금은 세입자의 별도 금고에 그대로 보관된 현금처럼 그리지 않는다. 세입자의 현금은 임대인에게 이동하고, 세입자 쪽에 남는 것은 반환청구권이다. 매수의 집 모양 안에 대출채권자의 소유 지분이 있는 것처럼 표시하지 않는다. 담보권과 소유권은 다른 선이다. ‘집값−대출’은 가계의 경제적 몫이지 법률상 지분 분할이 아니다.

## 5. 장별 설명 장면·조작·반례

모든 장의 흐름은 **짧은 질문과 초기 그림 → 관찰 → 예측 → 한 조건 조작 → 이유·실제 확인 질문 → 이유 있는 확인 문제·출처**다. 각 장은 적어도 한 개의 주 장면을 본문 중간에 붙인다. 장면 수·3D 수를 목표로 삼지 않으며 입력 폼+결과 카드로 끝내지 않는다.

### A · 01 집에 사는 것과 집을 소유하는 것

- 학습 목표: 거주서비스, 소유권, 보증금 반환청구권, 대출채무를 같은 권리로 혼동하지 않는다.
- 첫 장면: 같은 집 실루엣 왼쪽에 민지, 오른쪽에 임대인/매도인, 아래에 은행을 둔다. 임대·매수 전환 시 **집을 사용하는 선은 남고 소유·반환·상환의 선이 바뀐다**. 역할 모양과 라벨을 서로 다르게 한다.
- 과정: 계약 전 → 돈 지급/권리 교환 → 입주 후 장부. 전세 보증금 1억4,000만원의 지급은 현금 감소와 반환청구권 증가, 2,000만원 차입은 현금과 부채 증가로 각각 관찰한다. 매수는 2억원 집과 8,000만원 부채를 별도 층에 놓는다.
- 조작: 월세/전세/매수, 부대비용 0/기본, 단계·초기화. 처음부터 여러 금액 입력을 펼치지 않는다.
- 불변량: 비용·평가변동 없는 대출/자산교환은 순자산 보존. 순자산=현금+보증금 장부가치+주택 평가액−부채. 같은 자산을 현금과 반환청구권에 동시에 넣지 않는다.
- 반례: 현금이 적어져도 그만큼 소비한 것은 아니다. 소유권이 있어도 사용할 현금이 많다는 뜻은 아니다. 보증금 장부가치는 회수 보장이 아니다.
- 모바일/정적: 민지→계약 상대→은행의 세로 경로로 바꾸고 화살표 방향도 바꾼다. 세 방식의 권리 범례와 전후 장부 표를 항상 제공한다.

### A · 02 월세와 보증금의 두 가격

- 질문: 매월 빠지는 돈, 묶여 있는 돈, 빌린 돈의 대가는 각각 얼마인가?
- 첫 장면: 같은 기간의 월세 흐름 아래에 보증금 ‘지급→묶인 반환청구권→반환’ 띠를 놓는다. 비용 띠와 자산 띠를 다른 행으로 분리한다.
- 가상 비교: 보증금 2,000만원/월세 70만원과 보증금 6,000만원/월세 50만원. 추가 보증금 4,000만원으로 월 20만원이 줄어드는 두 제안의 단순 연 환산율은 `20만원×12÷4,000만원=6%`. **이 수치는 두 제안의 비교 비율이지 법정 전월세전환율, 투자 수익률, 안전성 지표가 아니다.**
- 조작: 두 제안·추가 보증금의 자기자금/차입 구성·가상 차입금리·기간. 출발자금은 유지하고 자기자금 부족이면 실행 가능으로 표시하지 않는다.
- 모델: 월 임차 관련 현금=월세+보증금 대출이자+해당 월 비용; 보증금 원금은 별도. 단순 기회비용 설명은 자기자금 보증금에만 가상 대체수익률을 적용하고 차입 원금에 같은 항목을 다시 더하지 않는다. 09의 완전한 비교에서는 이 근사를 합산하지 않는다.
- 반례: 추가 차입금리가 비교 비율보다 높거나 반환 시차가 길면 월세 감소만으로 유리함을 확정할 수 없다. 보증금 차이0이면 비율은 정의 불가. 역방향 제안도 음수·방향을 숨기지 않는다.
- 모바일/정적: 기간별 지출을 세로 행으로, 보증금 원금을 별도 고정 행으로 표시한다. 차이와 비율 산식은 라벨과 표로 읽힌다.

### B · 03 계약부터 입주까지의 권리 지도

- 학습 목표: 계약 체결, 임대 권한 확인, 주택 인도, 전입신고, 확정일자, 신고·등기 관련 절차가 같은 사건이 아님을 설명한다.
- 장면: 자체 가상 계약서의 목적물/당사자/금액/날짜에서 가상 등기사항·건축물 자료·당사자 권한으로 선을 연결한다. 시간축 아래에 **계약의 약속 / 대항요건 / 우선변제 관련 요건 / 실제 확인 자료**를 별도 행으로 둔다. 체크 수를 안전 점수로 환산하지 않는다.
- 조작: 일치하는 사례/주소 불일치/권한 미확인/추가 권리 발생의 고정 시나리오, 문서 근거 공개, 단계. 날짜를 움직이는 모델은 필요한 사실을 다 준 교육 예시만 다룬다.
- 정확성: 주택임대차보호법의 적용 범위, 대항요건과 확정일자의 차이를 법령·생활법령으로 재확인한다. ‘서명/확정일자만 있으면 안전’, ‘등기부에 없으니 모든 채무가 없음’, ‘집주인처럼 보이면 임대 권한 있음’으로 결론 내리지 않는다. 전입신고와 임대차 신고를 구별한다.
- 반례/검증: 문서 한 장 누락, 동일 날짜의 순서 불명, 신탁·대리·미등기·다가구 등 복잡한 경우는 **추가 공식 확인 필요**로 남긴다. 체크가 완료되어도 법률상 적격/안전 자동 판정 금지. 계약 전/잔금 전 재확인의 이유를 권리변동으로 보여 준다.
- 모바일/정적: 문서 축약 그림을 위, 확인 대상과 이유를 아래에 두고 실제 연결선을 남긴다. 전체 근거표와 날짜별 정적 프레임을 제공한다.

### B · 04 보증금을 돌려받는 조건

- 장면1: 집 처분으로 생긴 **가상 회수 재원**의 높이가 내려가면, 먼저 배분하는 채권 구역 뒤에 세입자의 반환금이 남는 모습을 보여 준다. 이는 **순서가 외부에서 주어진 단순 배분 연습**이며 한국 법정 배당 순위를 계산하지 않는다.
- 고정 예시: 재원 1억6,000만원, 먼저 지급할 가상 채권 5,000만원, 세입자 청구 1억4,000만원이면 먼저5,000+세입자1억1,000+남음0, 미회수3,000만원. `회수=min(청구,max(0,재원−먼저 지급액))`. 집값·등기 채권최고액·실제 채권액·경매 배당재원은 다른 값이다.
- 장면2: 은행을 향하는 **전세자금대출 보증**과 세입자 반환을 다루는 **보증금 반환보증**의 두 경로를 나란히 놓는다. 보증가입·사고요건·이행청구·심사·실제 지급을 따로 표시한다.
- 조작: 재원·선행 지급액·반환 예정/실제 날짜, 무보증/가상 적격 지급/조건 미확인. 실제 HUG/HF 상품 심사·법정 배당 알고리즘과 상품 간 순위를 만들지 않는다.
- 불변량: 배분 합≤재원, 세입자 회수≤청구. 임대인 반환과 보증 이행으로 같은 금액을 두 번 회수하지 않는다. 기관 지급으로 대위되는 권리는 회수 구조가 달라지는 것이며 세입자에게 무료 추가자산을 생성하지 않는다.
- 반례: 집값 대비 보증금이 낮아도 권리·시점·다른 채권이 미확인이면 안전을 단정할 수 없다. 가입 가능 조회·가입완료·지급 가능·오늘 현금은 각각 다르다. 지연을 확정손실로, 미회수를 영구손실로 자동 분류하지 않는다.
- 모바일/정적: 재원·배분은 세로 비례 띠, 보증 관계는 별도 세로 경로. 재원 표와 청구/결정/도착의 같은 날짜 표를 제공한다. 공식 이행 안내의 ‘이사·전출 가능 시점’은 개별 확인 대상이며 앱이 전출을 권하지 않는다.

### C · 05 집을 사는 날 필요한 돈

- 장면: 2억원 매매대금의 계약금2,000·중도금4,000·잔금1억4,000만원을 하나의 가격 띠에서 분할한다. 대출8,000만원은 별도 은행 경로로 잔금에 합류하며, 추가비용500만원은 가격 띠 밖에서 빠져나간다.
- 고정 일정: 경과일0 계약금, 30 중도금, 60 잔금/대출 실행/가상 부대비용. 이 날짜·비율은 법정·표준 계약 관행이 아니라 자체 사례다. 기본 시작현금1억5,000만원이면 종료현금2,500만원, 집2억원, 빚8,000만원, 순자산1억4,500만원이다.
- 조작: 대출 실행60/61일, 시작자금, 부대비용, 단계/정지. 61일 실행은 총합으로 마련되어도 60일 납기를 못 맞출 수 있음을 보인다. 대출 상담/한도 조회를 실행된 돈으로 계산하지 않는다.
- 불변량: 계약금+중도금+잔금=가격; 자기자금+실행대출=실제 지급가격+비용+남은현금. 계약금 등을 집값에 다시 더하지 않는다. 납기 전 입금만 사용한다.
- 반례: 가격만 준비하면 부대비용·입주 준비·예비현금이 빠진다. 비용0, 대출0, 부족1원, 같은 날 입출금 순서 불명도 검증한다. 계약 해제/위약금·중개보수 법정률을 임의 구현하지 않는다.
- 모바일/정적: 한 날짜의 은행/민지/매도인 경로를 세로로 연결하고 납기선과 당시 사용가능액을 붙인다. 날짜별 원장과 당시 부족 기록을 보존한다.

### C · 06 빌릴 수 있는 돈과 감당할 돈

- 장면: 집 담보평가액과 대출의 **한 시점 비율**, 연소득과 심사용 연간 원리금의 **한 해 비율**, 월 실수령·생활비·납입의 **월 현금 경계**를 세 개의 다른 눈금/단위로 놓는다. 전부 같은 단위의 안전등급 카드로 만들지 않는다.
- 모델: 원리용 LTV=`대출액÷담보평가액`; 단순 연 원리금/소득 비율=`가정한 심사용 연 원리금 합÷가정 연소득`. 실제 DSR의 인정소득·산정만기·포함 채무·예외는 별도 규정임을 표시한다. 실수령 월소득을 규제 DSR 분모로 사용하지 않는다.
- 조작: 담보평가액만 낮추기, 다른 빚 추가, 생활비·소득 감소, 심사용 가상 금리/실제 납입 금리 분리. 심사 금리에 스트레스를 더해도 실제 청구 이자가 자동 상승하지 않음을 같은 장면에서 보여 준다.
- 가상 한도를 쓸 때는 ‘교육용 기관 A의 규칙, 한국 현행 기준 아님’으로 표시한다. 결과는 ‘이 가상 제약에서 막힌 이유’이며 은행 승인·이용가능 한도가 아니다. LTV/DSR/상품·총량 제한을 단순 min 식으로 현실 승인액에 합치지 않는다.
- 반례/검증: 소득0·평가액0이면 해당 비율 정의 불가; 높은 소득에도 현금 납기 부족, 낮은 LTV에도 생활비 부족. 예정 납입을 할 수 없는데 부채가 실제로 줄었다고 표시하지 않는다.
- 모바일/정적: 시점·연간·월간 세 척도를 세로 분리하고 분자/분모 라벨을 유지한다. 한국 현행 수치를 적용하려면 최종 시행 원문과 예외/경과규정까지 새로 확인해야 하며, 이 계획은 현행 한도표를 확정하지 않는다.

### D · 07 금리와 상환의 시간표

- 장면: 같은 8,000만원에서 고정/가상 변동 경로의 **남은 원금 선·납입의 원금/이자 비례 띠·금리 재산정 경계**를 같은 시간축에 맞춘다. 24개월 관찰 끝에도 240개월 대출의 원금이 남는 부분을 잘라 숨기지 않는다.
- 기본: 1권의 원리금균등 원리 사용. 변동 사례는 13개월부터 명목연율4→7%, 12개월 말 잔액을 남은228개월로 재계산하는 자체 계약이다. 실제 변동·혼합·주기형 상품의 공통 규칙이 아니다.
- 조작: 고정/가상 재산정, 상환기간, 24개월 관찰/전체 예정, 중도상환0/정해진 가상액. 중도상환 수수료는 별도 가정이고 ‘항상 무료’로 처리하지 않는다. 만기일시상환은 비교 반례만 제공한다.
- 불변량: 원금 감소 합+남은 원금=시작 원금, 납입 합=원금+이자+명시 비용. 금리 재산정은 원금을 새로 빌린 것이 아니다. 0금리·1개월·재산정 직전/직후·완납·반복재생·마지막 회차를 검사한다.
- 반례: 긴 만기는 월 납입을 낮출 수 있지만 총이자와 만기 위험을 없애지 않는다. 관찰 끝 순자산이 같아도 중간 현금 경로는 다를 수 있다. 대환·만기 연장은 자동 성공으로 모델링하지 않는다.
- 모바일/정적: 차트를 접지 않고 의미별 세로 정렬, 12/13개월 전후를 동시에 읽는 고정 비교, 전체 상환표. 실제 입금이 아니라 ‘계획대로 납입한 예정 경로’임을 명시한다.

### D · 08 살면서 계속 드는 비용

- 장면: 집 단면에서 전용공간·공용시설·사용서비스로 가지를 나누고 **누가 먼저 납부 / 누가 최종 부담 / 반환 또는 정산 여부**의 경로를 연결한다. 관리비 고지 합계 하나를 전부 임차인의 소비로 칠하지 않는다.
- 자체 사례: 월 관리서비스15만원, 가상 장기수선충당금2만원, 임차인이 대신 낸 금액의 반환청구권을 별도 추적. 이 구조의 실제 적용은 주택 유형·공동주택관리법·계약과 확인 자료에 따른다. 수선유지비와 장기수선충당금을 같은 항목으로 합치지 않는다.
- 다른 장면: 가구가 자기 예비통장에 매월10만원을 적립하다 12개월째120만원 수리비를 내는 시간표. 예비통장 이체 때와 실제 수리 때 두 번 비용 처리하지 않는다. 공동주택에 외부 납부한 충당금을 자기 현금통장처럼 다루지 않는다.
- 조작: 정기/일시 수리, 발생월, 부담주체 확인/미확인, 예비자금0/기본. 실제 수리 책임·통상손모·원상복구 분쟁을 자동 판정하지 않는다.
- 반례/검증: 연평균 비용은 낮지만 수리월 현금이 부족한 사례, 미확인 부담주체, 환급 미도착. 주택 가격 경로가 노후화를 반영했다면 별도 ‘감가상각 비용’을 다시 얹지 않는다. 수리비를 냈다고 집 가치가 같은 금액 자동 상승하지 않는다.
- 모바일/정적: 단면 역할은 작은 SVG+외부 HTML 라벨, 비용 주체별 세로 연결, 납부/청구권/실제정산 표. 세금은 5권으로 연결하고 여기서는 임의 실제세액 계산을 하지 않는다.

### E · 09 같은 조건에서 빌리기와 사기

- 장면: 공통1억5,000만원에서 월세/전세/매수 세 갈래로 나가는 돈과 권리를 **동일 눈금의 자산·부채·누적비용·현금** 네 행에 둔다. 종점에는 임대 보증금 반환과 주택 처분을 양쪽 모두 수행한 현금 회수 관문이 있다. ‘주택 평가액’과 ‘처분 후 가용현금’을 전환해도 비교 시점은 같다.
- 조작: 공통 관찰기간, 가격 유지/가상 하락/상승, 가상 잔액수익률0/3%, 거래비용0/기본. 한 번에 한 조건만 바꾼 비교를 기본으로 하고 차이를 설명한 뒤 상세 설정을 연다. 가격 경로는 전망·확률이 아닌 조건이다.
- 계산 계약은 §6을 따른다. 월세와 원리금 전체를 비용끼리 바로 비교하지 않는다. 매수의 집값 상승과 임차인의 남은 유동자금 운용을 한쪽만 넣지 않는다. 반환보증금·남은 대출·처분비를 양쪽 종점에 포함한다.
- 출력은 필요한 시작현금, 월별 납입, 누적 비회수성 지출, 종점 자산/빚, 동일 기준의 순현재비용과 가정 목록이다. **통합점수·추천·매수 적기·안전 판정 없음.** 계산이 가정상 낮은 비용을 보이면 ‘이 조건·기간·범위에서 낮다’로만 읽는다.
- 반례/검증: 기간0(별도 즉시 정산), 수익률0, 가격변화0, 거래비용0, 동일 경로, 가격·보증금0, 비용보다 낮은 매각대금, 중간 현금 부족. 손익분기점이 없거나 여러 교차가 있으면 억지로 한 날짜를 만들지 않는다. 계약 갱신·매각 완료가 미확인이면 조건부 결과다.
- 모바일/정적: 세 경로를 가로로 찌그러뜨리지 않고 동일 눈금의 세로 패널로 재배치한다. 월/종점 고정 비교와 전체 원장으로 같은 이유를 읽는다.

### E · 10 위치·생활과 시장의 숫자

- 첫 장면: 실제 지역명 없는 가상 A/B 집에서 일터·일상 시설로 가는 경로를 그린다. 기호는 위치 관계이고 선 길이는 실제 거리가 아니다. 월 임차 지출 A70/B50만원, 왕복 통근 A40/B100분, 월20일이면 B의 절감20만원과 추가시간20시간을 **돈/시간 두 축**에 놓는다. 시간가치를 독자 대신 정해 합산하지 않는다.
- 조작: 출근일 수·필요 접근조건·이사 가능 시점. 승강기·무장애 접근·돌봄 동선·재택 공간 등은 단순 금전 점수로 상쇄할 수 없는 조건으로 선택한다. 제약으로 남은 후보가0이면0을 보여 준다. 가족 형태의 우열이나 특정 지역 계층화를 만들지 않는다.
- 짧은 두 번째 장면: 가상 매물의 호가, 실제 계약가격, 공시가격/평가액, 지역 가격지수를 **각자 다른 관측 표식**으로 놓는다. 2권 곡선을 복제하지 않고 인허가→착공→준공의 시차 띠로 공급 발표와 당장 입주 가능 물량이 다름을 설명한다. 수요·금리 하나로 결정되는 가격 예측은 하지 않는다.
- 반례: 평균가격 상승이 같은 주택 가격 상승과 같지 않을 수 있다. 지역지수·최고가 한 건이 내 계약의 적정성을 보장하지 않는다. 기준연도·면적·유형·지역·거래일/신고일·해제·수정 여부를 확인한다.
- 검증/정적: 분↔시간·편도/왕복·월근무일 변환, 제약 우선, 관측/가정/전망 라벨. 모바일에는 경로와 비용/시간 막대를 세로로 분리한다. 실제 API·지역 데이터 수집·위치 요청은 없다.

### F · 11 이사와 충격을 견디는 구조

- 장면: 기존 집 반환/매각과 새 집 납기를 **두 개의 계약 시간축과 하나의 현금 통로**에 연결한다. 가진 자산 높이와 오늘 통과할 현금의 경계를 구분한다.
- 가상 이사 예시: 시작현금1,000만원, 옛 보증금1억원 도착예정30일, 새 보증금9,000만원 납기20일. 20일 부족8,000만원은30일 입금 뒤에도 과거 기록으로 남는다. 이를 자동 브리지대출·현금 마이너스로 메우지 않는다. 새 계약 이행 자체가 안 된 경로는 이사 완료로 그리지 않는다.
- 가격·레버리지 보조: 집2억원·빚8,000만원에서 집값이20% 떨어지면 비용·상환 전 경제적 몫1억2,000→8,000만원. 집의20%와 자기 몫의약33.3% 하락을 분모와 함께 비교한다. 빚이 가격보다 커진 사례에서 잔여채무를0으로 자르지 않는다. 이것은 예상 손실률이 아니다.
- 조작: 반환/매각 도착일, 새 납기, 소득 중단, 금리 재산정/수리비의 개별 충격 및 명시적 동시 충격. 충격 빈도·상관을 알 수 없으면 확률을 붙이지 않는다.
- 불변량: 장부상 자산≠미리 쓸 수 있는 현금; 실제 도착액만 사용; 손실·추가비용·추가 외부자금은 원장에 따로 남김; 부족했던 과거는 나중 입금으로 지워지지 않음.
- 정적/모바일: 기존/새 계약과 현금을 같은 세로 날짜 줄에서 읽고 ‘늦게 받음/일부 회수/미확정’을 다른 라벨로 표시한다. 보증금 받기 전 이사·전출의 권리 효과는03·04와 공식 상담 확인으로 되돌린다.

### F · 12 주거 자료 함께 읽기

- 자체 가상 자료3묶음: 보증부월세 계약+관리비 항목, 전세 계약+등기 발췌 모형+보증 설명, 매수 계약+대출 설명+잔금 일정. 실제 문서 로고·개인정보·사실처럼 보이는 서명·고유번호를 복제하지 않는다.
- 장면: 문서 금액/시점/대상에서 주거 관계도와 돈 시간축으로 선을 연결한다. **문서로 확인됨 / 계산에 둔 가정 / 아직 확인 필요**의 세 상태를 선 형태와 텍스트로 구별한다. 확인됐다는 것은 문서에 적혀 있다는 뜻이며 진위·적법·상환·실제 지급까지 보장하지 않는다.
- 조작: 근거 선택·예측·조건 하나 변경·근거 공개. 대출 실행일 미정, 반환보증 범위 누락, 관리비 포함항목 미상 중 하나라도 남으면 임의로 숫자를 채우지 않는다. 추가 자료/질문을 제안하고 결론을 보류한다.
- 종합 목표: 비용 비교가 맞아도 계약 위험·생활 제약을 따로 확인해야 함을 설명한다. 상품 랭킹·선택 자동화·계약 실행은 하지 않는다.
- 검증: 세 사례의 사실/가정/미확인 분류, 같은 항목의 장간 용어·값·시점 일치, 미구현 링크 없음, 전체 읽음/모바일/정적 대안. 결과표만 보지 않고 선과 경계가 실제로 무엇을 설명하는지 직접 캡처를 검토한다.

## 6. 비교 모델의 고정 계약

### 6.1 네 가지 숫자를 섞지 않는다

1. **현금흐름**: 그 날짜 실제 들어오고 나가는 돈. 원금·보증금·수수료 모두 포함될 수 있다.
2. **비회수성 지출**: 이자·월세·서비스·명시 비용 등. 원금 상환·보증금 지급은 원칙적으로 이 항목이 아니다. 손실 확정과 미회수는 구별한다.
3. **순자산**: 같은 시점의 자산 평가액−부채. 자산가격 상승은 현금 유입이 아니다. 원금 상환 직전/직후에는 현금과 부채가 같이 줄어 순자산이 자동 증가하지 않는다.
4. **동일 기준 순현재비용**: 시작·월별·종점 현금의 시점을 맞춘 조건부 비교값. 실제 지출 합·회계 비용·세법상 필요경비가 아니며 별도 명칭을 유지한다.

### 6.2 같은 기간, 양쪽 종점 정산

경로 s, 기간 T개월, 월 할인율 d, 시작 순현금 투입 U, 각 월 납입 O, 종점 순회수 R을 정의한다.

`순현재비용_s = U_s + Σ[O_s,m / (1+d)^m] − R_s,T / (1+d)^T`

- 매수 U=가격−시작대출+취득 부대비용. 월 O=원금상환+이자+해당 월 비회수성 비용. R=가정 처분가격−처분비−그 시점 남은 대출.
- 임차 U=보증금−보증금대출+시작 부대비용. 월 O=월세+대출 원리금+해당 월 비용+보증금 추가 납입−실제 중간 반환. R=종점 실제 반환 가정액−그 시점 남은 보증금대출. 중간 반환과 종점 반환을 중복하지 않는다.
- 대출원금은 현금 납입에 포함되지만 종점 부채 감소와 함께 계산하므로 두 번 비용이 되지 않는다. d=0·가격불변·비용0이면 정상 상환한 원금과 전액 반환되는 보증금은 순비용을 만들지 않는다.
- 할인에는 연 유효 대체수익률 q로부터 `d=(1+q)^(1/12)−1`을 사용한다. 대출의 명목연율/12와 혼용하지 않는다. 명목 금액만 다루고 물가가 반영된 실질 수치와 섞지 않는다.
- 이 방식에서는 묶인 자기자금의 기회비용이 시점/할인에 반영된다. **자기자금×기회비용률을 또 더하거나 임차인의 잔액 투자수익을 또 빼지 않는다.** 가격변화 가정에 포함한 감가와 별도 감가비도 중복하지 않는다.
- 처분 후 순회수가 음수면 음수를 보존하고 추가 상환 필요액을 표시한다. 매각 없이 보유한다고 가정할 때는 평가 순자산만 표시하며 위 처분 비교값과 같은 열에 무표시로 섞지 않는다.

### 6.3 같은 시작자금과 월 배정액의 교차검증

가상 유동자금은 `X0=W−U`, `Xm=X(m−1)×(1+d)+H_m−O_m`로 월말을 계산하고, 종점 정산 후 `Z=X_T+R_T`로 검증한다. 공통 W·H·d·T가 같은 두 경로에서:

`Z_a−Z_b = −(순현재비용_a−순현재비용_b)×(1+d)^T`.

이것은 비교 일관성 테스트이며 이 잔액을 다시 순현재비용에 더하지 않는다. 수익률 q는 가상의 일정한 세후·비용후 수익률 가정이며 실제 투자 상품이 아니다. 월초 수익 반영→월말 배정액→월말 납입→마지막 월 정산으로 순서를 고정한다.

시작 또는 중간 X가 음수여야 계획이 성립하면 **추가자금 없이는 실행 불가한 예정 경로**다. 음수를 자동 차입으로 쓰거나 이자를 붙이지 않는다. 최초 부족시점·필요액을 표시하고 실현된 종점재산 비교를 중단한다. 예정 상환표는 표시할 수 있으나 실제 납입·부채 감소로 주장하지 않는다. 실제 미납·법정 연체·추심 모형은 범위 밖이다. 05·11의 날짜 모델도 입금 전에 미래 돈을 쓰지 않는다.

### 6.4 수치·상태·테스트 불변량

- 계산 금액은 원, 비율은 명시한 단위, 날짜는 경과일 또는 명시 월말. 표시 반올림만 별도로 하고 판정은 원래 값에서 한다.
- 유한값, 음수 불허 항목, 정수 월/일, 0 분모, 입력 범위, 종점1회 처리, 초기화·재실행의 동일성을 검사한다. 유효 범위를 벗어난 값은 조용히 clamp해 정상처럼 표시하지 않는다.
- 모든 그림·표·텍스트·예측 답은 같은 순수 모델의 관찰 프레임을 읽는다. 재생은 계산 결과를 보여 주는 관찰 순서이지 실제 계약 절차를 자동 실행하는 과정이 아니다.
- 상태는 `가정/예정`, `문서 확인`, `실행/도착`, `미확인`, `부족/중단`을 구분한다. 장부상 권리를 현금으로 바꾸는 장면은 실제 도착 또는 명시적 가정이 있을 때만 가능하다.
- 1권 `repayment.mjs`는 원금 상한1억원·고정금리 예정 모델이다. 기본8,000만원에는 맞지만 더 큰 주택대출이나 재산정·부족 처리는 그대로 지원하지 않는다. 읽고 재사용 가능한 부분만 재사용하며, 범위 확장이 필요하면 housing 내부 순수 함수와 일치 테스트를 우선한다. 기존 돈 실험의 입력 상한·오류 계약을 몰래 바꾸지 않는다. 공통 리팩터링이 필요하면 별도 범위를 정한다.

## 12. 이번 계획 문서의 점검 기록

2026-10-20, 위 기준 main에서 분리한 문서 전용 작업 트리에서 수행했다. 앱 구현·테스트 완료 기록이 아니다.

- 두 계획 문서의 상대 링크가 실제 파일로 연결됨을 검사했다. 12개 chapterId의 중복이 없고 `housing`이 현재 카탈로그에 등록되지 않았음을 확인했다.
