기준: 2026-10-20. 구현 후보이며 main 병합·공개 배포 완료 기록이 아니다.

## 범위와 보존

- 계획 문서 PR [20](https://github.com/Middleages/my-books/pull/20)의 검산된 기초 모델을 출발점으로 소개·01 `company-boundary`·02 `double-entry`를 구현했다.
- `accounting`, `categoryId: money`, `volume: 7`. 읽음 ID는 `accounting/company-boundary`, `accounting/double-entry`이며 소개는 분모에 포함하지 않는다.
- 기존 책의 본문·URL·ID·읽음 키는 수정하지 않았다. 공통 표지에 회계만의 장부 그림 분기를 추가했다.
- 01의 세 거래 비교는 독립 기초이며 회수 시 현금+기존 채권=500이다. 02는 M1의 T01–T03 발췌로 현금500→550→650→410, 자산500→550→650→650이다. 아직 M1 전체 결산을 보여 주는 장면이 아니다.
- 그림·띠·분개·정적 단계는 같은 `foundation.mjs` 프레임에서 읽는다. 자산과 청구권의 띠는 동일한 전체 폭650가상단위이며 실제 DOM 길이를 비교하도록 검사한다. 화살표는 관계 방향이며 금액/시간 비율이 아니라는 설명을 붙였다.

## 정확성 확인

계정별 정상 잔액 방향으로 차변/대변을 반영한다. 거래 중복·잘못된 계정/금액·불균형·현금 부족을 확정 전에 거부하고 원래 장부를 변형하지 않는다. 0과 소수 경계, 세 비교 사례, 네 누적 단계, 음수 자본의 대차 관계를 단위 검사한다. 공개 A UI는 음수 잔액 시나리오를 제공하지 않는다. 장부 균형만으로 계정 분류·누락까지 검증된다고 설명하지 않는다.

IFRS 개념체계·IFRS15·IAS16·IAS1·IFRS18 및 한국회계기준원 공식 페이지를 2026-10-20에 확인했다. 실제 제도와 가상 사례를 구분하고 2027-01-01 IFRS18 시행 경계를 적었다. 전문 신고·감사·세무 판단을 수행하지 않는다. 상세 근거는 각 장과 [계획](ACCOUNTING-TEXTBOOK-PLAN.md)의 출처 확인 기록을 따른다.

## 실행 기록

- A 첫 모델/본문 구현 후 전체 단위 검사 **910/910 통과**, TypeScript/Vite 빌드 **327 modules 통과**. 기존 큰 번들 경고는 남아 있으며 경고를 오류 없는 소형 번들로 오해하지 않는다.
- 첫 모델 검사에서 소수0.1의 이진 부동소수 표현을 엄격동등으로 비교한 3개 assertion을 발견했다. 값 반올림으로 계산을 바꾸지 않고 기존 불변식과 같은1e-9 허용차로 검사해 해결했다.
- 로컬 production Chromium 첫 launch는 `socket() failed: Operation not permitted`로 종료했다. 이 실행은 **검사0건·스크린샷0장**이며 브라우저 성공이 아니다. 같은 제한을 우회하지 않고 PR의 기존 Actions 검증 환경에서 확인한다.
- 브라우저 verifier는1440/390/320폭의 모든 구현 경로·3거래×3금액×3프레임·실제 띠 길이·분개 쌍·키보드·재생/정지·설정 변경·초기화·정적 단계·route 타이머 정리·읽음/미확인 ID 보존을 검사한다. 768/900폭 레이아웃 및 일반 움직임/reduced-motion도 포함한다.
- 콘솔 오류의 원본 URL·메시지·행/열과 실패 응답 URL/status·requestfailed를 보존한다. 알려진 게시 base에서 **실제로 관찰된 정확한 host-root favicon404**만 별도 기록한다. URL 없는 오류·앱 경로·다른 호스트/상태·텍스트만 favicon인 오류는 실패다. 공개 검사는 같은 dist 자산의 전체 바이트 길이와 SHA256를 비교한 뒤 실행한다.
- accounting suite 등록은 공통 선택기 변경이므로 이 첫 PR은 정책에 따라 사용 가능한 전체 suite가 선택된다. 이후 회계 전용 장 변경은 accounting+book-volumes가 기본이며 모든 배치에서 전체 단위/빌드를 유지한다. 선택하지 않은 책을 브라우저 통과로 기록하지 않는다.
