## 1. 목적: 좋아 보이는 숫자를 어디까지 믿어도 될까?

비전공 성인이 생활 금융·보험·투자 설명·경제 뉴스의 숫자를 읽고 **무엇을 요약했는지, 분모와 조건이 무엇인지, 얼마나 모르는지, 잘못됐을 때 무엇을 감당해야 하는지**를 설명하게 한다. 공식 암기나 수익률 예측보다 판단의 질문을 익히는 책이다.

읽은 뒤 할 수 있어야 할 일:

1. 평균·중앙값·분포·흩어짐이 각각 답하는 질문을 구분하고 요약값 뒤의 큰 손실을 찾는다.
2. 확률 가정과 관측 빈도를 구분하고, 드문 사건을 보지 못한 기록을 불가능의 증거로 읽지 않는다.
3. 조건부 확률의 분모를 자연빈도, 즉 같은 전체에서 나온 건수로 다시 세고 기저율을 확인한다.
4. 표본 변동·선택 편향·모형 불확실성을 나누며 평균의 신뢰구간과 다음 한 번의 예측구간을 구별한다.
5. 함께 움직임과 원인, 개별 위험과 공동 충격, 남아 있는 자료와 처음 전체를 분리한다.
6. 많은 시도 중 최고 성과와 재현 가능한 근거를 구분하고, 선택에 쓰지 않은 자료의 경계를 지킨다.
7. 평균이 좋아도 중간에 필요한 돈을 마련하지 못할 수 있음을 설명하고 조건·한계가 붙은 결론을 쓴다.

**제외:** 특정 종목·상품·매매 시점·적정 자산 비중·보험 가입·은퇴 인출률 추천, 실제 시장 수익률/손실 확률 예측, 개인 신용·적격성·안전성 점수, 도박·베팅·켈리 비중 최적화, 수학적 증명 중심 통계 사전, 파생상품 가격 모형, 실제 계좌·소득·건강·계약 업로드·시세 API·외부 저장. 의사결정은 가상 조건의 비교이며 금융 거래를 실행하지 않는다.

## 4. 공통 사례와 불확실성의 언어

### 4.1 하나의 만능 대시보드 대신 네 종류의 주장

가상의 성인 독자가 다음 설명을 접한다고 놓는다. 가족 형태·직업·자산 규모·투자 여부를 독자의 정답으로 가정하지 않는다.

- “이 집단의 평균 지출은 20만원입니다.”: 01·05에서 같은 관측 단위와 빠진 대상을 확인한다.
- “이 사건은 드물고 알림은 잘 잡습니다.”: 02·03·04·06에서 손실·빈도·분모·불확실성을 나눈다.
- “두 대상은 다르게 움직이고 남은 상품의 성과가 좋습니다.”: 07·08·09·10에서 관계·선택 절차를 확인한다.
- “평균이 좋으니 필요한 돈을 계속 낼 수 있습니다.”: 11·12에서 시간·중단·조건부 결론을 따진다.

장끼리 비교할 만한 데이터는 공유하되, 한 집단의 지출 자료를 사건 발생률·시장 수익률·시계열로 바꾸어 재사용하지 않는다. 01의 10가구는 10개월이 아니며 08의 100가지 확률 칸은 실제 100번의 경험이 아니다. 각 사례에 `caseId`, 대상, 한 관측의 단위, 기간, 자료 생성 방식, 알려진 값/추정값/모르는 값을 붙인다.

### 4.2 화면 가까이에 붙일 다섯 라벨

| 라벨 | 의미 | 금지할 바꿔 읽기 |
| --- | --- | --- |
| 자체 가상 관측 | 사람이 정한 유한한 기록을 사례 안의 관측으로 사용 | 실제 조사·실제 운용 성과 |
| 모형 가정 | 확률·독립성·정규성·비용·거래 시점 등을 정함 | 현실에서 검증된 사실 |
| 모형의 정확한 계산 | 주어진 가정으로 전수 열거·산식 계산 | 현실의 정확한 미래 확률 |
| 표본/시뮬레이션 결과 | seed·표본번호·반복 수로 재현한 유한 결과 | 이론값과 반드시 일치하거나 다음 결과를 보장 |
| 추정/민감도·미확인 | 방법/조건부 범위 또는 아직 근거 없는 값 | 모든 범위가 95% 신뢰구간·같은 확률의 시나리오 |

“확실하다/불확실하다” 두 색으로 끝내지 않는다. **결과의 우연한 변동, 유한 표본 때문에 모르는 모수, 잘못된 모형/선택/측정/시대 변화**를 구분한다. 시뮬레이션 반복을 늘리면 계산 잡음은 줄 수 있지만 잘못된 모형을 고치지는 않는다. 실제 데이터는 기본 범위에 없으며 도입한다면 출처·대상·기간·단위·수정/탈락·수집 시점·가중치·이용 조건을 별도 기록한다.

### 4.3 확률과 그림의 정직성

- 확률은 내부에서 0–1, 금액은 명시한 원 또는 가상 화폐단위로 계산한다. %와 %p, 상대 변화와 절대 차이를 나란히 표시한다. 기준 확률 0이면 상대 증가율은 정의 불가다.
- 건수는 음이 아닌 정수다. 자연빈도 예시는 정수 건수가 나오는 고정 조건부터 시작한다. 일반 비율을 확장해 소수 기대건수가 나오면 **기대건수**라고 표시하며 실제 관측 사람/사건 수로 그리지 않는다.
- 확률 점의 한 칸, 히스토그램 구간, 시간축의 한 단계가 무엇인지 표시한다. 히스토그램은 기본 **같은 구간 폭**·건수 또는 비율 축을 사용한다. 다른 구간 폭을 쓰면 면적과 밀도 단위를 설명하고 높이를 확률로 읽게 하지 않는다.
- 두 분포는 공통 축과 같은 구간 경계를 사용한다. 0·음수·큰 꼬리·겹침을 잘라 숨기지 않는다. 보기 확대는 원래 범위와 생략 건수·정확한 표를 함께 남긴다. 점도표에서 겹친 점을 지우지 않는다.
- 0.01%를 0.0%로 반올림한 뒤 “없음”으로 판정하지 않는다. 작은 확률은 충분한 자리수·분수/건수·‘표시 정밀도보다 작음’ 중 적절한 대안으로 보인다.
- 조건부 확률은 **지금 분모로 삼는 집단의 경계와 총건수**를 계속 표시한다. 전체 10,000건과 알림 288건을 같은 100%처럼 겹쳐 놓지 않는다.
- 표본추출은 회전 바퀴·주사위·룰렛·당첨음이 아니라 선택된 관측과 누적 분포가 보이는 단계 관찰이다. 자동 재생하지 않는다. “좋은 결과 나올 때까지 다시”를 보상하지 않는다.

## 5. 장별 관계·장면·조작·검증 설계

모든 장은 **학습 질문/목표 → 첫 그림과 짧은 설명 → 예측 → 조건 하나 조작 → 결과의 이유/현실 확인 질문 → 이유 있는 확인 문제/출처**로 구성한다. 아래 불변량·반례는 모델 테스트와 장의 설명을 함께 설계하기 위한 것이다. 모든 장의 통계·그림·표·해설·예측 답은 하나의 모델 결과/관찰 프레임을 읽는다.

### A · 01 평균 뒤에 있는 사람들

- **눈으로 발견할 관계:** 전체 합계를 같은 수로 나눈 위치와 사람들을 순서대로 세어 가운데를 고른 위치가 다르다. 같은 평균20이어도 중앙과 꼬리가 다르다.
- **초기 사례/시각:** 같은 한 달, 가상 10가구의 예기치 않은 지출을 만원으로 표시한다. 고른 집단 `[12,14,16,18,20,20,22,24,26,28]`, 꼬리 집단 `[10,10,10,10,10,10,10,10,10,110]`. 공통 금액축의 점도표, 평균의 균형점·중앙 두 순위·전체 합계 띠를 연결한다. 모두 합200·평균20, 중앙값20/10이다.
- **과정/조작:** 원래 순서→정렬→가운데/합계 보기; 두 집단 비교, 마지막 큰 값만 변경, 같은 데이터의 구간 폭 변경. 구간 폭을 바꿔도 원래 점·평균·중앙값은 그대로이고 히스토그램 모양만 달라짐을 보인다.
- **모델/불변량:** 순열에 통계 불변, 빈도합=n, 평균×n=합계, 전체 유한집단의 분산은 n으로 나눔. 표준편차는 원래 금액 단위, 분산은 금액 제곱 단위. 표본분산의 n−1은05의 추정 맥락에서 구분한다. 사분위는 정렬 뒤 위치 `(n−1)p` 선형보간 방식으로 고정하고 경계를 기록한다.
- **반례/라벨:** 꼬리 집단의 IQR은0이어도 최대110·표준편차30이다. 중앙값·IQR도 꼬리 위험을 모두 말하지 않는다. “평균인 사람이 반드시 존재”, “중앙값이 항상 더 좋은 지표”, “평균±표준편차가 손실 상한”은 모두 반례로 확인한다. 10가구 전부의 기술값이지 실제 가계/미래 분포 추정이 아니다.
- **정적/모바일/접근성:** 작은 점 축을 축소하기보다 고른/꼬리 집단을 세로 정렬하고 공통 금액축 유지. 정렬 전후 수치표·순위 라벨·범례와 키보드 프리셋. 색 없이도 평균 선/중앙 괄호를 구별하고 움직임 없이 양쪽 첫 장면을 읽는다.
- **주요 검사:** n0 정의 불가, n1, 짝/홀수 중앙, 중복값, 모두0, 음수 순유출을 허용한 별도 데이터의 부호, 유한값 검증, 마지막 구간 우측 끝 포함·누락/중복 없음. 근거 S01–S03.

### A · 02 평균 손실과 버틸 돈

- **눈으로 발견할 관계:** 같은 기대손실 막대 뒤에 다른 큰 손실·부족액이 남고, 돈의 도착일만 늦어져도 납기 경계가 달라진다.
- **자체 사례:** 한 가상 기간의 손실 A는0/100만원에 확률80/20%, B는0/200/1,600만원에97/2/1%. 서로 배타적·전체를 채우는 결과다. 둘 다 기대손실20만원이다. 현금200만원이면 A의 부족0, B의 큰 사건 부족1,400만원·발생 가정1%·**기대부족액14만원**이다.
- **시각/과정:** 손실 크기 축에 확률 질량을 놓고 현금200의 세로 경계를 겹친다. 결과 하나를 선택하면 손실을 충당액/미충당액으로 분해한다. 별도 날짜 행에서 확정 도착100만원의 날짜30과 지출일15/45를 비교한다. 늦게 들어오는100은15일 현금으로 세지 않는다.
- **조작/불변량:** 현금0/200/300/1,600, 지출15/45일, 분포A/B, 결과 단계. `기대손실=ΣpL`, `기대부족액=Σp max(L−납기현금,0)`, 부족확률=`Σp·1[L>납기현금]`. 모든 결과에서 손실=충당+미충당; 납기 현금=충당+남음. 납기 현금은 초기 현금+납기 전 도착한 외부 유입이며, 뒤에 올100은 별도 예정 항목이다. 비용/차입/보험금 없이 돈을 만들지 않는다.
- **반례/라벨:** 기대부족액14는 큰 사고 때 필요한1,400과 다르고, 확률을 몰라 시나리오만 있으면 기대값을 계산하지 않는다. ‘기대부족액’은 이 장의 현금 경계 함수이며 금융규제의 Expected Shortfall/VaR와 같은 지표라고 쓰지 않는다. 꼬리는 이 분포의 큰 값 쪽이며 실재 손실 상한이 아니다. 현금1,600으로 부족0이 돼도 손실 자체는 남는다.
- **정적/모바일/접근성:** 전체 손실 분포·날짜별 사용 가능 현금·결과별 부족표를 함께 제공한다. 작은 확률 막대에는 직접 라벨, 큰 금액은 잘라 숨기지 않고 세로 재배치. 버튼으로 결과·날짜 전환, 색 외 빗금/경계선, reduced-motion 전후 고정 비교.
- **주요 검사:** 확률합1, p0/1, 손실0, 현금과 손실 같은 경계, 납기와 도착 같은 날의 명시한 입금→지출 순서, 불가능 결과 표시, 재실행/반올림 독립. 근거 S04·S11와 자체 산술; 보험금 계약은 재현하지 않음.

### B · 03 한 번도 없었던 일의 확률

- **눈으로 발견할 관계:** 가정한 확률은 같아도 작은 기록의 발생 횟수는 다르다. ‘기대1건’과 ‘정확히1건’은 다르다.
- **자체 사례/시각:** 가상 지급 지연을 서로 독립이고 확률이 일정한 사건으로 가정한다. p=1%, n=100의 기대건수1과, 이항모형의0건 확률 `(1−0.01)^100≈36.6032%`를 나란히 보인다. 위에는 모형의 횟수별 분포, 아래에는 고정 seed의 관측 기록·실제 횟수/분모를 둔다.
- **과정/조작:** 알려진 p 가정→기록 하나 보기→다른 표본번호 비교→관측비율과 이론값 구분. p0/0.01/0.02/1, n10/100/1,000, 표본번호와 한 단계/처음부터. seed를 입력하지 않아도 반복 가능한 번호를 제공하고 표본번호 변경 이력을 숨기지 않는다. 기본 사례가0건인 경우라도 “설명용 선정 표본”임을 밝힌다.
- **모델/불변량:** 정확한 이항분포/기대건수와 seed 생성표본을 별도 필드로 반환한다. 전체 확률합1, 횟수0–n, `관측비율=k/n`. n0은 자료 없음. 큰 n에서 팩토리얼 오버플로 대신 안정적인 계산을 검증한다. 그림에서 꼬리를 묶으면 묶인 횟수 구간과 확률합을 명시한다.
- **짧은 비교:** 지연 가정1%→2%는 상대100% 증가, 절대+1%p, 동일10,000건 기준 기대100→200건이다. 다른 분모를 섞지 않는다. 소수 기대건수는 관측건수와 구분한다.
- **반례/불확실성:** 과거99번 없었다고 다음1번이 정해지지 않는다. 단, 독립·일정확률 가정이 깨지는 공통 장애에는 같은 식을 적용하지 않는다. 0건 기록으로 실제 p=0을 확정하지 않는다. p를 모르는 추정 문제는06에서 다시 다룬다.
- **정적/모바일/접근성:** 반복 결과를 카드 회전 대신 표본별 정적 점/횟수표로 제공한다. 1,000건을 모두 작은 점으로 쑤셔 넣지 않고 묶음의 단위를 명시한다. 현재 k/n과 모형 p를 직접 텍스트로, 키보드 단계·정지·reset, 움직임 없이 누적 표를 읽게 한다.
- **주요 검사:** seed+입력+표본번호 재현, p0/1 퇴화분포, 같은 seed prefix, 확률합/기대값 교차 검산, 이론값을 실현값으로 덮지 않음. 근거 S04.

### B · 04 알림이 왔을 때 다시 세기

- **눈으로 발견할 관계:** 오류를 잘 잡는 비율과 알림 중 실제 오류의 비율은 분모가 다르다. 드문 오류에서는 정상 건수의 작은 오경보도 클 수 있다.
- **정본:** 전체10,000건 중 실제 오류100건(1%). 오류의90%에 알림, 정상의2%에도 알림. 실제 오류+알림90, 오류+무알림10, 정상+알림198, 정상+무알림9,702. 알림288건 중 오류90건이므로31.25%. 이 표는 가정한 비율을 정확히 펼친 가상 집합이지 무작위 표본에서 반드시 나오는 건수가 아니다. ‘민감도90%’를 이31.25%로 바꿔 읽지 않는다.
- **시각/과정:** 전체→오류/정상→알림/무알림의 건수 나무와 동일2×2표를 연결한다. ‘알림 받은 것만’ 선택 시 그288건의 경계만 확대하고90/288 분모를 고정 표시한다. 사람10,000명을 장식 점10개로 바꾸면서 한 점을1명처럼 보이지 않게 한다. 묶음은 정확한 단위와 건수 라벨을 갖는다.
- **조작:** 오류 기저율1%/10%, 민감도90% 고정, 오경보율2% 고정으로 시작한다. 10%에서는900/(900+180)=83.3333%. 이후 허용 범위 내 비율 프리셋과 알림/무알림 조건 선택. 알림이 없다는 관측도 오류확률0의 증거가 아닌 반례다.
- **모델/불변량:** 모든 칸의 합10,000, 행/열 합 일치, `P(오류|알림)=동시/알림`, `P(알림|오류)=동시/오류`; 동일 사건의 전확률 분해와 자연빈도 결과 일치. 분모0은 정의 불가이며0%로 대신하지 않는다. 알려진 비율을 사용한 베이즈 갱신이고 비율 추정의 확실성을 새로 만들어 내지 않는다.
- **반례/라벨:** 가상의 지급 오류 신호일 뿐 금융사기 탐지 정확도·개인 신용·사람의 진위 판정이 아니다. ‘알림90% 정확’은 무엇의90%인지 질문한다. 같은 알림을 중복 증거로 두 번 갱신하지 않는다. 순차 증거는 독립성/조건부 의존 정보 없이는 결합하지 않는 경계만 설명한다.
- **정적/모바일/접근성:** 전체 나무는 세로로 재배치하고 조건 경계와 정확한 건수표 유지. 버튼/선택상자·키보드로 분모 전환, 초점 이동에 의존하지 않는 요약. 오류/정상은 모양·라벨로도 구분, reduced-motion에서는 같은 분할 전후 그림.
- **주요 검사:** 정본 네 칸·31.25%·83.3333%, 완전/무정보 신호, 기저율0/1, 알림0건, 정수 관측과 소수 기대건수 구별. 베이즈 관계는 집합·건수 직접 검산; 학습효과 논문 S15는 아직 미확인 후보.

### C · 05 일부를 보고 전체 말하기

- **눈으로 발견할 관계:** 표본의 평균들이 전체 평균 주위에 흩어지고, 표본을 크게 하면 일반적으로 그 흩어짐이 작아지지만 잘못 고른 집단은 그대로 빗나갈 수 있다.
- **자체 사례/시각:** 01의 각10개 값이 각각10번씩 나타나는 별도의 가상100가구 모집단을 사용한다. 값이 같은 가구도 서로 다른 고유 ID를 가지며, 같은 기록을 복사한 사례와 구별한다. 전체 명부→선택된 가구→표본평균 하나→여러 표본평균의 점도표를 연결한다. 가구100곳은100개월 자료가 아니다.
- **조작/과정:** 고른/꼬리 모집단, 비복원 단순무작위 표본 n5/20/80/100, 고정seed의 표본번호. 반복200개의 전체 분포를 즉시 볼 수 있으며 자동 추출을 기다리지 않는다. 별도 ‘지출이 적은 명부 앞쪽만 선택’은 편의표본임을 명시한다. 표본 수와 서로 다른 가구 수를 함께 센다.
- **모델/불변량:** 표본 내 ID 중복 없음, n≤N, 전수 n=N이면 평균 오차0. 표본간 추출은 새로 시작하며 독립적인 표본번호 규칙을 사용한다. 모집단 표준편차σ(N분모)로 단순무작위 비복원 표본평균의 정확한 표준오차 `σ/√n×√((N−n)/(N−1))`를 별도 이론값으로 제공한다. 이 식은 자체 유한집단 산술로 검산하며 반복200개에서 관측한 표준편차와 같다고 강제하지 않는다.
- **반례/불확실성:** 큰 표본 한 번의 오차가 작은 표본보다 반드시 작지는 않다. 같은 가구 기록을10번 복사하면 독립 정보10개가 되지 않는다. 편의표본에 무작위 표본의 표준오차·신뢰구간을 자동 붙이지 않는다. 조사 가중치·복잡 표본·자기상관은 추가 조건으로 안내하고 단순모형으로 실제 통계를 계산하지 않는다.
- **정적/모바일/접근성:** 명부 전체와 선택명단은 표/접근 가능한 목록, 반복 분포는 공통 축의 세로 패널. 모집단 평균선·표본평균 표식을 모양으로 구별. 키보드 n/표본번호·동일 seed 초기화·정적 전체 결과와 reduced-motion 제공.
- **주요 검사:** 전수/1개/경계, 선택 정렬에 요약 불변, 중복복사 식별, 같은 seed 재현, 모집단/표본 분산 분모 구분, 편의표본의 추론 unavailable 상태. 근거 S01·S02·S07.

### C · 06 평균의 범위와 다음 한 번

- **눈으로 발견할 관계:** 평균 위치에 대한 좁은 막대와 다음 한 관측에 대한 넓은 막대가 다른 질문에 답한다. 표본 수를 늘려도 개별 결과의 변동은 사라지지 않는다.
- **명시한 교육모형:** 가상 가게의 월순유입 편차를 독립·동일 정규분포, 알려진 표준편차20만원으로 둔다. 음수는 부족 방향의 편차이며 음의 매출이 아니다. 현실 가게의 자료가 정규·독립이라는 주장은 하지 않는다. 편차 평균5·n25라는 **별도 가상 요약 예**를 기본 계산 검산값으로 쓴다.
- **시각/조작:** 같은 금액축에 표본평균점, 평균 신뢰구간, 다음1회 예측구간을 다른 선/괄호로 나란히 둔다. n25/100, 신뢰수준90/95%, 편차의σ, ‘알려진 모집단에서 반복 표본 보기’를 분리한다. 반복 모드는 참평균0·σ20이라는 가상 생성 조건과 고정 seed로 표본을 만들고 실제 생성표본 평균을 계산한다. 요약 예5를 생성 결과처럼 끼워 넣지 않으며 참평균은 설명/검산용이지 추정 화면의 입력이 아니다.
- **모델:** 95%의 z≈1.959964로 평균 CI=`x̄±zσ/√n`; 새 독립1회 PI=`x̄±zσ√(1+1/n)`. 동일 정규·σ알려짐 가정 아래의 구간이다. n25/평균5/σ20이면 반폭 약7.8399와39.9756만원. σ를 표본에서 추정하면 이 z공식을 그대로 쓰지 않고 t 등 다른 절차가 필요하다고 설명한다. 임의 범위를 신뢰구간이라고 이름 붙이지 않는다.
- **해석:** 95%는 이 절차를 같은 가정 아래 반복할 때 참평균을 덮는 장기 비율의 성질이다. 이미 고정된 구간 안에 참평균이95% 확률로 있다는 빈도주의 해석, 관측95%가CI에 있다는 해석은 피한다. PI도 새 관측 하나에 대한 절차이며 모든 미래값·최악 손실을 보장하지 않는다. 반복표의 포함률을 정확히95%가 되도록 조정하지 않는다.
- **03 재방문:** 독립·일정확률의100번 관측에서 사건0건이라도, 정확한 단측95% 상한은 `1−0.05^(1/100)≈2.9513%`다. 이는 p가 그 이하일 사후확률95%라는 뜻이 아니다. 사건0건에 한정한 식이고 일반k에 복사하지 않는다. ‘3/n’은 큰n의 근사로만 선택 읽기에 둔다.
- **반례/불확실성:** 표본이 커도 편향·변화한 과정·공동 충격·정규모형 밖의 꼬리는 이CI가 해결하지 못한다. 조건을 깨는 장면은 경고/정적 반례로 제공하고 수학적95%를 그대로 보증하지 않는다.
- **정적/모바일/접근성·검사:** 두 구간을 세로로 쌓아 공통축·대상 라벨·정확한 끝값 표를 유지. 키보드 n/수준·반복번호, 색 외 선종류·정적 포함표. CI/PI의 폭 관계, n 증가 시 CI 수축/PI의 잔여 변동, σ0, n0 거부, seed 재현, 포함 판정의 반올림 독립, 0사건 상한0–1·n 증가 시 감소를 검사한다. 근거 S05·S06·S08.

### D · 07 같이 움직였다는 증거

- **눈으로 발견할 관계:** 두 숫자의 동행 뒤에 공통 조건이 있고, 집단 구성만 바뀌어도 전체 평균의 방향이 뒤집힐 수 있다.
- **자체 사례:** 가상 매장들의 캠페인 사용/미사용과 일매출. 비수기 사용80일·평균80단위, 미사용20일·70; 성수기 사용20일·180, 미사용80일·170. 각 계절 안에서는 사용 쪽이10 높지만 전체 사용100·미사용150이다. 표의100일은 서로 독립이라는 추정 가정을 자동 부여하지 않는다.
- **시각/과정:** 계절색+형태를 가진 관측 묶음의 비례 띠·집단별 평균점과 전체 평균점을 연결한다. 옆에 계절→캠페인 선택, 계절→매출의 공통 원인 후보를 연결하되 ‘후보 설명’ 점선으로 표시한다. 집계 전→계절로 나눔→구성비만 맞춘 비교의 순서다.
- **조작/모델:** 원래 네 칸의 건수·평균·관측은 보존하고, 별도 표준화 비교에서 양쪽 계절 가중치만50:50으로 맞춘다. 재가중 평균130/120으로 방향이 달라진다. 새로100일을 관측했거나 기존 관측을 다른 계절로 옮긴 것이 아니다. 이는 동일 구성으로 다시 가중한 기술 비교이지 캠페인 인과효과+10 추정이 아니다. 합계/평균/관계도 라벨은 같은 표에서 읽는다.
- **반례/불확실성:** 계절을 나누면 모든 교란이 사라졌다고 하지 않는다. 역인과·가격/매장차이·동시 변화·선택 이유가 남는다. 무작위 배정·타당한 비교 설계의 역할을 설명하되 실제 실험을 한 것처럼 원인 화살표를 확정하지 않는다. 상관계수는 선형 동행 요약이고 인과확률이 아니다.
- **정적/모바일/접근성:** 네 집단을 세로 행으로, 계절 후보 경로를 아래에 둔다. 같은 금액축·건수·전체 분모·가중치표 유지. 구성비 프리셋/키보드, 정적 전후 비교, 색 없이 계절 라벨. 애니메이션이 원인이 실제 작동하는 장면인 것처럼 보이지 않게 한다.
- **주요 검사:** 가중평균 정본100/150→130/120, 빈 집단 분모0, 원래 총건수/관측 불변·각 가중 합계 일치, 비교 가중치만 변하면 집단 내 평균 유지, 원인 판정 unavailable. 근거 S09·S07.

### D · 08 함께 손실 나는 조건

- **눈으로 발견할 관계:** A와B 각각의 손실 확률이 같아도 ‘둘 다’ 칸의 크기가 달라지면 묶음의 큰 손실 확률이 달라진다.
- **자체 사례/시각:** A/B 각각 한 기간에20% 확률로−20%, 그 밖에는0%라는 가상 모형. 처음1,000단위를 반반 보유한다. 공동 손실 q=4%이면2×2확률표는 둘다4·A만16·B만16·없음64%; q=20%면20·0·0·80%; q=0이면0·20·20·60%. 표의 행/열 합20%는 유지되고 묶음손실0/100/200단위의 분포가 변한다.
- **과정/조작:** 개별 분포 고정→짝짓기/결합분포 변화→묶음 손실과 현금경계150 비교. q0/4/20%, 보유비중0/50/100%, 동일 시작금액, 공통충격 프리셋. 대각선 공동사건 영역·주변 합·손실 막대를 연결하고 단순히 이름이 다른 두 상자로 표현하지 않는다.
- **모델/불변량:** `max(0,pA+pB−1)≤q≤min(pA,pB)`; 셀합1·음수금지·주변확률보존. pA=pB=.2이면 q=.04는 독립, q=.2는 완전동행이다. 기본 반반 기대손실40은 세 관계에서 같지만 손실>150확률은q로 달라진다. 수익비중과 사건확률 가중치를 다른 필드로 둔다.
- **상관 반례:** 별도3개 동일비중 결과 A=`[-20,0,20]%`, B=`[10,−20,10]%`는 선형상관0이지만 B가A로 정해지는 의존이다. 기본2×2이항 모형의 상관0 사례를 ‘모든 분포에서 독립’으로 일반화하지 않는다. 둘 중 한쪽 분산0이면 상관은 정의 불가다.
- **불확실성/경계:** q는 추정한 실제 시장값이 아니다. 과거 상관을 고정해 미래를 보장하거나 최적 비중을 추천하지 않는다. 음의 상관에서도 모든 위험이 없어지는 것은 아니다. 보험료·보험회사 공동재원은4권의 범위로 남긴다.
- **정적/모바일/접근성·검사:** 2×2표/주변합을 먼저 보이고 결과분포를 아래로, 같은 축·직접 라벨·빗금으로 공동사건 표시. 키보드q/비중, 정적 셀표/손실표, 움직임 없는 짝짓기 비교. 정본 기대40·공동 부족q, 비중 합1, q경계 거부, 분산0 상관, 비선형0상관 반례, 동일 frame값을 검사한다. 근거 S10·S11와 자체 유한분포 산술.

### E · 10 많이 찾으면 보이는 우연

- **눈으로 발견할 관계:** 실력 차이가 없는 가상 후보도 더 많이 찾으면 과거 최고값은 커질 수 있다. 고른 뒤 다시 고르면 검증용 자료도 선택에 사용한 자료가 된다.
- **자체 자료/시각:** 각 후보가 각 가상 기간에 독립적으로 ±2% 초과수익을 같은 확률로 내는 **실제 전략이 아닌 잡음 모형**이다. 후보의 참기대초과수익은0, 비용은0이며 비교 기간은 같다. 고정 seed로 최대100후보×48기간을 먼저 생성한다. 선택24기간/조정12기간/마지막 보류12기간을 명확히 나누고, 후보1/10/100개에서 같은 prefix를 보인다.
- **과정/조작:** 선택 구간의 산술평균 초과수익으로 후보를 고정한다(동률은 고정 ID 순). 조정 구간 보기 → 최종 후보 잠금 → 보류 구간 공개 순서로 진행하고 전체 시도 수·선택 기준·수정 이력을 남긴다. 보류 공개 뒤 규칙을 바꾸면 그 자료는 이미 본 자료로 바뀌고 독립 검증 배지를 제거한다. reset이 같은 자료를 새 독립 표본으로 만들지 않는다.
- **시각 속성:** 동일 축의 후보 분포와 선택된 한 점, 구간 사이의 잠금 경계, 선택 시점 뒤 자료의 가림/공개 상태를 연결한다. 큰 숫자의 1등 표만 보여 주지 않는다. 기본 화면에 선택 절차와 후보 수가 보인다. 이후 성과가 반드시 낮아지도록 seed를 고르지 않고 우연히 좋아지는 반례도 설명한다.
- **모형/반례:** 후보 수가 늘면 중첩된 선택 구간의 최고값은 감소하지 않지만 보류 성과의 개선은 보장되지 않는다. 후보100개가 완전히 같은 자료를 쓰는 의존 프리셋은 독립100시도와 다르다. 실제 백테스트에는 거래 가능성·비용·시점·살아남은 대상·시대 변화가 더 필요하며, 이 모형은 시장 예측기나 투자전략 최적화가 아니다. 산술평균 초과수익은 선택용 통계이며 누적 계좌 수익률이라고 표시하지 않는다.
- **다중비교 짧은 장면:** 효과가 없는 독립 검사 각각의 거짓 신호 확률을5%로 정한 경우, m번 중 적어도 하나의 거짓 신호는 `1−0.95^m`이다. m1/10/100은5/약40.1263/약99.4079%. 이는 ‘선택한 후보가 거짓일 확률’이나 실제 전략100개의 확률이 아니다. 의존 검사에는 이 곱셈을 쓰지 않는다. p값은 효과 크기·가설이 참일 확률이 아니라는 ASA의 경계를 짧게 덧붙이고 검정법 백과로 늘리지 않는다.
- **정보 시점:** 별도 고정 타임라인에 관측 대상 기간/발표일/규칙 선택일을 두어 선택일 뒤 발표값은 사용 불가라고 모델로 판정한다. 시간 자료를 무작위로 섞으면 괜찮다는 규칙을 만들지 않는다. 실제 코딩/특성 선택/하이퍼파라미터 엔진은 제외한다.

1. 최신 main·작업 트리·AGENTS/계획/선행 배치 증거·병행 책을 확인하고 별도 브랜치/트리를 쓴다. 다른 책의 미공개 소스를 편의상 합치거나 main 쓰기/배포 경합을 일으키지 않는다.
2. 한 배치의 두 장과 기존 영향 장만 구현한다. 설명 관계/시각 속성/조건 전후/모델 근거를 먼저 적고 공식 출처 확인일과 한계를 본문에 남긴다. 독립 검토로 통계 해석·산술·모델/UI·범위·접근성·시각 설명력을 확인한다.
3. **전체 `npm test`·전체 `npm run build`·`git diff --check`를 유지**한다. 의존성 준비는 최신 저장소 지침에 따른다. targeted 검사는 보조이지 전체 unit/build의 대체가 아니다.
4. 평상시 브라우저는 **확률 책의 추가/수정·영향 장+홈/권차/목차/읽음 공통 smoke**에 집중한다. 기존 책 전체 상세 검사를 매번 되풀이하지 않지만 선택된 기존 suite의 필수 assertion을 자르지 않는다. 새 verifier 등록/선택기·공통CSS·workflow 같은 공통 변경은 현재 정책의 넓은 회귀 대상이다.
