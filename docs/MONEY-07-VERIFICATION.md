## 모바일·키보드·reduced-motion

Chromium viewport 390×844 / 320×844와 `prefers-reduced-motion: reduce`를 사용했다.

- 비교 그림과 예산 패널이 세로 배치되고 주요 금액·라벨은 HTML 크기를 유지한다.
- 변경 월 보기·처음부터·한 단계·재생/정지·표 열기, 큰 원금/짧은 기간의 경계 입력을 조작했다.
- 일반/표 열림/큰 월 납입 모두 문서 scrollWidth가 390/320px로 뷰포트와 같음.
- reduced-motion에서는 재생 중에도 이동 CSS animation이 none이며 같은 정적 단계·값을 제공.
- 모바일 경로는 세로 이동과 아래 방향 화살표로 바뀐다.
- 스크린샷 검토에서 큰 음수 눈금의 부호 잘림을 발견했다. SVG 축 라벨의 bounding box가
  왼쪽 밖으로 나가는 재현 검사를 추가해 실패를 확인하고, 큰 숫자일 때 축 여백을 넓혔다.
  재검사 통과와 320px 스크린샷에서 `-2,990`만원의 부호까지 표시됨을 확인했다.
- 04 물가·05 이자 장도 두 모바일 폭에서 단계 조작, 문서 넘침 없음,
  reduced-motion의 실행 중 CSS 이동 효과 없음 확인으로 기존 검증을 보완했다.

실제 휴대기기 터치·Safari/WebKit·OS 설정 변경·스크린리더 실기 검증은 미실행이다.
viewport/미디어 에뮬레이션을 실제 기기 통과로 보고하지 않는다.
