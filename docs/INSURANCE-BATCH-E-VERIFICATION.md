# 보험 배치 E · 09–10 및 전체 점검

작성일: 2026-10-20 KST. 범위: 09 claims·10 reading-insurance, 소개·01–10 전체 편집 점검. D 수정판의 최종 게시 게이트를 끝낸 뒤 순차 공개한다. 현재 문서는 로컬 준비 상태이며 구현·검증·게시 근거를 구분한다.

## 설계

09는 약정상 지급대상과 실제 도착 현금을 분리하고, 납기 당시 부족액과 나중에 남은 미충당 지출을 다른 값으로 유지한다. 같은 날에는 입금→납기 순서를 명시한다. 기본값·지연·거절·일부지급은 고정 가상 시나리오이며 실제 법정 지급일이나 개별 청구 판단이 아니다.

10은 자체 가상 계약의 문서에 적힌 약속, 계산을 위한 가정, 아직 모르는 조건을 다른 선/경계/기호로 나눈다. 확인된 약속을 실제 지급 확정으로 바꾸지 않으며 미확인을 0원이나 거절로 채우지 않는다. 사건일·보장대상 가정 변경과 조건부 손실 영역을 같은 모델/정적표에서 읽는다. 점수·랭킹·가입 추천은 없다.

## 실행·검토 상태

로컬 구현과 소스·모델 검증을 완료했다. 실제 브라우저·게시 결과는 실행 후 아래에 기록한다. 사용자의 컴퓨터를 사용하지 않으며, 로컬 Chromium 권한 제한을 우회하지 않는다. 지원되는 Actions production·published Chromium과 자산 일치·직접 PNG 검토를 게시 게이트로 유지한다. 실제 기기·Safari/Firefox·스크린리더 음성·학습효과·개별 계약 적합성은 미검증이다.

## 구현과 게시 전 독립 검토

09는 기본·납기 당일·지연·거절·일부지급의 다섯 고정 사례를 구현했다. 입금 → 납기 → 충당의 같은 날 순서를 모델이 정하고 모바일 사건 목록도 같은 순서를 사용한다. 지출·현금·과거 부족 기록의 합계를 섞지 않는다. 10은 자체 문서 3개와 분류 문장 12개, 30/90/180/365일 경계, 실선 약속·점선 가정·열린 미확인 관계를 구현했다. 미확인 사건일은 임의의 90일 값이나 위치로 표시하지 않는다.

독립 소스 검토에서 실제 실행 전 예방한 UI 결함은 09의 열린 현금 경로에 채움색이 상속되는 문제, 0원 기록 막대의 테두리가 너비를 만드는 문제, 모바일의 같은 날 순서, 10의 미확인 날짜 컨트롤 표시다. 각각 경로의 `fill:none`과 점만 채우기, 0값의 테두리 제거, 모델의 같은 날 정렬, 미확인 시 슬라이더 숨김과 날짜 버튼으로 새 가정 복귀로 바로잡았다. 마지막으로 09 날짜축 끝값도 D와 같은 고유 너비·줄바꿈 방지 규칙을 적용했다. 이 소스 검토를 실제 화면 합격으로 기록하지 않는다.
