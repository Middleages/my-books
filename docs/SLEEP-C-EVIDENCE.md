# 수면 C 05–06 근거·시각 준비

2026-10-20. 2권 B 자체 게이트를 닫고 3권 B 검증을 기다리는 동안 다음 순환 배치를 준비한다. C 앱 구현·검증·게시 완료를 뜻하지 않는다.

직접 열람: NHS Helping your baby to sleep, https://www.nhs.uk/baby/caring-for-a-newborn/helping-your-baby-to-sleep/ , 페이지 검토2025-01-28. 아이마다 수면/각성 패턴이 다르고 성장·몸 상태 등에 따라 변할 수 있다는 설명, 간단하고 진정되는 취침 전 순서의 일반 안내를 확인했다. 개별 수면량 예시와 일부 아이의 야간 수유 관련 문장을 보편적 목표/중단 지시로 사용하지 않는다. 안내가 효과나 정확한 잠드는 시각을 보장한다는 주장도 하지 않는다.

NHS Sleep and young children, https://www.nhs.uk/baby/health/sleep-and-young-children/ , 페이지 검토2023-03-31, 다음 검토 예정2026-03-31로 표시되어 있다. 현재 페이지 열람일과 오래된 검토일을 구분한다. 예측 가능한 차분한 순서라는 일반 개념 외 세부 시간 이동·늦은 낮잠 제거·장난감/comforter 제안은 채택하지 않는다. 특히 영아 안전 수면 지침과 충돌할 수 있는 느슨한 물품을 모델에 추가하지 않는다.

05 시각 계약 초안: 연령 없는 합성 며칠을 같은 하루 눈금으로 나란히 그린다. ‘잠의 기회’와 ‘확인된 잠’은 다른 층이고 추정/모름을 별도 무늬로 표시한다. 하루의 짧은 기록만으로 낮잠 전환일을 확정하지 못함을 보여 준다. 새 월령표, 낮잠 제거 권고, 강제 각성 시간 최적화 없음.

06 시각 계약 초안: 동일한 차분한 활동·잠자리 준비·돌봄 인수인계 카드를 두 가지 합성 가족 일정에서 재배열한다. 카드 순서와 실제 입면 결과를 분리한다. 시간·횟수 성과 점수가 없고, 안전·필요한 수유/불편 확인은 루틴 준수와 교환하는 항목이 아니다. 강제 울음 방치·약물·정해진 수유 중단 없음.

교육용 합성 데이터만 사용한다. 의학 전문가 감수 미실행. 근거의 연령/국가/검토일과 원문 범위를 보존한다.

구체 모델 초안:05는 첫째날/둘째날/셋째날의 08–20시라는 같은 표시 창을 사용한다. 기회 띠와 확인 수면 띠, 추정 무늬를 분리하며 전체24시간 수면량으로 오해하지 않게 한다. 추정 포함/확인만 보기 필터는 보이는 정보만 바꾸고 확인 수면 수치를 늘리지 않는다. 기회 기록 없음은 실제 기회0번과 같지 않다. 단 하루 미관찰을 거부/실패로 바꾸지 않는다.

06은 정해진 취침시각 계산 대신 차분한 이야기·잠자리 준비·돌봄 역할 확인 세 카드의 상대 순서를 조작한다. 화살표는 절차의 순서이지 잠드는 인과 효과/소요시간이 아니다. 안전한 잠자리와 필요한 돌봄 확인은 움직이는 카드보다 위의 고정 경계로 둔다. 혼자 돌보는 경우와 교대하는 경우를 보여 주되 실제 가족 자료는 받지 않는다. ‘한 가지 순서가 모든 가족의 정답’으로 채점하지 않는다.
