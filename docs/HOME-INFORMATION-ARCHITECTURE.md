# 홈의 정보 구조 결정

결정일: 2026-10-18. 사용자 승인에 따라 적용한다.

## 문제와 결정

장마다 홈에 링크를 추가하면 교재의 성장에 따라 첫 화면의 스크롤도 계속 길어진다.
홈은 **책을 고르는 곳**, 책 소개와 독서 화면은 **장을 고르는 곳**으로 역할을 나눈다.
홈의 전체 장 목록을 제거하고 책 소개의 전체 목차와 독서 화면의 목차는 유지한다.

- 분야 필터는 `전체`, `IT·기술`, `돈·경제`로 시작한다. 기본값은 전체다.
- 컴퓨터·네트워크는 IT·기술, 돈 교재는 돈·경제에 속한다.
- 책 카드는 분야와 권차·제목·짧은 소개·읽은 장 수·진행률·책 링크를 제공한다.
- 데스크톱은 3열, 중간 폭은 2열, 모바일은 1열이다. 모바일에서는 표지 영역을 짧게 바꾸고 본문 글자 크기를 유지한다.
- `0 < 읽은 장 수 < 공개 장 수`인 책을 읽는 중으로 표시하고 선택 분야 안에서 먼저 보여 준다. 같은 상태에서는 기존 카탈로그 순서를 유지한다. 별도의 중복 추천 목록은 만들지 않는다.
- 처음 읽는 책과 모두 읽은 책도 필터 결과에서 숨기지 않는다. 모든 장을 읽으면 ‘모두 읽음’을 표시한다. 0장인 경우 진행률 분모를 1로 처리해 유효한 HTML을 유지한다.
- ‘이어서 살펴보기’도 기존 책 소개로 이동한다. 마지막 방문 장이나 최근 읽은 순서를 추정하지 않는다.

## 구현·호환성

`src/catalog.ts`의 `bookCategories`가 분야 ID·표시 이름을 관리하고 각 책의 필수 `categoryId`가 분류를, 필수 `volume`이 분야별 권장 학습 순서를 정한다. `volume`은 분야 안에서 중복하지 않는 양의 정수이며 제목 문자열·배열 위치·현재 공개 책 수로 추론하지 않는다. 기존 `category`는 책의 상세 분야 설명으로 유지한다.
새 책은 기존 분야에 배정하거나 명시적으로 새 분야를 추가하고 권차를 함께 지정한다. 기존 책의 권차를 재번호화하지 않는다. 책이 없는 분야는 필터에 표시하지 않는다. 장을 추가해도 홈에 장 목록을 다시 추가하지 않는다.

`src/components/Library.tsx`가 홈 UI를 담당한다. CSS는 `home-` 접두어로 한정한다. 필터는 `aria-pressed`가 있는 기본 버튼으로 키보드 조작하며 결과 수는 상태 영역으로 안내한다. 자동 움직임 없이 같은 내용을 읽는다.
분야 선택은 홈에 머무르는 동안 유지하고 책에서 홈으로 돌아오거나 새로고침하면 전체로 돌아간다. 별도의 저장 키는 추가하지 않는다.

책·장 URL, chapterId, readId, `my-books:read:v1`, 알 수 없는 기존 읽음 ID를 그대로 보존한다. 현재 공개 장의 ID로만 진행률을 계산한다. 교재 본문·실험·k3s 범위는 변경하지 않는다.

검색·페이지 나누기·마지막 방문 장 저장은 이번 범위에서 제외한다. 책 수가 늘어 분야별로도 탐색이 어려워지면 별도 결정한다.

## 분야별 권차 표시 — 2026-10-20 KST

카드 본문과 책 소개 제목 위에 `IT·기술 1권`, `돈·경제 3권`처럼 분야·권차를 함께 표시한다. 표지 그림 안에는 글자를 추가하지 않는다. 권차는 권장 학습 순서이며, 홈에서 읽는 중인 책을 우선하고 같은 상태에서 기존 카탈로그 순서를 유지하는 계약은 그대로다. 따라서 카드 위치가 바뀌어도 권차는 변하지 않는다. 홈의 짧은 안내가 이 의미를 설명한다.

- IT·기술: 컴퓨터 1권 → 네트워크 2권 → 쿠버네티스 3권. 데이터베이스 A 후보는 4권으로 소개·01–02를 등록하며 실제 게시 상태는 별도 검증 기록을 따른다.
- 돈·경제: 돈 1권 → 경제 2권 → 투자 3권 → 보험 4권 → 세금 5권. 세금 A 후보는 소개·01–02를 등록하며 실제 게시 상태는 별도 검증 기록을 따른다.
- 예약된 책·권차는 계획일 뿐이다. 구현되기 전에는 카탈로그·홈 카드·분야별 공개 권수에 추가하지 않는다.
- 공통 `bookVolumeLabel`이 `bookCategories`와 각 책의 `volume`을 읽는다. 화면별로 별도 번호를 계산하지 않는다.
- 분야 필터의 숫자는 현재 공개된 책 수이고, 개별 책의 `n권`은 학습 순서다. 책·장 URL, readId, 읽음 저장 키 및 알 수 없는 저장 ID는 변경하지 않는다.
