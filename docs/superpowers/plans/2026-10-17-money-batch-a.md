## 배포 전 검증 결과

- `npm test`: 기존 39개 + 돈 모델 11개 = 50개 통과.
- `npm run build`, `git diff --check`: 통과.
- Chromium: 1440×1000, 390×1000, 320×1000에서 새 세 장 렌더·가로 넘침 확인.
- 7가지 거래, 카드 구매·결제와 재실행, 원금/이자, 음수 순자산, 예산 지급일·지출월·목적 적립 변경 확인.
- 재생/정지 때 단계와 이동 표시 정지, 조건 변경 초기화, 키보드 범위 입력·Enter, reduced-motion 정적 단계 확인.
- 읽음 표시 후 새로고침 및 기존 computer/network/미지의 이전 ID 보존 확인.
- 기존 computer 2장·network ports/tls/diagnosis 경로와 ports 다시 예측, 새 소개 화면 확인.
- 새 소개와 기존 Ports의 MDX 문단 중첩 정리 후 개발 모드 콘솔 오류 없음.
- 원격 브라우저는 로컬 서버에 연결할 수 없어 로컬 Chromium/Playwright로 검증했다.
- 실제 Android/iOS 기기·Safari는 미검증. 금융상품의 실제 계약 계산은 제공하지 않는다.
