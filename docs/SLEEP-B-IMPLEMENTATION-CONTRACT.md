# 수면 B 03–04 구현 계약

2026-10-20. A 소스·실제 화면·전체10-suite 완료 뒤 별도 작업트리에서 준비한다.3권 A와 섞지 않는다. 통합 담당 메모리 우선 창 이후에도 로컬 build를 다른 작업자와 직렬로 실행한다. B 본문/모델 검증·원격PR·게시 게이트는 아직 미완료다.

## 03 졸림과 하루의 리듬
독자가 눈으로 볼 관계: 깨어 있음에 따라 변하는 수면 압력의 방향과 환경의 시간 신호는 서로 다른 층이다. 정성 모형의 높이나 화살표는 호르몬 수치·실제 잠드는 시간·영아별 성숙 시점을 나타내지 않는다.

두 조작을 분리한다. ‘깨어 있는 장면/수면 뒤 장면’은 압력 방향을 비교하고, ‘낮의 빛/저녁의 어두움’은 환경 신호의 개념을 비교한다. 합성 시간표를 개인 처방으로 만들지 않으며 강제로 오래 깨워 두기, 낮잠 없애기, 정확 wake window를 최적화하지 않는다. 시간대 신호를 바꾸어도 임상 입면 시각을 출력하지 않는다. 단계/초기화와 정적 해설을 제공하고 자동재생은 하지 않는다.

## 04 월령과 총수면 범위
독자가 눈으로 볼 관계: 동일한 총량도 밤잠/낮잠의 구성이 다를 수 있고, 미확인량이 있으면 총량을 확정할 수 없다. 고정24시간 눈금과 합성 분 단위 구성만 비교한다.

합성 사례는 개인 연령과 결합하지 않는다. 출처 참고표는 별도 탐색으로 둔다.2016 AASM 원표현4–12개월/1–2세/3–5세와 낮잠 포함 여부를 표시한다.12개월은 두 원표현이 겹침을 그대로 보여 주고 하나의 개인 목표로 조용히 선택하거나 평균내지 않는다.4개월 미만에는 권고 band를 생성하지 않는다.3세 경계는 원표현대로 분리하고 월령 사이를 보간하지 않는다. 범위 안/밖의 정상 판정색·점수·질환 예측·취침시각 처방은 없다.

모든 자료는 source/version/targetPopulation/country/checkedAt/limitations를 보존한다. 수면량만으로 건강이나 수면의 질을 결론 내리지 않는다. 사용자 실제 기록 입력·저장·전송은 없다. 전체 unit/build·전용 원본PNG/상호작용·배치별 게시를 분리 기록한다.
