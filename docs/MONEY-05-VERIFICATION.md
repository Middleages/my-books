## 실행 환경과 화면 검증

Browser 플러그인 스킬은 있으나 호출 가능한 실행 도구는 제공되지 않았다.
공개 게시 화면은 별도의 cloud Chrome으로도 확인하며, 로컬 데스크톱/모바일 검증은
일반 Playwright Core + npm 배포 `@sparticuz/chromium`의 headless Chromium 153.0.8010.0으로 실행했다.
기본 Playwright Chromium 다운로드는 ZIP 오류로 실패했고, npm 패키지에 포함된 Chromium으로 실행을 완료했다.
테스트 의존성은 저장소 밖에 설치했으며 프로젝트 의존성·lockfile은 변경하지 않았다.
한글 폰트가 없는 실행 환경에는 QA용 NanumGothic 폰트를 등록했다. 사이트에 폰트/네트워크 의존성은 추가하지 않았다.

검증 명령: 저장소의 `npm run build`, `npm test`, `git diff --check`와
임시 Playwright 검증 스크립트 `node /tmp/my-books-qa/verify.mjs`.
Vite와 브라우저를 같은 실행 네트워크 공간에서 시작해 `http://127.0.0.1:5173/my-books/`에 접속했다.
