## 브라우저 제약과 미검증 범위

브라우저 스킬과 현재 제공 API를 확인했다. 연결된 로컬 확장 브라우저 도구는 노출되지 않았고 cloud Chromium을 사용했다. 로컬 Vite 서버는 127.0.0.1:5173에서 실행됐지만 cloud 브라우저 접근은 `ERR_CONNECTION_REFUSED`였다. 따라서 로컬 실제 렌더를 통과로 기록하지 않는다. 게시 후 데스크톱 검증 결과는 아래에 별도 추가한다.

현재 API에는 viewport/media 변경 기능이 없다. 배치 A 및 B의 **320/390px 모바일과 reduced-motion 실제 실행은 미검증**이다. CSS 세로 배치, 기본 정적 기호·막대, 타이머 정리·초기화·네이티브 키보드 조작·정적 표는 코드로 확인했으며 이를 실제 실행으로 대신하지 않는다. 실제 휴대폰·Safari/Firefox·스크린리더·axe 검사도 미실행이다.
