# 0~36개월, 아이의 발달을 이해하는 법 — 상세 계획

작성/근거 확인일: 2026-10-20. 계획 문서 반영 및 소개·01–02 구현 착수 승인 상태. 임상 검토·본문 구현·앱 검사·배포는 아직 미실행.

## 핵심 질문
“아이의 행동을 어떻게 관찰하고, 놀이로 함께하며, 도움이 필요할 때 무엇을 전달할까?”

## 학습 구조
소개 + 12장. 월령별 자료를 찾는 탐색과 개념을 순서대로 배우는 목차를 병행한다. CDC가 제공하는 2·4·6·9·12·15·18·24·30·36개월 자료를 참고 지점으로 사용하되 한국 검진 시기와 혼동하지 않는다. 신생아/0~1개월은 관계·관찰 입문으로 두고 출처 없는 월별 체크 기준을 만들지 않는다. 13개월 등 중간 월령에서 ‘13개월 기준 통과’처럼 보간하지 않고 확인 가능한 앞뒤 자료의 실제 연령을 그대로 표시한다.

## 장별 설계

### 01 발달은 한 줄의 순위가 아니다 — development-map
- 질문: 몸·말·놀이·관계가 같은 속도로 발달할까?
- 시각: 합성 아이의 네 영역별 관찰 사건을 평행 시간 띠로 놓는다. 정상 범위나 퍼센타일로 가장한 곡선은 금지.
- 조작: 영역과 관찰 시점 선택. 보여 주는 것은 관찰 위치 변화이지 아이의 총점이 아니다.
- 반례: 말 한 항목으로 전 영역을 추론하지 못한다. 초기 화면에 ‘가상 관찰 예시, 규준 아님’ 표시.

### 02 개월수와 체크리스트를 읽는 법 — age-and-evidence
- 질문: 생활 월령·교정연령·자료의 기준 연령은 어떻게 다를까?
- 시각: 실제 날짜선과 조산으로 당겨진 출생 위치, 자료 출처의 연령 표지.
- 조작: 합성 재태기간/경과 주수 비교. 달을 항상 4주로 계산하지 않는다.
- 반례: 교정연령을 예방접종/행정 검진 일정 전체에 자동 적용하지 않는다. 음수 교정값은 예정일 전으로 표시하며 0개월 능력 판정 금지.
- AAP의 초기 2년 발달 해석 안내는 개별 진료 지침을 대체하지 않는다. 실제 도구별 적용은 별도 확인.

### 03 보이는 행동을 기록하기 — observe-not-label
- 질문: ‘잘 못해요’ 대신 무엇을 기록할까?
- 시각: 환경→기회→행동→도움의 연결 장면. 같은 행동도 기회가 없었을 수 있다.
- 조작: 합성 기록을 ‘관찰함/관찰하지 못함/기회 없음/모름’으로 분류.
- 반례: 미관찰을 실패나 0으로 바꾸지 않는다. 체크 수를 점수로 합산하지 않는다.

### 04 몸과 손으로 탐색하기 — movement-and-hands
- 질문: 큰 움직임과 손 사용은 놀이에서 어떻게 보일까?
- 시각: 자세·도달·잡기·놓기의 서로 다른 행동을 나란히 보여 주는 자체 삽화.
- 조작: 환경/물체 위치를 바꾸고 관찰 위치를 선택. 위험한 자세 유도·작은 물체 사용은 제외.
- 반례: 특정 행동 순서를 모든 아이의 필수 통과 경로로 만들지 않는다. 각 구체 행동의 연령 주장은 구현 때 공식 근거를 별도로 연결.

### 05 소리를 듣고 뜻을 나누기 — communication
- 질문: 말하기와 이해하기, 몸짓은 어떻게 연결될까?
- 시각: 보호자와 아이의 관심 대상·몸짓·소리가 오가는 장면.
- 조작: 합성 대화에서 기다림/응답 순서 관찰. 단어 수 자동 진단 금지.
- 반례: 한 장면의 침묵만으로 언어 능력·청력을 판정하지 않는다. 다언어 환경을 원인으로 단정하지 않는다.

### 06 주고받는 관계와 감정 — interaction
- 질문: 상호작용을 일방적인 자극과 어떻게 구분할까?
- 시각: 아이의 신호→보호자 반응→아이의 다음 신호, 과부하 신호에서 멈춤.
- 조작: 기다리기/따라가기 등 장면 순서 비교.
- 반례: 상호작용 횟수나 눈맞춤 지속 시간을 정상 점수로 바꾸지 않는다.

### 07 놀이로 알아가는 세상 — play-and-learning
- 질문: 탐색·모방·문제 해결을 일상에서 어떻게 볼까?
- 시각: 물체 탐색과 결과의 관계, 숨김/찾기·모방 같은 합성 놀이 사례.
- 조작: 장면과 관찰 질문 선택, 정답을 맞히는 아이 테스트가 아닌 보호자 해석 문제.
- 반례: 놀이 성공이 향후 지능이나 학습 성과를 예측한다는 표현 금지.

### 08 0~12개월 관찰 여행 — first-year
- 질문: 초기 월령 자료에서 무엇을 찾아야 할까?
- 시각: 0~1개월 입문과 2/4/6/9/12개월의 출처 표지가 있는 탐색 띠, 네 영역 필터.
- 조작: 연령·영역 선택 시 행동 설명/놀이/상담 준비가 함께 바뀜.
- 반례: 숫자 사이를 보간한 발달 기준 생성 금지. 각 항목은 자체 설명과 원출처 링크로 제공, 공식표 전체 복제 금지.

### 09 12~24개월 관찰 여행 — second-year
- 질문: 이동·의사표현·놀이의 변화는 어떻게 함께 나타날까?
- 시각: 12/15/18/24개월의 근거 지점과 독립적인 관찰 카드.
- 조작: 실제 기준 시점 확인 후 영역을 탐색.
- 반례: 8장과 겹치는12개월 데이터는 단일 정의를 재사용, 이웃 아이와 순위 비교 금지.

### 10 24~36개월 관찰 여행 — third-year
- 질문: 의사소통·상상 놀이·자기조절을 어떻게 관찰할까?
- 시각: 24/30/36개월 지점의 행동 맥락 비교.
- 조작: 낯선 환경과 익숙한 환경의 가상 관찰 차이를 확인.
- 반례: 모든 거부 행동을 지연이나 양육 실패로 판단하지 않는다. 24개월 자료 중복도 단일 소스.

### 11 기다려 볼 일과 상담할 일 — seek-support
- 질문: 우려가 생겼을 때 무엇을 준비하고 누구에게 문의할까?
- 시각: 관찰→우려 공유→표준 선별/평가라는 역할 구분도. 실제 서비스 절차는 한국 자료로 확인.
- 조작: 합성 사례의 기록과 상담 질문을 연결. 의료 긴급도를 자동 산출하는 분류기는 만들지 않는다.
- 반례: 이전 능력 소실·부모의 우려를 ‘다음 월령까지 대기’로 안내하지 않는다. 급성 증상/응급 상황은 별도 전문 지침 영역임을 명시.

### 12 우리 집 관찰과 놀이 계획 — observation-plan
- 질문: 비교와 채점 없이 다음 일주일을 어떻게 보낼까?
- 시각: 생활 속 기회·짧은 놀이·관찰 메모·상담 질문의 주간 보드.
- 조작: 합성 사례만 편집, 인쇄 가능한 빈 양식 제공. 발달 달성률·우수 부모 점수 없음.
- 반례: 모름은 모름으로 유지, 서버 저장/외부 전송 없음. 실제 아이 기록 기능은 별도 개인정보 설계와 승인 전 제외.

## 공통 모델 및 UI 계약
- EvidenceItem: id, sourceURL, sourceAgeMonths, domain, paraphrase, checkedAt, limitations. 근거가 확인되지 않은 항목은 ‘미검증’으로 분리해 본문 사실 데이터에 넣지 않는다.
- ObservationState 네 상태를 그대로 유지하며 achievementScore 필드를 만들지 않는다.
- AgeNavigation은 앞뒤 근거 지점 탐색만 수행한다. age→risk/diagnosis 함수 금지.
- 합성 예시·원출처 기준·개인 판단을 시각적으로 분리한다. 실제 빈도를 모르면 점 개수·면적을 통계처럼 표현하지 않는다.
- 모바일320/390에서 선택과 핵심 그림을 인접하게, 1440에서는 비교 그림을 나란히. 의미를 유지하는 라벨·모양·범례로 색각 차이를 지원한다.
- 자동재생 없음. 정지/한단계/초기화 및 reduced-motion 정적 전후 그림에서 같은 정보를 제공한다.
- 읽음률과 관찰 상태는 완전히 분리. 기존 localStorage 읽음 ID 유지.

## 구현 전 정확성 게이트
1. 한국 K-DST의 구체 문항·해석·검진 제도를 다루기 전에 현재 자료와 이용조건을 확인한다. 확인 전에는 해당 내용을 보류하며, A의 관찰 개념과 출처·연령 읽기 교육은 확인된 CDC·AAP 근거로 진행한다. 자료를 찾았다는 사실과 전문을 읽고 사용할 권리가 있다는 사실을 구분.
2. 항목별 근거 매핑과 자체 한국어 설명 검토. 의료 전문가 검토를 권장하며 실제 검토 전 ‘감수 완료’ 표시 금지.
3. 아이의 실제 상태를 판정하는 기능 없이 교육용 범위 검토.
4. 놀이별 안전 조건과 중단 신호의 공식 근거 확인. 구체 급식/수면/응급 처치는 별도 권으로 연결하되 미구현 링크 금지.
5. 근거 확인 실패 항목은 보류. 계획이 있다는 이유로 임의 기준을 만들어 채우지 않는다.

## 검증
모델은 날짜 경계/월말/윤년, 원출처 연령 보존, 중간월령의 보간 금지, unknown 유지, 초기화·정적 동등성을 검사한다. 전체 unit/build와 새 책/공유 홈 영향 범위의 브라우저 검사, 실제 원본 PNG 직접 검토를 수행한다. 최초 카테고리 등록·최종 책 마감은 기존 정책에 따른 넓은 회귀를 한다. 진단 정확도나 임상 타당성을 소프트웨어 테스트 통과로 주장하지 않는다.


## 2026-10-20 구현 착수 상태

사용자가 첫 권 계획 문서 반영과 구현 시작·배포를 승인했다. 이 승인은 구현이나 의학 검토가 완료됐다는 뜻이 아니다. 소개·01–02부터 순차 제작하며 본문·원출처·모바일 화면 검증 뒤 기존 게시 담당과 직렬 통합한다. 현재 문서 반영 준비 상태이며 앱 등록/게시 완료가 아니다.
