# 경제 교재 배치별 실행 프롬프트

작성일: 2026-10-18. 각 블록은 독립적으로 복사할 수 있다. 최신 main 기준으로 순서대로 실행한다. A가 완료된 뒤에는 B부터 실행한다. 계획이 아닌 실행 기록은 배치별 VERIFICATION 문서를 본다.

## 세션 A

```text
Middleages/my-books의 ‘경제 뉴스를 읽는 원리’ 배치 A를 진행하자.
최신 main의 AGENTS.md, docs/ECONOMICS-TEXTBOOK-PLAN.md, docs/ECONOMICS-SESSION-PROMPTS.md,
docs/CONTENT-AUTHORING.md, docs/HOME-INFORMATION-ARCHITECTURE.md,
docs/MONEY-TEXTBOOK-PLAN.md, docs/MONEY-BOOK-REVIEW.md와 이전 경제 배치 검증 기록을 먼저 읽어줘.
기존 관련 본문·컴포넌트·모델·테스트를 확인하고 첫 권의 전체 점검과 배포의 완료·게시를 확인해줘.
과거 SHA에 고정하지 말고 최신 main을 기준으로 작업해줘.

이번 범위: 소개·01 경제는 서로 연결된 흐름·02 수요·공급과 가격.
계획 문서의 이 배치 상세 범위와 다음 요구를 전체 작업 지시로 실행해줘.
가계/기업의 반대 흐름·기간/잔액·현금 보존과 재고 부족; 곡선 위 이동/곡선 이동·같은 가격 상승과 반대 수량. 기존 배치 A가 이미 완료됐으면 덮어쓰지 말고 검증 기록을 확인한다.

공통 기준:
- 비전공 성인을 위한 쉬운 한국어. 그림·짧은 설명 → 과정 관찰 → 예측·조작 → 해석·적용 → 이유 있는 확인 문제·출처.
- 본문은 MDX, 조작은 React/TypeScript, 계산·프레임·판정은 UI 독립 모델. 그림·표·계산은 동일 상태. 입력 폼과 결과 숫자만으로 시각 설명을 대신하지 않는다.
- 경제 모형의 가정·다른 조건 일정·인과/상관·시차·불확실성을 구분한다. 가상 사례와 실제 통계를 명시하고 확정 예측기를 만들지 않는다.
- 한국은행·공식 통계·담당 공공기관 원문으로 사실을 확인하고 출처·확인일을 장별 기록한다. 실제 통계는 표 ID·기간·단위·기준년·조정·잠정 여부를 적는다.
- URL/chapter id/readId는 계획 문서의 예약 ID를 따른다. 기존 URL·my-books:read:v1·알 수 없는 읽음 ID·분야·표지·다른 세션 변경을 보존한다. 미구현 장은 공개 링크·진행률에 넣지 않는다.
완료 조건:
- 모델 핵심 관계·경계값·0·실패 사례·재실행 테스트, npm test, npm run build, git diff --check.
- 데스크톱·320/390px 모바일 실제 렌더·조작·가독성·넘침·콘솔, 키보드·포커스·재생/정지/초기화·reduced-motion·정적 대안 검증.
- MDX 취소선·강조 별표 잔류·HTML 중첩 실제 렌더 검사. 기존 돈·컴퓨터·네트워크·쿠버네티스 대표 링크/실험·홈 분야/표지·읽음 새로고침 회귀.
- 해당 배치 검증 문서에 기준 main·발견·수정·명령·실행 결과·미검증 항목을 사실대로 기록하고 계획의 공개 상태를 갱신한다.
- 최신 main 병행 변경을 다시 통합하고 필요한 검증을 재실행한 뒤 main 반영, GitHub Actions·Pages 배포 성공과 실제 게시 자산/본문 확인까지 끝낸다.
중간 승인을 반복 요청하거나 계획만 제시하고 멈추지 말고 지정 범위의 구현·검증·반영·배포까지 진행해줘.
검증 문서: docs/ECONOMICS-BATCH-A-VERIFICATION.md
```
