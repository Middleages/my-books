## 반례가 보존하는 것과 바꾸는 것

회수액 변화는 이익·총자산이 아니라 현금/채권 구성과 영업 현금을 바꾼다. 추가 외상 재고는 재고·채무를 함께 늘리고 현금은 같으며, 이후 지급이 현금·채무를 줄인다. 상각 최초 가정 비교는 이익·순설비를 바꾸되 취득 지급은 바꾸지 않는다. 만기 분류 비교는 유동부채의 분모만 바꾸며 총차입·총부채·현금을 바꾸지 않는다.

12장의 원가 누락은 이익305/재고300, 자산1035=부채390+자본645와 현금 다리를 모두 만족하지만 재고 수불과 충돌한다. 출자 오분류는 매출450/이익115/납입300/이익잉여금105로 총자본405를 유지하지만 계약과 충돌한다. 모델 내부 등식·직접=간접 검사를 회계 적정성의 충분조건으로 소개하지 않는다. 실제 자료 진위·회수 가능성·재고 실재·법적 배당 근거는 모형 밖에 남긴다.

## 기준·출처·전문 범위

IFRS Foundation의 개념체계, IFRS15, IAS2/IAS16/IAS1/IAS7/IFRS18의 공식 개요·공식 설명 자료를 장별로 연결했다. 공개 개요 직접 확인, 검색 발췌, 접근권한이 필요한 전문을 구별한다. 한국회계기준원은 실제 국내 적용 기준 확인의 출발점이며, 작은 회사라는 이유만으로 특정 기준을 적용한다고 단정하지 않는다.
