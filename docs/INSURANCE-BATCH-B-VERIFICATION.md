## 설계와 범위

03은 계약을 맺고 보험료를 내는 역할, 보장 대상, 보험금 받을 권리, 보험자의 책임을 연결과 방향으로 읽는다. 같은 사람이 여러 역할을 맡는 경우를 비교하고 기본계약·특약의 포함/제한 경계를 본다. 공적·직장·개인은 보장을 찾는 출처로, 서로 배타적인 보험의 법적 분류가 아니다. 가상 인물만 사용하며 실제 건강·개인자료를 입력하지 않는다.

04는 총손실500만원을 제외100·공제50·정률부담70·한도초과80·보험금200만원으로 한 번만 분해한다. 이는 제외→공제→정률→건별한도→연간남은한도의 순서를 직접 정한 가상 계약이다. 실제 약관마다 다른 지급식을 보편 공식으로 만들지 않는다. 정액 약속은 같은 손실 띠에 더하지 않고 별도 사건 조건과 약정액으로 표시한다.

연간총한도300만원/건별한도200만원에서 같은 청구의 지급액은200→100→0만원이다. 관찰 재생·정지는 새로운 청구가 아니며, 연간한도는 명시적으로 새 보험연도를 시작할 때 초기화한다. 그림·정적표·숫자·예측 판정은 같은 모델 프레임을 읽는다.
