## 구현 범위
- 소개·01 발달 영역 지도·02 월령/교정연령/근거 읽기. 신규 `parenting` / `child-development` / 1권의 중복을 검사하며 기존 권차·읽음 ID를 유지한다.
- 자체 합성 관찰을 영역별 평행 띠와 세 관찰 시점으로 표시한다. 위치는 순서이며 발달 규준·능력 순위가 아니다. 네 관찰 상태를 합산하지 않는다.
- 고정 합성 날짜와 재태기간·경과 주수로 날짜선을 만든다. 예정일·관찰일 위치는 동일한 일수 모델에 비례한다. 예정일 전 음수는 별도 문구로 보존한다. 달=4주 환산과 실제 아이 입력은 없다.
- 원출처 연령 탐색은 날짜 계산과 독립적이며 보간한 기준·위험·진단·점수 필드가 없다.
- 장면은 정적 비교에 적합해 자동재생·타이머를 사용하지 않는다. 직접 시점 선택, 초기화, 모든 관찰 펼치기로 동일 정보를 제공한다.
