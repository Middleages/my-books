# 먹기 D 07–08 모델·시각 계약

관찰한 사실 → 보호자 반응 → 다음 미확인 관찰을 서로 다른 역할 기호와 단계 경계로 연결한다. 반응을 바꾸어도 원인·섭취·점수는 null이다. 자동 재생 없이 이전/다음·초기화와 전체 정적 텍스트를 제공한다.

도구 경험은 제시 원점에서 그릇/도구에 남음·흘림·입으로 향함으로 갈라진다. 양 비율이 아닌 개념 갈래이며 섭취 확인은 별도 점선 경계다. 도구/도움 변경은 능력 판정·안전 인증을 생성하지 않는다. 모바일은 세로 흐름으로 재배치하며 제어와 그림을 인접시킨다.

실제 아이 데이터·임상 영양 계산·자가 재도전·응급 술기는 범위 밖이다.
