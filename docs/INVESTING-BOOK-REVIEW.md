## 현재까지의 독립 점검

기존 소개·01–10의 모델/카탈로그 테스트 169개를 실행했고 모두 통과했다. 기존 MDX의 메모리 내 SSR에서 원시 강조 별표·del·중첩 문단이 없으며 51개 내부 본문 링크가 당시 67개 실제 카탈로그/책 경로에 연결됨을 확인했다. 이 수치는 F 추가 전 점검이며 최종 전체 수치와 실제 브라우저 결과는 F 기록에서 갱신한다.

공식 원문 재확인 범위는 Investor.gov의 Stocks·ETF/NAV·Asset Allocation·Understanding Fees·International Investing, SEC.gov 재무제표 안내, IFRS15·IAS7·IAS33, FINRA 수익 정의, ESMA/2014/937 추적 성과 정의, CBO60815 현재가치, OpenDART 소개, BOK981 강의다. KRX 주문 안내 원문은 여전히 403으로 접근하지 못했으므로 기존 미확인 경계를 유지한다. 계획 당시 접근 실패 기록과 이후 성공한 재확인을 혼동하지 않는다. 미국의 법규·세금·권리일을 한국 현행 제도로 옮기지 않는다.

독립 점검에서 발견한 FX 교차항의 %/%p 표현, 일반 채권의 ‘좌’ 표기, 오래된 공개 장 수와 극소 입력의 수치 표현 문제를 F에서 좁게 보강한다. 기존 다른 책과 읽음 저장 형식은 변경하지 않는다. 신규 F와 통합 이후 독립 검토에서는 500개 테스트 전부, 13개 MDX의 메모리 내 SSR(원시 강조·del·중첩 문단0), 65개 내부 링크와 69개 실제 경로를 확인했다. 별도 수치 대조는 5,000개 이전 정점 경로, 101개 손실률, 6개 고정 규칙 창에서 통과했다. 12장의 분류는 미래 예상과 조건부 현재 평가를 모두 담도록 ‘추정·평가’로 정리하고, 11장의 최대낙폭을 관찰 시점별 낙폭의 최댓값으로 명확히 했다. 실제 화면 관찰·게시 검증은 아직 진행 중이다.
