# 먹기 F 시각·모델 계약

11장: 눈으로 발견할 관계는 동일한 용기도 제공 이력이 다르면 합칠 수 없다는 점이다. 손/도구→날것과 조리된 음식의 분리→소분·보관→인수인계 경계를 번호·화살표와 점선/실선으로 구별한다. 초기 미제공 사례에서도 보관 조건은 미확인이다. 용기 선택은 이력을 바꾸되 안전 판정은 만들지 않는다. 다음 단계와 초기화, 전체 정적 문장 대안을 제공한다.

12장: 사실과 질문의 관계를 실선 관찰/점선 질문으로 구별한다. 질문을 펼쳐도 관찰 원문은 그대로 남고 진단으로 변환하지 않는다. 5개 주제는 점수·횟수가 아니다. 인쇄용 빈 양식은 입력·저장 기능 없이 제공한다.

모바일은 흐름과 대조를 세로 재배치한다. 합성 자료, 영양·안전 판정 없음, 연령·국가·확인일과 근거 한계 분리. 정상/감소 움직임 모두 자동 진행 없음.
