# 돈 첫 권 전체 점검 — 신규 세션 인수인계

현재 상태: 이 인수인계의 점검을 실행했다. 발견·수정·검증·배포 상태는 [MONEY-BOOK-REVIEW.md](MONEY-BOOK-REVIEW.md)에 기록한다. 아래는 당시 작업 지시 원문이다.

사용자 결정(2026-10-18): 10장까지 이번 세션에서 구현·배포하고, 소개·01~10 전체 편집 점검은 **신규 세션**에서 진행한다. 이 문서는 다음 작업 지시이며 전체 점검 완료 기록이 아니다.

## 시작 자료

최신 main의 `AGENTS.md`, `MONEY-TEXTBOOK-PLAN.md`, `CONTENT-AUTHORING.md`, `HOME-INFORMATION-ARCHITECTURE.md`, `MONEY-04~10-VERIFICATION.md`와 돈 소개·01~10 본문, 관련 모델·컴포넌트·테스트를 읽는다. 특정 과거 커밋을 최신 상태 대신 쓰지 않는다. 병행 쿠버네티스·네트워크·홈 변경은 보존한다.

## 점검 범위

1. 처음 읽는 비전공 성인의 순서로 소개·01~10을 읽고 핵심 질문, 용어의 첫 설명, 선수 개념, 연결 링크, 중복과 빠진 설명을 확인한다.
2. 그림·과정·예측·조작·해석·확인 문제·공식 출처의 학습 흐름을 확인한다. 입력 폼·숫자만으로 끝나는 곳, 그림과 모델이 다른 곳을 찾는다.
3. 원/만원, 월초/월말, 명목/실질, 자산/현금/순자산, 수입/이체/소비, 원금/이자, 예정/실제, 목표일 당시/현재 잔액을 일관되게 구분하는지 확인한다.
4. 모델의 생략 조건과 출처 확인일을 검토한다. 실제 금융 제도·상품·세법을 다룬 문장은 최신 공식 자료로 확인한다. 외국 교육 원리를 한국 제도처럼 쓰지 않는다.
5. 특히 10장의 음수 현금은 계획의 자금 부족이며 실제 마이너스 통장·자동 대출이 아니다. 과거 부족 기록, 목표 소비 1회, 이체 보존, 월중 그림/월말 경로 구분이 독자에게 명확한지 확인한다.
6. 모바일·키보드·포커스·정지·초기화·reduced-motion·표와 정적 대안을 점검한다. 자동 검사와 실제 스크린리더·실기기 검증을 구분해 기록한다.
7. 기존 책·URL·readId·읽음 기록·분야·표지를 회귀 확인한다. 새 권이나 과도한 기능 확장은 하지 않는다.

## 결과와 완료 조건

문제별 근거·영향·수정 범위를 기록하고 실제 문제를 고친다. 관련 모델 테스트·빌드·의미 있는 화면 검증을 실행한다. 사용자 요청 범위의 읽기·검증·가역적 수정은 추가 확인 없이 진행한다. 전체 리디자인이나 새 책은 별도 범위다.

`docs/MONEY-BOOK-REVIEW.md`에 발견·수정·남은 문제와 미실행 검증을 남긴다. 계획·공개 범위와 기준 문서를 필요한 만큼 갱신하고 최신 main 병행 변경을 다시 통합한다. main 반영, GitHub Actions·Pages 배포 성공, 실제 게시 버전 확인까지 완료한다.
