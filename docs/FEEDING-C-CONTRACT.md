# 먹기 C 05–06 구현 계약

2026-10-20. 먹기 B 마감8b49592 기반 별도 작업트리. 수면 C 등 다른 권의 후속을 섞지 않는다. 이 기반에 없는 최신 수면 A 안전 문장을 되돌리는 통합을 하지 않고, 게시 담당자가 최신 main에 먹기 변경만 합친다.

05 관계는 제시 기록 안의 섭취 확인/모름이다. 일주일7개 날짜의5개 식품군을 같은 분류로 배치하고 상태 기호·색 역할을 분리한다. 강조는 데이터나 식품 섭취를 바꾸지 않는다. 식품군 빈칸은 결핍도 미섭취도 아니며 식단의 완전한 기록이 아니다. 그림의 식품 이름은 실제 조리 형태·한입 크기 지침이 아니다. 영양 충족률/성장 예측/보충제 추천 없음.

06은 재료→섭취 사실·시각→관찰→전달할 질문을 순서대로 공개한다. 연결은 전달 관계이지 원인 확정이 아니며 진단 앞의 끊긴 경계를 계속 표시한다. 응급 도움 안내는 첫 화면 고정이다. 개인 진단·원인 선정·자가 재도전 계획은 모든 모델 상태에서null. 모름을 정상으로 바꾸지 않는다. 실제 아이 기록 입력/보관/전송, 약물/응급 술기 시뮬레이터 없음.

본문·모델·조작을 분리하고 좁은 화면에서는 날짜/기록 카드가 재배치된다. 키보드 버튼/초기화와 정적 전체 설명을 제공하며 자동재생이 없다. 공식 근거의 국가/검토일을 유지한다. 의학·영양 전문가 감수 미실행. 소스·실제 화면·게시 게이트를 별도로 기록한다.
