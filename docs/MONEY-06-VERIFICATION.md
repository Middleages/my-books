## 화면 실행 환경

Browser 플러그인의 실행 도구는 노출되지 않았다. 로컬 화면 검증에는 저장소 밖의
Playwright Core + npm `@sparticuz/chromium` 패키지 Chromium 153.0.8010.0을 사용했다.
기본 압축 해제 과정에서 `/tmp/fonts`의 chown EINVAL이 발생해 npm 패키지의 같은 바이너리를
Node Brotli + 표준 tar의 소유권 보존 없는 해제로 준비했다. 프로젝트 의존성·lockfile은 변경하지 않았다.
QA 환경의 한글 폰트 부재는 NanumGothic 설치로 해결했으며 사이트에 외부 폰트 의존성을 추가하지 않았다.
Vite와 Chromium을 같은 실행 네트워크에서 시작해 `http://127.0.0.1:5173/my-books/`를 열었다.

검증 명령: `npm test`, `npm run build`, `git diff --check`,
`FONTCONFIG_PATH=/etc/fonts node /tmp/my-books-06-qa/verify.mjs`.
스크립트는 UI 조작 뒤 DOM과 계산값을 확인하며 스크린샷과 axe 결과를 저장했다.

## 모바일·reduced-motion

Chromium viewport 390×844 / 320×844, `prefers-reduced-motion: reduce`로 실행했다.

- 비교 그림·날짜·판정 패널이 세로 배치되며, 주요 라벨은 HTML 텍스트 크기를 유지한다.
- 목표일 보기, 처음부터, 단계 진행, 재생·정지 및 전체 표 열기 조작을 실행.
- 일반/표 열림/최대 노출 입력 모두 문서 scrollWidth가 각각 390/320px로 뷰포트와 같음.
- 최대 노출 입력: 준비금 200만원 전액 묶임, 매월 30만원, 목표 300만원,
  목표일 24개월·풀림 36개월. 37개 월별 이동 버튼과 그래프·표 정상 렌더.
- reduced-motion에서 재생 중에도 CSS animation이 none이며 같은 단계·판정·정적 정보가 보존됨.
- 모바일 그림·구성 막대·그래프와 큰 금액 축 라벨을 스크린샷으로 검토.

실제 휴대기기 터치·Safari/WebKit·OS 설정 변경·스크린리더 실행은 미검증이다.
뷰포트/미디어 에뮬레이션을 실제 기기 검증으로 보고하지 않는다.
