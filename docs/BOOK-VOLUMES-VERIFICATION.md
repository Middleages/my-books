# 분야별 권차 표시 검증

작성일: 2026-10-20 KST. 최초 구현 기준 소스: 보험 E `246167308c050d797d00501fb057e2ea61de51b4`. 아래 PR 검증은 세금 A와 결합한 후보이며, 게시 완료를 뜻하지 않는다.

## 구현 범위

- 카탈로그의 필수 `volume`은 분야별로 중복하지 않는 양의 정수다. 컴퓨터·네트워크·쿠버네티스는 IT·기술 1·2·3권, 돈·경제·투자·보험은 돈·경제 1·2·3·4권이다.
- `bookVolumeLabel`이 분야 이름과 명시적 권차로 홈 카드·책 소개 헤더의 같은 라벨을 만든다. 표지에는 글자를 추가하지 않는다.
- 읽는 중 우선·동일 상태의 기존 카탈로그 순서를 유지한다. 홈 안내에서 권차가 권장 학습 순서임을 밝힌다. 분야별 필터 숫자는 공개 책 수로 유지한다.
- 미구현 책을 카탈로그에 추가하지 않는다. 최초 권차 단독 패치에서 예약한 세금·데이터베이스는 공개할 때 각각 돈·경제 5권·IT·기술 4권을 명시해야 한다. 아래 통합 PR 후보에는 구현한 세금 01–02와 세금 5권 메타데이터가 포함됐다.
- URL·chapterId·readId·저장 키·알 수 없는 읽음 ID·표지·교재 본문·실험은 변경하지 않는다.
