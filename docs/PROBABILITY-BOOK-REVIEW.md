## 앞선1–7권과의 경계

## 모형과 표시의 공통 계약

- 실제 금융 데이터·개인정보·외부 API·추천 없음. 기록은 가상 관측, 확률은 교육 가정, 결과는 조건부 산술로 표시한다.
- 통계·도형·정적표·판정은 순수 모델과 관찰 프레임을 공유한다. 0/null/미실행/미관측/정의불가를 구별한다. 단위·기간·조건부 분모를 가까이 둔다.
- 금액·확률·건수·비중의 축을 섞지 않는다. 비교축·bin폭·반올림과 작은 확률의 비영 여부를 명시한다. 막대 수나 애니메이션 속도를 실제 표본/위험처럼 꾸미지 않는다.
- seed는 고정이며 기록을 원하는 결론으로 다시 뽑지 않는다. E의 극단적 최초1등을 전형적인 표본이라고 하지 않는다. F는 seed없는 전수 열거다.
- CI/PI/민감도, 상관/독립/인과, 생존/선택/보류 재사용, 기대값/꼬리/유동성/첫 실패를 각 장의 반례로 보존한다.
- 모바일 재배치·인접 제어·키보드·포커스·단계/정지/reset/unmount·reduced-motion·전체 정적 자료를 제공한다. 자동 시작·카지노형 추첨 없음.
- 예약chapterId/readId12개·volume8·money분야·기존 저장키·알 수 없는 읽음ID 보존. 소개와등록 분모12를 일치시키고 다른 책/홈정보구조를 바꾸지 않는다.
