# 육아 4권: 감정과 관계를 배우는 시간

작성·자료 확인일: 2026-10-20. 상태: A 소개·01–02 소스에 이어 B 03–04 로컬 구현. B 실행 검증과 원격 게이트는 EMOTIONS-BATCH-B-VERIFICATION.md를 따른다. 05–12는 계획이며 공개 등록하지 않는다. 전문가 감수 미실행.

## 목적·독자
0–36개월 아이를 돌보는 비전공 성인을 위한 관계·정서 입문. 핵심 질문은 “아이의 마음을 단정하지 않으면서 안전한 경계를 세우고 다시 연결하려면 무엇을 볼까?”다. 0–12개월 비언어 돌봄, 12–23개월 환경·짧은 안내, 24–36개월 언어·선택 사례를 구분한다. 이는 발달 합격표가 아니다.

1권의 발달 관찰, 2권의 수면, 3권의 먹이기를 반복하지 않고 감정과 상호작용에 집중한다. 6권의 돌봄 분담·어린이집 제도는 짧은 연결만 둔다.

제안: categoryId parenting / volume 4 / bookId child-emotions. 소개는 범위·사용법·자료 연령·상담 경계를 안내한다. 아래 12장은 서로 다른 학습 질문을 기준으로 나눴다. 구현 전 근거 또는 내용이 중복되면 통합하고, 12장을 채우기 위한 내용을 추가하지 않는다.

## 소개 + 12장

### 01 감정과 행동을 나누어 보기 — feelings-and-actions
질문·학습 목표: 감정의 존재와 행동의 허용 범위를 구분해 설명할 수 있다.
관계 그림: 사람 실루엣 안의 감정 말풍선과 바깥 행동 경계를 분리한다. 화남 표시는 남고 다치는 행동 경로만 막힌다.
조작·모델: 같은 가상 장면에서 감정 이름/관찰된 행동/추측을 구분한다. 감정을 바꿔도 안전 경계는 유지한다.
반례·한계: 표정 하나로 마음을 읽거나, 울지 않는 아이를 더 잘 조절하는 아이로 평가하지 않는다.
대상·근거: 전 연령의 보호자 개념; 언어 장면은 24–36개월 / E1·E2.

### 02 곁에서 함께 진정하기 — co-regulation
질문·학습 목표: 공동조절을 아이에게 혼자 참게 하는 훈련과 구분한다.
관계 그림: 아이의 신호와 보호자 응답의 양방향 연결, 소음·빛·돌봄 환경의 바깥 층. 연결선은 상호작용이지 진정 성공 확률이 아니다.
조작·모델: 0–12개월 합성 장면에서 관찰→필요 살피기→안전한 반응의 순서를 진행한다. 화면은 예정된 관찰 사실만 바꾼다.
반례·한계: 안으면 반드시 울음이 멎는다는 결과를 만들지 않는다. 울음의 원인을 감정만으로 축소하지 않는다.
대상·근거: 0–36개월; 영아 예시 별도 / E3.

### 03 신호를 보고 말을 보태기 — noticing-signals
질문·학습 목표: 관찰과 감정 추측을 구분하고 수정 가능한 말로 표현한다.
관계 그림: 관찰 사실은 실선, 잠정 해석은 점선. 아이의 다른 반응이 오면 해석이 교체되지만 처음 관찰은 남는다.
조작·모델: 관찰/가설/미확인을 골라 같은 장면의 해석을 비교한다. 아이가 말로 교정할 수 없는 장면도 유지한다.
반례·한계: 눈맞춤이나 특정 표정을 의무로 만들지 않는다. 말하지 않는 아이에게 감정 단어 시험을 하지 않는다.
대상·근거: 24–36개월 언어 코칭, 영아는 비언어 반응 / E1·E3.

### 04 편안한 때 연습하는 감정 말 — emotion-language
질문·학습 목표: 진정 전 안전 확보와 진정 후 대화를 구분한다.
관계 그림: 시간 흐름에서 즉시 안전·기다림·나중 대화를 서로 다른 영역에 놓는다.
조작·모델: 가상 아이가 대화에 참여 가능한지에 따른 설명 위치만 바꾼다. 고정된 진정 시간 타이머는 없다.
반례·한계: 힘든 순간에 감정 이름을 맞힐 때까지 질문하거나 대답을 강요하지 않는다.
대상·근거: 24–36개월에 해당하는 2–4세 자료의 일부만 적용 / E1.

### 05 친절하고 분명한 행동 경계 — gentle-boundaries
질문·학습 목표: 감정을 인정하면서도 다치게 하는 행동은 제한할 수 있음을 설명한다.
관계 그림: 아이·상대·물건의 위치와 안전한 대체 행동 경로. 거절 문장 카드만 바뀌는 UI 대신 이동 가능한 범위를 비교한다.
조작·모델: 동일 장면에서 환경 조정/짧은 안내/안전한 대안을 선택하고 각각의 역할을 확인한다.
반례·한계: 식사·돌봄·애정을 벌로 박탈하지 않는다. 체벌·위협·수치주기·강압·영아 방치 전략을 제안하지 않는다.
대상·근거: 영아는 환경 조정 중심, 유아는 이해 가능한 짧은 안내 / E2.

### 06 큰 감정이 지나가는 동안 — intense-emotions
질문·학습 목표: 즉각적인 안전과 나중에 배울 기회를 분리한다.
관계 그림: 사람 간 거리·위험 물건·보호자 도움 연결을 고정 장면에서 표시한다. 감정의 크기를 점수 게이지로 만들지 않는다.
조작·모델: 가상 관찰에서 지금 확인할 안전 정보와 나중 대화할 질문을 분류한다.
반례·한계: 모든 울음·몸부림이 떼쓰기라는 판단 금지. 통증·질병 등 가능성을 배제하거나 상담 필요를 숨기지 않는다.
대상·근거: 24–36개월 사례 중심; 영아 울음 대응으로 복사하지 않음 / E1·E2.

### 07 기질을 고치는 대신 맞추기 — temperament-and-fit
질문·학습 목표: 아이의 반응 차이와 환경의 요구를 함께 살펴볼 수 있다.
관계 그림: 낯선 공간·소리·접근 속도의 환경 층과 관찰된 반응을 나란히 표시한다. 좋은/나쁜 기질 축은 없다.
조작·모델: 같은 아이의 합성 관찰을 유지한 채 환경 조건 하나만 변경한다. 달라진 요구를 설명하되 실제 행동 결과를 예측하지 않는다.
반례·한계: 기질 유형 검사·애착 점수·자폐/ADHD 추정 금지. 한 번의 반응으로 고정 성격을 정하지 않는다.
대상·근거: 0–36개월 보호자 관찰; 유형별 개입 근거 추가 확인 / E3; 개별 기질 권고 미확인.

### 08 헤어짐과 다시 만남 — separation-and-reunion
질문·학습 목표: 분리 상황의 예고·인계·재회를 하나의 과정으로 본다.
관계 그림: 보호자·아이·돌봄자 사이의 인계선과 재회 위치. 울음 길이가 아닌 누가 돌보는지가 드러난다.
조작·모델: 합성 일정에서 익숙한 돌봄자/인계 확인/재회 약속을 확인한다. 실제 위치나 시간 입력은 없다.
반례·한계: 몰래 사라지기나 울음을 애착 실패로 해석하지 않는다. 적응 완료일을 계산하지 않는다.
대상·근거: 영유아 일반 안내; 개인 경과와 월령은 달라질 수 있음 / E4.

### 09 하던 일을 마치고 다음으로 — transitions-and-routines
질문·학습 목표: 전환의 어려움을 고집 하나로 설명하지 않고 예고·환경·도움으로 나누어 본다.
관계 그림: 현재 활동과 다음 활동 사이 연결 다리, 예고와 도움의 위치를 표시한다.
조작·모델: 같은 일과에서 예고/도움 제공 여부를 비교하고 바뀐 정보의 양을 관찰한다. 순응률을 계산하지 않는다.
반례·한계: 모든 아이에게 같은 카운트다운·시간표를 강요하지 않는다. 영아에게 선택지 협상을 요구하지 않는다.
대상·근거: 유아 사례 중심; 영아는 돌봄자 준비 / E2; 세부 전환 방법 후속 확인.

### 10 함께 놀며 관계 배우기 — playing-together
질문·학습 목표: 같은 공간에서 놀이하는 것과 능숙하게 양보하는 것을 구분한다.
관계 그림: 장난감·아이·어른의 위치와 접근 경로, 도움 제공 지점을 보여 준다.
조작·모델: 가상 갈등에서 관찰 사실/안전 경계/제공할 도움을 분리한다. 강제 양보의 보상 점수는 없다.
반례·한계: 나눠 주지 않는 행동을 이기적인 성격으로 판단하거나 포옹·사과·접촉을 강요하지 않는다.
대상·근거: 12–36개월; 세부 또래 발달 기대는 추가 근거 확인 / E2·E3.

### 11 어긋난 뒤 다시 연결하기 — repairing-connection
질문·학습 목표: 실수 인정·책임·다음 행동을 구분하고 관계 회복을 즉시 용서받기로 착각하지 않는다.
관계 그림: 갈등 이전/직후/나중 장면을 나란히 두고 어른의 행동 수정 경로를 강조한다.
조작·모델: 합성 보호자 문장에서 변명/책임 인정/구체적인 다음 행동을 분리한다.
반례·한계: 아이에게 어른을 달래거나 용서·안아 주기를 요구하지 않는다. 반복되는 폭력을 사과로 상쇄하지 않는다.
대상·근거: 0–36개월 보호자의 행동 중심 / E2.

### 12 우리 집의 관찰과 도움 계획 — observation-and-support
질문·학습 목표: 잘잘못 점수 대신 관찰·환경 조정·도움 요청을 정리한다.
관계 그림: 관찰 사실, 모르는 점, 보호자 지원, 상담 질문의 네 영역. 화살표는 정보 전달만 뜻한다.
조작·모델: 합성 사례로 다음에 살필 질문을 고르고 인쇄용 빈 양식을 본다. 실제 개인정보 저장 없음.
반례·한계: 체크 개수로 정상/문제·진료 긴급도를 판정하지 않는다. 지속적 우려는 전문가와 논의할 질문으로 남긴다.
대상·근거: 0–36개월; 의료 판단 제외 / E3·E2.

## 4권 정확성 경계
감정·관찰 행동·보호자의 해석을 분리한다. 공동조절은 아이를 조종하거나 일정 시간 내 진정시키는 알고리즘이 아니다. 체벌·수치주기·위협·강압·필수 돌봄 박탈을 대안으로 제안하지 않는다. 아이의 기질·애착·발달·정신건강 점수 및 진단 출력 금지. 언어와 선택을 사용하는 장면은 이해 가능한 유아 사례로 제한하고, CDC 2–4세 자료를 0–23개월에 확대하지 않는다. 도움을 구하는 보호자를 실패로 묘사하지 않는다. 관계 회복은 반복 폭력의 면죄부가 아니다.

## 공통 시각·모델·검증 계약
- 장별 질문 → 관찰 가능한 관계 → 형태·위치·경계 → 바꿀 조건/고정 조건 → 모델 상태 → 정적 대안을 순서대로 설계한다. 첫 화면부터 비교가 드러나야 한다. 같은 카드 안 문장 교체만으로 관계를 대신하지 않는다.
- 모든 사례는 자체 작성한 합성 사례다. 실제 아이·보호자의 이름, 사진, 의료 기록, 주소, 연락처를 입력·저장·전송하지 않는다. 선택값은 교육 장면의 상태이며 실제 사람의 평가가 아니다.
- `scenarioId / ageBand / sourceIds / observedFacts / hypotheses / unknowns / step / selectedOption`을 UI 독립 모델로 관리한다. 같은 관찰 프레임에서 그림·라벨·해설·정적 표를 읽는다. 추측을 사실로 승격하거나 미확인을 거짓/0으로 치환하지 않는다.
- source별 `publisher / title / url / checkedAt / country / targetAge / reviewedScope / limitations / chapterIds`를 남긴다. 자료의 대상 연령·국가·조건 밖으로 권고를 자동 확장하지 않는다. 원문·사진·도표를 복제하지 않고 자체 설명과 그림을 쓴다.
- 320·390·850·1440px에서 관계를 재배치하고 주요 라벨 글자 크기를 유지한다. 선택과 결과는 인접하게 둔다. 색+형태+직접 라벨을 병행하고 키보드·명확한 포커스·읽을 수 있는 결과를 제공한다.
- 자동재생 금지. 단계 진행/정지/초기화로 관찰한다. reduced-motion과 정적 전후 그림에서도 같은 사실·불확실성·한계를 전달한다. 타이머 정리와 재실행의 멱등성을 테스트한다.
- 신규 본문은 `src/content/<bookId>/*.mdx`, UI는 `src/components/<bookId>/`, 합성 시나리오 모델은 `src/simulations/<bookId>/`. 외부 내용이나 입력을 실행 가능한 MDX로 평가하지 않는다.
- 이후 구현 시 전체 unit/build, 영향 장 실제 렌더, 콘솔·링크·읽음 회귀, 최초 등록/마감 넓은 회귀를 수행한다. 기능 통과와 그림 설명력은 별도 판정한다. 원본 캡처를 직접 열고 관계·반례·오해 가능성을 검토한다.
- `categoryId: parenting`, 명시적 volume과 bookId는 제안일 뿐이다. 구현 전 중복 확인. 기존 URL·chapterId·readId·`my-books:read:v1`·알 수 없는 읽음 ID를 보존한다. 계획된 장을 카탈로그·홈·읽음 분모에 미리 넣지 않는다.
- 검증 기록에는 기준 SHA·실행 명령·환경·관찰·실패/미실행을 구분한다. 소프트웨어 테스트는 의학적 유효성이나 전문가 감수의 대체가 아니다. 원격 반영·배포는 별도 승인과 직렬 게시 담당의 실제 배포 확인이 필요하다.
