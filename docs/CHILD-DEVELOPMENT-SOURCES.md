# 근거·한계·검증 기록

확인일 2026-10-20. 이 문서는 자료 검토 범위를 기록하며 의학 전문가 감수 완료를 뜻하지 않는다.

## 확인한 공개 1차 자료
- CDC 연령별 자료 안내: https://www.cdc.gov/act-early/milestones/ — 2/4/6/9/12/15/18/24/30/36개월 등의 탐색 시점, 표준 선별 대체 불가 및 우려/능력 소실 시 상담 안내 확인. 한국 국가검진 일정으로 전용하지 않는다.
- CDC 관찰과 선별 구분: https://www.cdc.gov/act-early/about/developmental-monitoring-and-screening.html — 페이지 열람. 책에서는 관찰과 전문 절차의 역할 구분 근거로만 사용.
- CDC 우려 시 행동: https://www.cdc.gov/concerned — 보호자 우려를 진료에서 공유하도록 하는 원칙 확인. 미국의 서비스 연락 경로는 한국 독자에게 그대로 이식하지 않는다.
- AAP 교정연령: https://www.healthychildren.org/English/ages-stages/baby/preemie/pages/Corrected-Age-For-Preemies.aspx — 2018 업데이트 자료의 계산 설명과 초기2년 발달 해석 범위를 확인. 오래된 자료임을 표시하고 실제 도구별 지침을 재확인해야 한다.
- AAP 놀이 안내: https://healthychildren.org/English/family-life/power-of-play/Pages/default.aspx — 놀이 주제 범위와 후속 근거 탐색 출발점. 개별 놀이의 안전성과 연령별 효과를 이 목록 페이지만으로 검증했다고 주장하지 않는다.

## 한국 자료 확인 한계
- NHIS 2024 영유아 검진 안내 PDF: https://www.nhis.or.kr/static/html/wbma/c/wbhaca04800_2024.pdf — 문서 접근 성공. 검색 결과에서 검진 안내 존재를 확인했지만 추출 문자 손상으로 전문 세부내용의 완전 검증은 하지 못했다. 2026 최신 일정/제도라고 단정하지 않고 본 계획에 구체 검진 회차·시기표를 싣지 않았다.
- KDCA K-DST 개정판 사용지침서 게시물: https://www.kdca.go.kr/board/board.es?act=view&bid=0019&list_no=138033&mid=a20507010000 — 검색 결과 존재 확인, 본문 접근404. 최신판·전문·재사용 조건 미확인. 구현 전 현행 공식 경로를 찾아 검토해야 한다. 척도 문항/점수표 복제 및 자체 판정은 계획 범위 밖이다.
- 과거 NHIS 2014/2017 안내는 최신 검진 근거로 사용하지 않았다.

## 작성 기준
저장소 AGENTS.md, CONTENT-AUTHORING.md, HOME-INFORMATION-ARCHITECTURE.md를 읽고 그림 중심 설명, 단일 상태 모델, 모바일 인접 조작, 정적 동등성, 카테고리 권차·읽음 보존을 적용했다. 최초 계획은 전달용 디렉터리에 작성했다. 현재는 승인된 전용 작업 브랜치와 draft PR #38에 반영했으며 다른 진행 중 작업을 보존한다. 앱 등록은 작업 브랜치에 한정되며 main/Pages 게시는 아직 완료하지 않았다.

## 2026-10-20 구현 착수 상태

사용자가 첫 권 계획 문서 반영과 구현 시작·배포를 승인했다. 이 승인은 구현이나 의학 검토가 완료됐다는 뜻이 아니다. 소개·01–02부터 순차 제작하며 본문·원출처·모바일 화면 검증 뒤 기존 게시 담당과 직렬 통합한다. 계획·A 소스는 draft PR #38에 반영했으며 작업 브랜치에 앱을 등록했다. main/Pages 게시 완료가 아니다. 최신 실제 검증은 CHILD-DEVELOPMENT-BATCH-A-VERIFICATION.md를 따른다.

## 후속 한국 제도 근거 탐색 (2026-10-20)

- 질병관리청 국가건강정보포털의 [건강검진(국가건강검진)](https://health.kdca.go.kr/healthinfo/biz/health/gnrlzHealthInfo/gnrlzHealthInfo/gnrlzHealthInfoView.do?cntnts_sn=6671) 본문 접근 및 2026-06-01 업데이트 표시를 확인했다. 영유아 검진의 성장·발달 점검 목적과 공단 안내 경로의 후속 확인 출발점으로 보존한다. 이 페이지 접근이 K-DST 지침서 전문·현행판·재사용 조건 검증을 대체하지 않는다.
- K-DST 개정판 기존 KDCA 게시물은 검색 결과에 남지만 재열람에서도 오류가 발생했다. 비공식 복사본을 현행 공식판으로 간주하지 않으며 재사용 권한을 추정하지 않았다.

## C의 소통·상호작용 근거 (2026-10-20)

### D 07–08 확인 (2026-10-20)
CDC 2/4/6/9개월과 1세 원문(각 장 링크)을 직접 확인했다. 08은 각 원출처에서 두 예만 자체 요약하며 0–12 월별 기준이나 전체 검사표를 만들지 않는다. 발췌가 없는 영역은 자료 범위의 빈칸이며 능력 부재가 아니다. 12개월 source/예는 단일 모델에 두어 후속 경계에서 재사용한다. CDC 6/9개월 놀이 안내와 AAP toy safety(2024-12-19)로 07의 개념·안전 범위를 확인했다. AAP 놀이 페이지 한 주소는 오류였으며 근거에 포함하지 않았다. K-DST 현행판·재사용 조건과 임상 감수는 여전히 미완료다.

### E 09–10 확인 (2026-10-20)
CDC 15/18/30개월 및 2/3세 원문을 직접 확인했다(각 장 링크). 각 연령 두 예만 자체 요약하고 단어 수·반응 시간·전체 체크리스트·점수를 제외했다. 12/24개월은 단일 원출처 객체와 같은 발췌를 구간 경계에서 재사용한다. 13/21/27/33개월 기준은 만들지 않는다. 30개월의 가상 놀이와 다른 아이 곁/함께 놀기, 36개월의 놀이 참여/질문은 각각 해당 원출처 연령에만 붙인다.
