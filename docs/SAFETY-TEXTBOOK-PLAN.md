# 육아 5권: 안전과 도움을 요청하는 법

작성·자료 확인일: 2026-10-20. 상태: 계획 초안. 본문 구현·앱 등록·원격 게시·전문가 감수 미실행.

## 목적·독자
0–36개월 아이의 보호자가 위험을 아이의 부주의로 돌리지 않고 환경·제품·관찰·돌봄 인계를 함께 살피도록 돕는다. 핵심 질문은 “무엇을 미리 바꾸고, 무엇은 혼자 판단하지 말고 도움을 구해야 할까?”다. 의료 처치 교본이나 실시간 응급 분류기가 아니다.

2권 수면 안전·3권 식사 안전은 최신 합의된 장으로 연결하고 중복 처방하지 않는다. 이 권은 집 안 위험 경로, 이동, 물, 열, 중독 예방, 진료 정보 준비와 전문 도움 경계에 집중한다. 수치 기준과 응급술기는 근거가 확인되어도 별도 전문 검토 없이 넣지 않는다.

제안: categoryId parenting / volume 5 / bookId child-safety. 소개는 범위·사용법·자료 연령·상담 경계를 안내한다. 아래 12장은 서로 다른 학습 질문을 기준으로 나눴다. 구현 전 근거 또는 내용이 중복되면 통합하고, 12장을 채우기 위한 내용을 추가하지 않는다.

## 소개 + 12장

### 01 안전은 아이의 주의력만이 아니다 — safety-layers
질문·학습 목표: 환경·제품·관찰·도움 요청의 역할을 구분한다.
관계 그림: 합성 집 단면에서 위험원·접근 경로·보호 장벽·돌봄자의 위치를 별도 층으로 표시한다.
조작·모델: 같은 방에서 물건 위치 하나를 바꿔 접근 경로만 비교한다. 사고 발생 확률은 계산하지 않는다.
반례·한계: 위험요소 체크 완료가 안전 보증은 아니다. 보호자 비난이나 사고 재현 보상 게임 금지.
대상·근거: 0–36개월; 통계 자료는 0–5세로 구분 / S1·S4.

### 02 아이의 이동이 바꾸는 집 — reach-and-movement
질문·학습 목표: 뒤집기·기기·서기 등 새 움직임에 따라 다시 살필 곳이 달라짐을 이해한다.
관계 그림: 높이 숫자가 아닌 이동 가능한 바닥·가구·창가의 연결과 끊김을 표시한다.
조작·모델: 가상 이동 상태와 가구 배치를 변경해 새로 연결된 경로를 찾는다. 특정 월령에 기술을 강제하지 않는다.
반례·한계: 어제 못 올라갔다고 오늘도 접근하지 못한다고 단정하지 않는다. 임의 난간 간격·높이 안전 기준 금지.
대상·근거: 개별 이동 능력에 따른 0–36개월 보호자 점검 / S1·S4.

### 03 추락·끼임·넘어짐 살피기 — falls-and-entrapment
질문·학습 목표: 높은 곳·가구·문 주변의 서로 다른 위험을 설명한다.
관계 그림: 기저귀 교환 공간과 창가·문 틈의 위치 관계를 자체 단면으로 비교한다.
조작·모델: 위험원 접근을 줄이는 배치를 선택하고 남는 확인 항목을 표시한다.
반례·한계: 추락 높이·충격 슬라이더로 부상 정도나 집에서 관찰해도 되는지를 계산하지 않는다. 침대 안전 난간을 영아 수면의 보편 해결책으로 제시하지 않는다.
대상·근거: 0–36개월; 수면 공간은 2권 최신 지침과 대조 / S1·S4.

### 04 입으로 탐색하는 시기의 물건 — small-objects
질문·학습 목표: 작은 부품·전지·자석·포장재를 식사 안전과 구별해 관리한다.
관계 그림: 놀이감의 본체/분리 부품/보관함을 분해 그림으로 표시하며 원래 제품 형태는 창작한다.
조작·모델: 가상 방에서 접근 가능한 물건과 확인 안 된 부품을 분류한다.
반례·한계: 입 크기나 물체 크기로 삼켜도 안전하다고 판정하지 않는다. 전지·자석의 자가 처치·기다림·먹이기 절차를 만들지 않는다.
대상·근거: 0–36개월; 식품 질식 예방은 3권 연결 / S4; 국내 품목별 최신 경고 추가 확인.

### 05 물 주변에서는 누가 보고 있나 — water-supervision
질문·학습 목표: 물 접근 제한과 성인 관찰을 서로 대체할 수 없는 층으로 이해한다.
관계 그림: 욕조·물통·물놀이 공간과 관찰 성인의 연결. 인계 전후 담당 표시가 눈에 보인다.
조작·모델: 합성 돌봄 장면에서 맡았다는 말과 실제 인수 확인의 차이를 선택한다.
반례·한계: 얕은 물·목욕 의자·형제자매가 성인 관찰을 대체한다는 표현 금지. 허용 방치 시간·안전 수심 계산 금지.
대상·근거: 영유아 물 주변 예방 / S4; 국내 세부 자료 구현 전 확인.

### 06 뜨거운 것과 닿는 경로 — burn-prevention
질문·학습 목표: 뜨거운 액체·표면·줄을 잡아당기는 경로를 구분한다.
관계 그림: 조리대·컵·전선·아이의 접근선, 닿기/당기기/쏟아짐 가능 경로를 정적 비교한다.
조작·모델: 물건 배치를 바꿔 접촉 경로가 어떻게 달라지는지 본다. 실제 화상 장면은 재현하지 않는다.
반례·한계: 온도×시간으로 화상 등급·처치 여부를 추정하지 않는다. 냉각 시간·약제·민간요법은 확인 없이 안내하지 않는다.
대상·근거: 0–36개월 가정 환경 / S4; 국내 응급처치 세부 절차 보류.

### 07 약·세제·생활화학제품의 자리 — poison-prevention
질문·학습 목표: 잠금·원래 용기·표시·인계가 서로 다른 역할임을 설명한다.
관계 그림: 보관 공간과 일상 음료 공간의 분리, 내용물과 라벨의 연결을 표시한다.
조작·모델: 합성 용기의 라벨 확인/불명/보관 상태를 구분하고 전문가에게 전달할 질문을 찾는다.
반례·한계: 안전마개가 완전 차단을 보장하지 않는다. 삼킨 양·체중으로 독성/응급도·구토 유도·약 용량 계산 금지.
대상·근거: 0–36개월; 개인 중독 처치는 제외 / S4; 식약처 품목별 자료 추가 확인.

### 08 차와 길에서 이동하기 — travel-safety
질문·학습 목표: 제품 사용설명·아이 조건·차량 적합성·탑승 확인을 분리한다.
관계 그림: 자동차 좌석과 카시트 연결 위치, 승하차 전후 확인 지점의 자체 도해.
조작·모델: 가상 사용설명서에서 제품 허용 범위·미확인 정보·차량 설명서 확인을 분리한다.
반례·한계: 국가별 법정 연령/키를 안전 전환점으로 단정하지 않는다. 영상 속 과거 기준을 최신 규정으로 쓰지 않는다. 제품별 고정 각도·벨트 배선은 검증 전 그리지 않는다.
대상·근거: 0–36개월; 국내 제품·규정은 별도 확인 / S3; 현재 카시트 조건 추가 확인.

### 09 집 밖과 화재 대비의 연결 — outside-and-preparedness
질문·학습 목표: 낯선 장소에서도 위험 확인·돌봄 인계·도움 경로가 필요함을 이해한다.
관계 그림: 가상 방문 장소의 출입·집결·도움 연락 연결을 표시하되 실제 피난 경로 판정은 하지 않는다.
조작·모델: 사전 확인 정보와 현장에서 다시 확인할 정보를 나눈다.
반례·한계: 모든 아파트 화재에 무조건 계단/옥상/실내 대기를 지시하지 않는다. 연기·방화문·건물 조건을 생략한 탈출 게임 금지.
대상·근거: 보호자 준비; 영유아 대피 술기 제외 / S2; 국내 장소별 화재 지침 추가 확인.

### 10 진료에 가져갈 질문과 관찰 — preparing-for-care
질문·학습 목표: 관찰된 사실·시각·평소와의 차이·이미 한 조치를 구분해 전달한다.
관계 그림: 합성 사건의 시간 띠와 사실/해석/모름 영역, 의료진에게 전달되는 연결을 보인다.
조작·모델: 가상 기록에서 추정 진단을 빼고 사실과 질문을 정리한다. 실제 진료 기록 입력 없음.
반례·한계: 자료를 다 채우려다 긴급 도움을 늦추지 않는다. 체온·호흡수·증상 점수로 자동 긴급도나 복약을 제시하지 않는다.
대상·근거: 0–36개월; 일반 정보정리 도구 / S5; 소아 진료준비 세부 근거 추가 확인.

### 11 응급 상황에서는 책을 멈추기 — emergency-boundary
질문·학습 목표: 교육 콘텐츠와 실시간 전문 도움의 경계를 이해한다.
관계 그림: 책 화면 바깥의 실제 도움 경로를 별도 영역으로 표시. 학습 완료 버튼과 도움 요청을 혼동시키지 않는다.
조작·모델: 합성 신고 예시의 위치·관찰 상태·연락 가능성 항목을 읽는다. 연결/신고/지도 수행을 실제로 실행하지 않는다.
반례·한계: 전체 응급 신호 목록이나 비응급 보증을 제공하지 않는다. CPR·기도폐쇄 처치의 무검증 게임, 속도·힘 채점, 약물 처방 금지.
대상·근거: 한국에서는 119 도움 경로; 해외는 현지 번호 별도 확인 / S5·S2.

### 12 돌봄자가 바뀌어도 남는 안전 계획 — shared-safety-plan
질문·학습 목표: 환경 점검·담당 인계·연락 준비·전문 교육을 연결한다.
관계 그림: 공간별 점검과 담당자가 교차하는 보드, 확인/미확인/재확인 필요 상태를 문자·형태로 표현한다.
조작·모델: 합성 사례에서 담당자 변경으로 재확인이 필요한 항목을 고른다. 빈 인쇄 양식만 제공한다.
반례·한계: 체크 수로 가정 안전 점수를 주지 않는다. 실제 주소·지병·연락처 입력 및 자동 신고 연동 금지.
대상·근거: 0–36개월 보호자 팀 / S1·S2·S5.

## 5권 정확성 경계
한국 적용을 기본으로 하고 각 자료의 국가와 대상 연령을 표시한다. 법정 최소요건과 제품 사용조건·안전 권고를 섞지 않는다. 위험원 접근 경로를 교육할 뿐 사고·부상·응급도 확률을 산출하지 않는다. 개인 약물 용량·복약 변경·중독 처치·CPR/기도폐쇄 술기 시뮬레이터를 만들지 않는다. 국내 응급 도움은 119로 명시하되 실제 신고를 대신하거나 연결됐다고 표현하지 않는다. 실제 긴급 상황에서는 기록/학습을 끝내도록 요구하지 않는다. 빈 체크리스트는 안전 인증서가 아니며, 미확인 조건을 안전으로 표시하지 않는다.

## 공통 시각·모델·검증 계약
- 장별 질문 → 관찰 가능한 관계 → 형태·위치·경계 → 바꿀 조건/고정 조건 → 모델 상태 → 정적 대안을 순서대로 설계한다. 첫 화면부터 비교가 드러나야 한다. 같은 카드 안 문장 교체만으로 관계를 대신하지 않는다.
- 모든 사례는 자체 작성한 합성 사례다. 실제 아이·보호자의 이름, 사진, 의료 기록, 주소, 연락처를 입력·저장·전송하지 않는다. 선택값은 교육 장면의 상태이며 실제 사람의 평가가 아니다.
- `scenarioId / ageBand / sourceIds / observedFacts / hypotheses / unknowns / step / selectedOption`을 UI 독립 모델로 관리한다. 같은 관찰 프레임에서 그림·라벨·해설·정적 표를 읽는다. 추측을 사실로 승격하거나 미확인을 거짓/0으로 치환하지 않는다.
- source별 `publisher / title / url / checkedAt / country / targetAge / reviewedScope / limitations / chapterIds`를 남긴다. 자료의 대상 연령·국가·조건 밖으로 권고를 자동 확장하지 않는다. 원문·사진·도표를 복제하지 않고 자체 설명과 그림을 쓴다.
- 320·390·850·1440px에서 관계를 재배치하고 주요 라벨 글자 크기를 유지한다. 선택과 결과는 인접하게 둔다. 색+형태+직접 라벨을 병행하고 키보드·명확한 포커스·읽을 수 있는 결과를 제공한다.
- 자동재생 금지. 단계 진행/정지/초기화로 관찰한다. reduced-motion과 정적 전후 그림에서도 같은 사실·불확실성·한계를 전달한다. 타이머 정리와 재실행의 멱등성을 테스트한다.
- 신규 본문은 `src/content/<bookId>/*.mdx`, UI는 `src/components/<bookId>/`, 합성 시나리오 모델은 `src/simulations/<bookId>/`. 외부 내용이나 입력을 실행 가능한 MDX로 평가하지 않는다.
- 이후 구현 시 전체 unit/build, 영향 장 실제 렌더, 콘솔·링크·읽음 회귀, 최초 등록/마감 넓은 회귀를 수행한다. 기능 통과와 그림 설명력은 별도 판정한다. 원본 캡처를 직접 열고 관계·반례·오해 가능성을 검토한다.
- `categoryId: parenting`, 명시적 volume과 bookId는 제안일 뿐이다. 구현 전 중복 확인. 기존 URL·chapterId·readId·`my-books:read:v1`·알 수 없는 읽음 ID를 보존한다. 계획된 장을 카탈로그·홈·읽음 분모에 미리 넣지 않는다.
- 검증 기록에는 기준 SHA·실행 명령·환경·관찰·실패/미실행을 구분한다. 소프트웨어 테스트는 의학적 유효성이나 전문가 감수의 대체가 아니다. 원격 반영·배포는 별도 승인과 직렬 게시 담당의 실제 배포 확인이 필요하다.
