# B 03–04 근거·모델 사전 검토

2026-10-20. A의 전용 소스·화면 게이트 후 전체 회귀 대기 중 공식 자료를 추가 열람했다. B 본문/앱 구현이나 게시를 완료했다는 문서가 아니다.

- NIH/NHLBI https://www.nhlbi.nih.gov/health/sleep-deprivation/body-clock : 깨어 있는 동안 누적되는 수면 압력과 빛/어둠 등 시간 신호를 받는 내부 시계를 구분한 일반 설명. 이를 영아의 정량 곡선·입면 예측·멜라토닌 투약으로 전용하지 않는다. 본문에서 ‘일반 원리, 영아별 계수/성숙 시점 재현 아님’을 표시해야 한다.
- AASM 공식2016 합의문 https://aasm.org/resources/pdf/pediatricsleepdurationconsensus.pdf : 원문PDF 재열람.4–12개월12–16시간,1–2세11–14시간,3–5세10–13시간은24시간/낮잠 포함.4개월 미만은 수치 권고에서 제외. 개인차·의학/행동/환경 요인을 인정하며 하루 합격선이 아니다. 이번 검색에서 같은 범위의 새 대체 합의문을 확인하지 못했으나 그것만으로 이후 개정이 없다고 단정하지 않는다.2016판임을 그대로 적는다.
- 원표현상12개월과1세 범위가 겹친다. 경계에서 하나를 조용히 선택하거나 평균내지 말고 두 원표현과 해석 한계를 함께 보여 주는 것이 안전하다.3세 경계는1–2세와3–5세의 원표현을 보존한다.
- NHS https://www.nhs.uk/baby/caring-for-a-newborn/helping-your-baby-to-sleep/ 는 열람했다. 세부 월령 예시/밤중 수유 내용을 보편적 달성 목표로 쓰지 않는다.

모델 초안:03은 무차원 정성 상태와 시간대 신호를 서로 다른 층으로 보여 주고 분 단위 입면 시각·강제 각성 최적화 없음.04는 연령과 독립된 합성 밤/낮 구성의 합계와 출처 참고표를 별도로 두고, 미확인량이 있으면 정확 총량을 확정하지 않는다. 범위 안/밖을 건강 판정색이나 점수로 만들지 않는다.
