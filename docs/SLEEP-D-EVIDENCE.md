# 수면 D 07–08 근거와 시각 준비

2026-10-20. 수면 C 자체 게이트 마감 후 먹기 C 정상 CI를 기다리는 동안 다음 순환 배치 근거를 준비한다. D 본문·모델·검증·게시 완료를 뜻하지 않는다.

- NHS Soothing a crying baby, https://www.nhs.uk/baby/caring-for-a-newborn/soothing-a-crying-baby/ , 페이지 검토2026-04-22, 영국 보호자 안내. 울음에는 다양한 맥락이 있고 원인을 쉽게 알 수 없을 때가 있다는 일반 설명, 기록이 상담과 추가 지원 계획에 도움을 줄 수 있다는 내용, 아픔/응급 우려 때 도움을 구해야 한다는 경계를 실제 열람했다. 특정 울음 패턴으로 원인/영아산통을 진단하지 않는다. 원문의10분 예시를 울음 방치/수면교육 타이머로 사용하지 않는다. 영국111/999와 영국지원번호를 한국에 그대로 적용하지 않는다.
- AAP Safe Sleep Tips for Sleep-Deprived New Parents, https://www.healthychildren.org/English/ages-stages/baby/sleep/Pages/safe-sleep-tips-for-sleep-deprived-parents.aspx , 업데이트2026-09-13, 미국 신생아/영아 보호자 안내. 수면이 부족한 보호자가 안전한 수면 환경을 유지하고 다른 사람 도움을 받아야 할 수 있다는 설명, 함께 돌보는 사람에게 안전 원칙을 공유한다는 내용을 확인했다. 일반 수면 시간/각성 주기 숫자를 개인 기준으로 사용하지 않는다. 속싸개·공갈젖꼭지 도입·구체 self-soothing 순서/대기 간격은 모델에 추가하지 않는다. 알람이나 영상 시청을 안전 보장 장치로 바꾸지 않는다. 이미 검증된02장의 보호자 취침 전 별도 수면 공간 복귀를 유지한다.

07 모델 초안: 소리만 들음/깬 모습을 확인함/돌봄 뒤 상태를 아직 모름의 합성 기록을 선택한다. ‘확인 사실’ 층과 ‘확인할 맥락(수유·환경·불편)’ 층이 분리되어 있고 질문 강조가 원인값을 바꾸지 않는다. 맥락은 감별진단 체크리스트가 아니며 가능성/확률/습관 판정·수유 중단 조건을 출력하지 않는다. 필요한 돌봄을 우선하고 건강 우려를 기록 완성 뒤로 미루지 않는다.

08 모델 초안: 가족이 선택을 논의할 때의 아이 신호·돌보는 사람의 반응·실행 여건·멈추고 도움 요청할 조건을 병렬로 비교한다. 우선 생각할 조건을 강조하면 관련 상담 질문으로 연결되지만 효과 순위/유일한 정답/애착 결과 예측은 없다. 한 사람이 돌보는 합성 장면과 교대 장면에서 가능한 역할 연결이 달라짐을 보여 준다. 필요한 수유·안전 공간·건강/보호자 피로 경계는 선택으로 끄지 못한다. 구체 수면교육 프로토콜/울음 방치 시간표/개입 효과 수치는 제외한다.

실제 아이·가족 자료 입력·저장·전송 없음. 의학 전문가 감수 미실행. 사용자 선택은 교육 장면의 정보 강조이지 개인의 실행 권고가 아니다.
