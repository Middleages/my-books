## 배치 A 상세 설계

### 01: 작은 거래에서 전체 지도로

가상 한 달, 가계와 빵집 한 곳을 묶은 두 부문. 시작 현금은 각각 20만원·100만원, 노동 10시간, 시간당 1만원, 빵 2천원, 생산성 시간당 5개. 노동과 임금을 같은 거래의 양쪽으로, 빵 인도와 대금도 같은 거래의 양쪽으로 반영한다. 화면의 관찰 단계는 시작 → 노동·임금 → 생산 → 소비·판매 → 결산이다. 실제 경제의 처리 순서나 생산의 유일한 투입이라는 뜻이 아니다.

노동시간 0–20, 희망 구매량 0–100개를 변경한다. 실제 판매는 재고·가계 현금·희망량 중 작은 값(정수 개). 못 산 수량과 이유를 남기고 미실행 구매를 매출로 잡지 않는다. 기업 시작 현금은 최대 임금을 지급할 수 있다. 재실행은 초기값에서 매번 계산한다. 모든 단계에서 두 부문 현금 합 120만원, 생산량=소비량+재고, 가계 임금=기업 임금지급, 가계 소비대금=기업 판매수입을 검사한다. 재고 가치·설비·원가를 생략하므로 현금 합을 총자산/국부로, 판매수입을 이익으로 표시하지 않는다.

돈은 실선·원, 노동/재화는 점선·사각형과 직접 라벨로 구별한다. 단계에 따라 해당 경로를 강조하되 정지 상태에서도 방향이 남는다. 마커는 거래의 표시이며 속도·개수는 금액이 아니다. 정적 전체 표와 한 단계 버튼을 제공한다. 정부·금융·해외는 별도 관계 카드로 위치를 설명하며 계산에 포함하지 않는다.

### 02: 같은 상승, 다른 원인

가상 마을의 같은 품질 빵, 원/개와 개/일. 교육용 직선 곡선: Qd=max(0,120+d−P/50), Qs=max(0,−20+s+P/50). d,s는 가격 외 조건 변화의 개/일 단위 이동량이며 탄력성이나 실제 추정치가 아니다. 실험 범위 d=0–40, s=−40–0에서 양의 내부 균형이 존재한다. 균형 P=3500+25(d−s), Q=50+(d+s)/2.

실험 1은 곡선을 고정하고 가정 가격만 1000–6000원으로 바꾼다. 수요량/공급량을 별개 점으로 표시하고 불일치를 실제 거래량이라고 하지 않는다. 실험 2는 기준 → 조건 변경 → 같은 가격에서 비교 → 새 교점 비교 순서. 수요 증가 d=40과 공급 감소 s=−40은 둘 다 4500원이나 균형수량은 70/30개다. 두 변화 동시 적용은 5500원·50개로, 수량이 그대로여도 조건이 안 바뀐 것은 아니다.

그래프 범위는 모든 비교에서 P=0–8000원, Q=0–160개/일로 고정. 그림·표·점·해설·예측 판정은 모델 반환값을 읽는다. 후속 프레임은 조정 속도 예측이 아닌 비교 관찰 순서다. 소수 계산을 유지하고 표시만 반올림한다. 균형은 사려는 양과 팔려는 양의 일치이며 즉시 도달·복지·공정성의 보장이 아니다. 두 관측만으로 현실 원인을 확정하지 않는다.
