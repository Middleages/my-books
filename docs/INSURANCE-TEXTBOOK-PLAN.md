## 목적·독자·선행 연결

비전공 성인이 “어떤 손실을 내가 남겨 두고, 어떤 손실을 어떤 계약으로 나누며, 돈은 언제 도착하는가?”를 설명하는 책이다. 1권09의 현금·보험·투자 역할을 반복하는 대신 손실의 크기→공동 부담→계약 조건→유지와 해지→청구 시차→설명서 읽기로 깊게 들어간다. 3권의 분산이 남기는 공통 위험과도 연결한다.

구매·판매·개별 보험료 견적·적정 보장액·상품 추천·실제 건강/개인 금융정보·가입·해지 실행을 추가하지 않는다. 세액공제·연금 세제는 세금 권, 확률 추정·통계 추론은 확률 권의 후속 범위다. 공적·직장·개인 보장의 역할을 구분하되 모든 제도를 합산하는 실무 계산기를 만들지 않는다.

## 배치별 고정 설계

### A · 소개·01–02

01: 한 기간의 사건 발생 확률20%·손실100만원과 1%·손실2,000만원. 사건 없으면 손실0. 기대손실은 모두20만원이며 어느 개인의 실제 손실이 평균으로 지급되는 뜻이 아니다. 현금200만원 기본에서 한 번의 충격·부족액을 비교한다. 같은100개 점은 확률 분포의 설명이지 앞으로100번의 결과 보장이 아니다. 현금0·손실0·확률0/1·유한 범위·동일 조건 재실행을 검증한다.

02: 가상20가구가 각10만원을 내 공동재원200만원, 별도 출발 준비금100만원. 가구별 손실100만원, 개별 사례2가구/공통 사례8가구 피해를 고정한다. 두 가구라는 결과 자체가 통계적 독립성의 증거는 아니며 여덟 가구도 현실 발생률 추정이 아니다. 가용300만원, 청구200만원이면 지급200만원/남은100만원. 청구800만원이면 지급 가능300만원/부족500만원이며 제한된 교육모형의 비례배분으로 표시한다. 실제 보험회사가 임의로 비례 삭감한다는 규칙이 아니다. 사업비·위험평가·자본·재보험·지급능력의 필요성을 짧게 연결하고 실제 보험료를 기대손실과 동일시하지 않는다. 재보험은 상대방의 지급 조건/신용 위험을 없애지 않는다.

### B · 03–04

03: 계약자(계약·보험료), 피보험자(보장 대상), 보험수익자(보험금 받을 사람), 보험자(인수·지급 책임)를 역할과 화살표로 분리한다. 한 사람이 여러 역할일 수 있고 보험 종류에 따라 구조가 다름을 밝힌다. 기본계약/특약의 포함 경계와 공적/직장/개인 보장 출처를 구분하며 직장 이동 이후 지속을 가정하지 않는다. 실험은 미리 정한 가상 인물만 사용한다.

04: 총손실500만원−제외100만원−공제50만원=정률 적용 기초350만원. 보험자80%인280만원에 건별한도200만원을 적용하면 지급200만원·본인부담300만원이다. 본인부담은 제외100+공제50+정률70+한도초과80만원. 순서는 이 가상 계약의 정의이며 보편 약관식이 아니다. 정액형은 사건 조건을 만족할 때 약정액을 지급하며 손실배분 띠와 별도로 설명한다. 건별한도200만원·연간총한도300만원 기본에서 같은 청구를 반복하면 첫200만원/둘째100만원/셋째0원이 지급된다. 새 보험연도에만 총한도를 초기화한다. 0·한도0·제외가 손실보다 큰 입력·공제 경계·큰 유한값·반올림을 검증한다.

### C · 05–06

05: 가상 계약 효력 발생일0, 이 담보의 보장개시 전 대기기간30일(0–29 제외; 담보 보장개시30일), 감액기간30–89일(50%), 정상90일부터, 계약 보장 종료일365는 제외(사건일364까지)한다. 사건일과 청구일을 혼동하지 않는다. 보장 사건/제외 조건/날짜 경계를 별개 관문으로 시각화한다. 29/30/89/90 정확 경계·기간 밖·제외·정보 불명확을 검증한다. 고지사항은 실제 질문에 사실대로 답하고 불확실하면 공식 채널에 확인한다는 원리만 설명한다. 자동 승인/거절·건강정보 수집·법적 결론은 만들지 않는다.

06: 동일 대상손실300만원, 같은 손실을 보장하는 두 가상 실손계약 한도300/300만원은 단순화한 명시적 책임배분으로150/150, 합300만원이다. 가상 배분식은 각 적격 계약의 남은한도 c_i에 대해 총지급=min(대상손실,Σc_i), 지급_i=총지급×c_i/Σc_i이며 합0이면 모두0이다. 같으면 균등하고 한 계약만 적격이면 그 계약 한도까지만 지급한다. 한도·제외·자기부담이 다르면 실제 조정식이 달라진다고 명시한다. 한 계약만 보장/양쪽 제외/대상 밖 손실·한도 부족을 비교한다. 정액계약은 별도 조건을 만족한 약정100/200만원의 지급 약속이며 모든 계약의 무조건 중복 지급을 주장하지 않는다. 손실액·실손 합·정액 합을 다른 줄에 두고 실제 보장 공백을 숨기지 않는다.

### D · 07–08

07: 가상12년 관찰, 매년 시작시점0·1·2·3·4년에10만원씩 내는 보험료 납입5년/보장구간[0,10) 계약과 2년마다 갱신하는 별도 계약을 비교한다. 갱신 보험료는 [12,14,17,20,24]만원/년의 고정 가상 표이며 실제 인상률 예측이 아니다. 갱신형은0·1년12만원,2·3년14만원,4·5년17만원,6·7년20만원,8·9년24만원을 각 연도 시작에 내며10년에는 종료되어 납입/보장없음이다. 갱신과 재가입은 조건을 다시 확인할 별개 경계다. 재가입이 언제나 새 건강심사를 뜻하지는 않는다. 5년 납입 종료가10년 보장 종료와 다름을 공통 시간축으로 보인다. 갱신 중단·보장 끝·0시점·연도 경계 검증. 건강상태/세금/연령의 실제 요율은 모델 밖이다.

08: 07의 첫 계약과 같은 납입/보장 가정에서 직접 주어진 경과연도0–9 해약환급금표 [0,2,5,9,14,20,22,24,26,28]만원을 사용한다. 각 연도 값은 그날 예정보험료 납입 직후 즉시해지 금액이다. 연도10은 보장종료 뒤 만기보험금0원이라는 별도 행이며 해약환급금으로 표시하지 않는다. 누적보험료와 환급금은 따로 나타내고 현실 상품을 흉내 낸 역산식을 만들지 않는다. 무/저해약환급형은 보장이 같아 보이더라도 환급 조건이 다를 수 있다는 문서 확인 관점이다. 해지 이후 새 사건의 보장이 끝남을 시간표에 반영한다. 해지 전 사건의 청구권까지 자동 소멸한다고 설명하지 않는다. 해지·청약철회·취소·만기는 개념과 확인 서류가 다르며 현행 기한 숫자는 원문 확인 없이 고정하지 않는다. 표 외 연도·중간 시점 추정/보간을 금지하고 범위를 밝힌다.

### E · 09–10·전체 편집

09: 출발현금100만원, 사고 지출300만원·납기5일, 청구일2일·지급 예정/도착일10일의 가상 현금 시간표. 약관상 지급대상200만원과 당장 사용가능 현금을 분리한다. 납기에는 부족200만원, 도착 후 미충당 지출을 해결해도5일의 부족 이력은 남긴다. 같은 날 사건은 명시적 입금→납기 순서이며 실제 약속일/법정 기한이 아니다. 청구→접수→심사→결정→지급을 관찰하며 추가서류/조사는 필요한 경우의 분기로 표시하고 지연/거절/일부지급은 고정 시나리오로 분리한다. 자료는 가상이며 실제 개인정보·건강서류를 입력하지 않는다.

10: 자체 가상 계약3개(손해 보전형, 사건 정액형, 갱신/환급 조건 포함형)의 짧은 설명서에서 문서에 확인된 약속·계산을 위한 가정·아직 모르는 조건을 분류한다. 확인된 사실은 문서에 약속이 적혀 있다는 뜻이며 실제 청구 승인/수령으로 바꾸지 않는다. 계약별 약속 영역과 손실·날짜·비용·제외의 경계를 펼친 관계도에서 확인된 연결은 실선, 가정은 점선, 미확인 조건은 빈 경계와 물음표로 표시한다. 독자가 사건일 또는 보장대상이라는 가정 하나를 바꾸면 동일 손실 위에 칠해진 조건부 보장 범위가 달라지며, 미확인 조항은 답을 만들어 채우지 않고 확인 질문으로 남긴다. 분류 선택→근거 공개 전후의 변화와 세 계약의 서로 다른 지급 구조를 같은 프레임/정적 표에서 읽는다. 출처와 원문 확인 질문을 연결하고 세 계약 점수·랭킹·구매추천은 하지 않는다. 고지·약관·지급 제한·중복·유지비용·청구시차를 종합한다. 소개·01–10의 용어/단위/법적 범위/실손정액/시점/가상자료·링크·읽음·MDX·모바일을 전체 점검한다.
