# 육아 6권: 함께 키우는 생활

작성·자료 확인일: 2026-10-20. 상태: A–F 소개·01–12 로컬 후보 소스 구현. 원격 공개·화면 검증은 배치별 검증 기록을 따른다. 전문가 감수 미실행.

## 목적·독자
0–36개월 아이의 보호자와 함께 돌보는 성인을 위한 생활 협력 입문. 핵심 질문은 “누가 무엇을 알고 맡으며, 바뀌는 상황에서도 아이와 보호자의 필요를 어떻게 함께 지킬까?”다. 가족에게 책임만 더하는 생산성 교재가 아니라 돌봄 공백·정보·지원 조건을 보이게 하는 교재다.

4권의 감정 조절이나 5권의 응급/안전을 다시 가르치지 않고 어린이집 적응, 동생, 역할 분담, 인계, 다양한 가족, 보호자 휴식에 적용한다. 보육 행정·복지 자격·법적 친권 판단·정신건강 치료는 범위 밖이다.

제안: categoryId parenting / volume 6 / bookId child-family. 소개는 범위·사용법·자료 연령·상담 경계를 안내한다. 아래 12장은 서로 다른 학습 질문을 기준으로 나눴다. 구현 전 근거 또는 내용이 중복되면 통합하고, 12장을 채우기 위한 내용을 추가하지 않는다.

## 소개 + 12장

### 01 아이 곁의 돌봄 팀 — care-network
질문·학습 목표: 가족 호칭과 실제 돌봄 역할은 같지 않음을 설명한다.
관계 그림: 아이 주변의 돌봄·정서 지원·연락·전문 지원 연결을 선 종류와 직접 라벨로 구분한다.
조작·모델: 여러 합성 가족 형태를 바꾸어도 필요한 역할은 남고 맡는 사람만 달라지는 것을 본다.
반례·한계: 두 부모·동거·성별 역할을 기본 정상값으로 두지 않는다. 혈연이 곧 돌봄 권한이라는 판단 금지.
대상·근거: 0–36개월 보호자; 가족 구조별 우열 없음 / F1.

### 02 보이는 일과 보이지 않는 일 — care-work
질문·학습 목표: 실행뿐 아니라 알아차림·준비·확인·마무리의 부담을 구분한다.
관계 그림: 한 돌봄 과제의 네 단계와 담당 연결, 사람별 시간이 아닌 역할의 연결/빈칸을 표시한다.
조작·모델: 합성 과제에서 실행 담당과 계획 담당을 따로 고르고 인수 확인을 살핀다.
반례·한계: 시간을 똑같이 나눈 것이 언제나 공정하다는 점수 금지. 취업/소득/장애 여부로 돌봄 기여를 낮추지 않는다.
대상·근거: 보호자 생활 설계, 임상 효과 주장 없음 / F1; 자체 교육 모형.

### 03 돌봄을 넘길 때 전할 것 — handover
질문·학습 목표: 전달·수신·이해·담당 수락을 구분한다.
관계 그림: 두 돌봄자 사이 정보 묶음과 확인 응답, 확인되지 않은 항목은 점선으로 남긴다.
조작·모델: 합성 수면·식사·컨디션·다음 일정의 사실/추측/미확인을 정리한다.
반례·한계: 메시지를 보냈다고 인수가 끝난 것은 아니다. 약 전달은 처방/기관 절차 밖 임의 복약 안내를 하지 않는다.
대상·근거: 0–36개월; 2·3·5권의 안전 기준 연결 / F1; 자체 정보정리 모형.

### 04 어린이집을 만나기 전 — before-childcare
질문·학습 목표: 기관·돌봄자·가정이 서로 알아야 할 질문을 준비한다.
관계 그림: 가정과 기관의 두 공간, 아이 경험·연락·일과·안전 확인의 연결을 표시한다.
조작·모델: 가상 기관 안내에서 확인된 내용/물어볼 내용/미정 일정을 구분한다.
반례·한계: 등록 적령기·시설 등급·적응 성공률을 계산하지 않는다. 해외 보육 제도를 한국 규정으로 옮기지 않는다.
대상·근거: 0–36개월; 기관별 절차 별도 확인 / F2·F5.

### 05 적응을 관찰하고 함께 조정하기 — childcare-adjustment
질문·학습 목표: 첫날 울음 하나보다 여러 맥락의 관찰과 교사의 설명을 함께 본다.
관계 그림: 등원·돌봄 중·재회의 같은 시간 띠에 알려진 관찰과 빈칸을 표시한다.
조작·모델: 합성 며칠 기록에서 사실과 해석을 나누고 기관에 물을 질문을 만든다.
반례·한계: 일정 일수 안에 울음을 멈춰야 합격이라는 기준 금지. 작은 장난감·수면 애착물을 영아에게 자동 권하지 않는다.
대상·근거: 0–36개월; 개별 적응 기간 보장 없음 / F2.

### 06 다른 방식 사이에서 합의하기 — care-agreements
질문·학습 목표: 안전상 지켜야 할 조건과 조정 가능한 취향을 분리한다.
관계 그림: 공통 안전 경계 안에 서로 다른 일과 선택을 놓고 변경 가능한 영역을 표시한다.
조작·모델: 합성 보호자 의견을 사실/선호/기관 규정/추가 확인으로 분류한다.
반례·한계: 안전하지 않은 행동을 문화나 세대 차이로 정당화하지 않는다. 한 사람을 나쁜 양육자로 채점하지 않는다.
대상·근거: 보호자 간 협력; 4·5권 안전 경계 우선 / F1; 협상 효과 검증 없음.

### 07 동생을 기다리는 시간 — before-new-sibling
질문·학습 목표: 기존 아이의 이해와 가족 일정 변화를 분리해 준비한다.
관계 그림: 아기 도착 전후 생활 공간·돌봄자·함께하는 시간의 변화 지도.
조작·모델: 1–2세와 2–3세 합성 사례를 구분해 설명 가능한 내용과 어른 준비를 선택한다.
반례·한계: 큰아이는 양보해야 한다는 의무나 아기 돌봄 책임을 주지 않는다. 출산·입양 등 가족 형성 방식의 우열 없음.
대상·근거: 자료의 1–2세와 2–4세 구분 중 36개월 이하만 사용 / F3.

### 08 동생과 함께 사는 첫날들 — living-with-sibling
질문·학습 목표: 서로 다른 필요와 성인 보호 책임을 함께 볼 수 있다.
관계 그림: 두 아이 주변의 보호자 연결, 함께 있는 공간과 따로 돌보는 공간을 표시한다.
조작·모델: 합성 장면에서 각 아이의 필요/성인 담당/개별 시간을 구분한다.
반례·한계: 큰아이에게 영아를 맡기지 않는다. 질투나 이전 행동의 재등장을 아이의 잘못으로 낙인찍거나 의학적 변화까지 무조건 적응으로 판단하지 않는다.
대상·근거: 0–36개월 아이와 새 동생을 둔 가정 / F3.

### 09 예정이 어긋나는 날의 대안 — backup-care
질문·학습 목표: 정상 일정과 대체 일정, 연락 가능성과 실제 수락을 구분한다.
관계 그림: 돌봄 공백 구간과 후보→연락→수락의 단계, 미확정 연결을 보여 준다.
조작·모델: 합성 담당자의 부재를 선택하면 비어 있는 역할만 드러낸다. 자동으로 다른 사람에게 배정하지 않는다.
반례·한계: 비상 연락망에 이름이 있다고 언제든 돌볼 수 있다고 가정하지 않는다. 실제 주소/연락처/일정 수집 없음.
대상·근거: 보호자 준비; 질병 등원 기준은 별도 확인 / F1·F5; 자체 계획 모형.

### 10 보호자의 휴식도 계획 안에 — caregiver-rest
질문·학습 목표: 쉬라는 조언과 실제 쉴 수 있도록 돌봄을 넘기는 조건을 구분한다.
관계 그림: 보호자 활동·돌봄 담당·휴식 구간을 겹치지 않는 띠로 나타낸다. 휴식 시간의 질은 점수화하지 않는다.
조작·모델: 합성 일과에 휴식 구간을 놓고 그동안의 돌봄 수락 여부를 확인한다.
반례·한계: 호흡·산책·마음가짐이 구조적 부담이나 질환 치료를 대체한다는 표현 금지. 쉬지 못하는 보호자를 비난하지 않는다.
대상·근거: 보호자 전반; 임상 치료·진단 제외 / F1·F4.

### 11 가족 밖의 도움을 찾는 질문 — finding-support
질문·학습 목표: 지원의 이름·대상·이용 조건·확인 경로를 구분한다.
관계 그림: 가정의 필요와 공공/지역/전문 지원 창구를 조건이 적힌 연결로 표시한다.
조작·모델: 가상 지원 안내에서 지역·대상·비용·운영시간·최신 확인이 필요한 항목을 골라 본다.
반례·한계: 한국 지원 제도의 자격·비용을 미확인 채 고정하지 않는다. 가족 구성이나 자산을 입력받아 자동 자격 판정하지 않는다.
대상·근거: 국내 영유아 양육 가정; 지역별 현행 조건 확인 필요 / F5·F1.

### 12 우리 가족의 한 주를 다시 보기 — family-review
질문·학습 목표: 완벽한 일과가 아니라 빠진 돌봄과 바꿀 한 가지를 찾는다.
관계 그림: 실행/인계/휴식/미확인 네 층의 합성 주간 보드, 변경 전후의 역할 연결을 비교한다.
조작·모델: 이번 주 가상 계획에서 한 가지 변경과 재확인할 질문을 고른다. 인쇄용 빈 양식 제공.
반례·한계: 가족 점수·행복 지수·아이 결과 예측 금지. 실제 사생활·관계 갈등·의료정보 기록 기능 없음.
대상·근거: 0–36개월 돌봄 팀; 모든 가족 형태 포함 / F1·F4; 자체 계획 모형.

## 6권 정확성 경계
가족 다양성을 기본 전제로 하며 엄마/아빠의 성별 고정 역할, 두 부모 가정만 정상이라는 표현, 큰아이의 돌봄 책임화를 금지한다. 돌봄 역할과 법적 보호자/인계 권한은 다르다. 인계 메시지 작성 연습은 합성 사례만 사용하고 실제 발송·개인정보 수집·가족 갈등 점수·자동 자격 판정을 만들지 않는다. 보호자 휴식은 다른 돌봄자의 안전한 인수 조건과 함께 다루며 자기관리만으로 정신건강 문제나 구조적 어려움을 해결한다고 주장하지 않는다. 어린이집 적응 기간을 성적표로 만들지 않는다. UNICEF 보호자 지원 패키지의 독점 훈련·활동을 복제하거나 각색하지 않는다.

## 공통 시각·모델·검증 계약
- 장별 질문 → 관찰 가능한 관계 → 형태·위치·경계 → 바꿀 조건/고정 조건 → 모델 상태 → 정적 대안을 순서대로 설계한다. 첫 화면부터 비교가 드러나야 한다. 같은 카드 안 문장 교체만으로 관계를 대신하지 않는다.
- 모든 사례는 자체 작성한 합성 사례다. 실제 아이·보호자의 이름, 사진, 의료 기록, 주소, 연락처를 입력·저장·전송하지 않는다. 선택값은 교육 장면의 상태이며 실제 사람의 평가가 아니다.
- `scenarioId / ageBand / sourceIds / observedFacts / hypotheses / unknowns / step / selectedOption`을 UI 독립 모델로 관리한다. 같은 관찰 프레임에서 그림·라벨·해설·정적 표를 읽는다. 추측을 사실로 승격하거나 미확인을 거짓/0으로 치환하지 않는다.
- source별 `publisher / title / url / checkedAt / country / targetAge / reviewedScope / limitations / chapterIds`를 남긴다. 자료의 대상 연령·국가·조건 밖으로 권고를 자동 확장하지 않는다. 원문·사진·도표를 복제하지 않고 자체 설명과 그림을 쓴다.
- 320·390·850·1440px에서 관계를 재배치하고 주요 라벨 글자 크기를 유지한다. 선택과 결과는 인접하게 둔다. 색+형태+직접 라벨을 병행하고 키보드·명확한 포커스·읽을 수 있는 결과를 제공한다.
- 자동재생 금지. 단계 진행/정지/초기화로 관찰한다. reduced-motion과 정적 전후 그림에서도 같은 사실·불확실성·한계를 전달한다. 타이머 정리와 재실행의 멱등성을 테스트한다.
- 신규 본문은 `src/content/<bookId>/*.mdx`, UI는 `src/components/<bookId>/`, 합성 시나리오 모델은 `src/simulations/<bookId>/`. 외부 내용이나 입력을 실행 가능한 MDX로 평가하지 않는다.
- 이후 구현 시 전체 unit/build, 영향 장 실제 렌더, 콘솔·링크·읽음 회귀, 최초 등록/마감 넓은 회귀를 수행한다. 기능 통과와 그림 설명력은 별도 판정한다. 원본 캡처를 직접 열고 관계·반례·오해 가능성을 검토한다.
- `categoryId: parenting`, 명시적 volume과 bookId는 제안일 뿐이다. 구현 전 중복 확인. 기존 URL·chapterId·readId·`my-books:read:v1`·알 수 없는 읽음 ID를 보존한다. 계획된 장을 카탈로그·홈·읽음 분모에 미리 넣지 않는다.
- 검증 기록에는 기준 SHA·실행 명령·환경·관찰·실패/미실행을 구분한다. 소프트웨어 테스트는 의학적 유효성이나 전문가 감수의 대체가 아니다. 원격 반영·배포는 별도 승인과 직렬 게시 담당의 실제 배포 확인이 필요하다.
