## 1. 목표와 독자

경제·금융 비전공자가 월급, 소비, 저축, 대출, 투자, 보험, 세금, 주거와 은퇴를
서로 연결해 이해하는 인터랙티브 교과서를 만든다. 용어를 아는 데서 끝내지 않고
“이 숫자는 무엇을 뜻하고, 어떤 조건이 바뀌면 결과가 달라지는가?”를 설명하게 한다.

첫 독자는 월급과 가계 지출을 관리하고 대출·투자를 함께 가진 성인이다.
처음부터 개별 종목·금융상품 선택이나 복잡한 공식 암기를 요구하지 않는다.
한국의 생활 사례를 기본으로 하되, 원리와 한국의 연도별 제도를 구분한다.

학습 흐름은 기존 교과서와 같다.

**그림·짧은 설명으로 개념 이해 → 애니메이션으로 과정 관찰 → 예측·직접 조작 → 결과 해석·실제 적용**

인터랙티브 시뮬레이션, 설명용 애니메이션, 그림을 적극적으로 넣는다. 핵심 개념은
글만으로 설명하지 않고 구조·이동·누적·비교를 눈으로 이해할 수 있는 장면으로 설계한다.
설명과 시각 자료를 함께 집필하며, 계산 결과뿐 아니라 왜 변했는지와 모델의 한계도 보여 준다.

## 3. 전체 시리즈 지도: 기본 6권 + 추가 2권

아래는 가제와 범위다. 8권을 한 번에 구현하거나 미작성 책을 공개된 교재처럼 표시하지 않는다.
첫 권 이외의 장별 목차는 해당 권에 착수할 때 확정한다.

| 권 | 가제 | 독자가 답할 질문 | 다른 권과의 경계 |
| --- | --- | --- | --- |
| 1 | 돈의 기초와 우리 집 재무 | 내 돈은 어디에 있고 어떻게 움직이나? | 각 전문 분야는 입문·연결까지만 |
| 2 | 경제 뉴스를 읽는 원리 | 금리·물가·환율·경기는 어떻게 연결되나? | 가계부 작성이나 종목 예측은 제외 |
| 3 | 주식과 투자 자산의 원리 | 무엇을 소유하고 어떤 위험을 감수하나? | 회계 기초는 요약·링크, 세법 상세는 세금 권 |
| 4 | 보험과 위험 대비 | 어떤 위험을 남기고 어떤 위험을 나눌까? | 투자 수익과 위험 보장을 구분 |
| 5 | 세금의 구조와 생활 | 과세 대상·공제·세율은 어떻게 연결되나? | 연도별 제도·계산 규칙을 별도 관리 |
| 6 | 집과 주거의 경제 | 사거나 빌릴 때 비용·대출·위험은 어떻게 달라지나? | 세금 상세는 연결, 주택 가격 예측은 목표 아님 |
| 7 | 회계와 기업의 돈 | 이익이 나는데 왜 현금이 부족할까? | 투자 권의 재무제표 설명보다 깊게, 가계 재무와 구분 |
| 8 | 확률과 금융 의사결정 | 좋아 보이는 숫자를 어디까지 믿어도 될까? | 투자·보험·경제 전반에 공통인 판단 도구 |

### 추가 2권의 이유

**회계와 기업의 돈**은 매출·비용·자산·부채·현금흐름, 외상매출·재고·설비투자를 연결한다.
주식 투자뿐 아니라 회사의 사업과 성과를 읽는 데도 쓰인다.
대표 실험은 “같은 이익인데 외상매출·재고 때문에 달라지는 현금”이다.

**확률과 금융 의사결정**은 평균·중앙값·분산·상관, 손실 확률과 손실 크기,
조건부 확률·표본·생존자 편향·과적합·백테스트 착시를 생활 금융에 연결한다.
수학 선행 교재로 강제하기보다 필요한 부분을 각 권에서 짧게 소개하고 심화로 연결한다.

### 필요할 때 독립시킬 후보

| 후보 | 현재 배치 | 독립 교재로 나눌 조건 |
| --- | --- | --- |
| 채권·금리·외환 | 첫 권의 원리 소개 + 경제·투자 권 | 만기·신용·듀레이션·환율·환헤지까지 독립적인 학습 흐름이 필요할 때 |
| 연금과 은퇴의 현금흐름 | 첫 권의 생애 계획 + 세금·투자 권 | 적립과 인출, 수익률 순서, 장수·물가 위험을 충분히 다루게 될 때 |

두 후보는 참고 시리즈에 없는 내용이라고 표현하지 않는다. 이미 포함된 주제를 확장·분리하는 선택이다.
책 수를 늘리는 것보다 내용 중복과 편집 부담을 줄이는 것을 우선한다.

## 4. 우리 교과서의 공통 사례

가상의 한 가정이 월급을 받고 생활비를 쓰며 대출을 갚고 투자·보험·은퇴를 준비하는
과정을 여러 권에서 다른 관점으로 읽는다. 특정 가족 형태나 내 집 마련을 정답으로 가정하지 않는다.
주거·소득·부양·고용 형태가 다른 사례도 보조로 제공한다.

| 사건 | 연결되는 학습 |
| --- | --- |
| 월급 입금 | 소득·원천징수·현금흐름 |
| 카드 구매와 결제일 출금 | 소비 시점과 현금 이동 시점, 이중 집계 방지 |
| 계좌 간 이체 | 자산 위치 변화와 수입·소비의 구분 |
| 주담대 원금 상환 | 현금과 부채의 동시 감소, 이자와의 차이 |
| ETF 매수와 배당 | 자산 교환·수익·수수료·세금·환율 |
| 보험료 납입과 보험금 청구 | 비용·보장·위험 이전 |
| 은퇴 후 생활비 인출 | 순자산 규모와 현금흐름 지속성의 차이 |

‘모아’에서 보는 잔액·현금흐름·부채·순자산 변화의 의미를 이해하는 데 연결할 수 있다.
그러나 교과서는 모아 없이도 완결돼야 한다. 이번 범위에 모아 API·실제 계좌 연동·개인 금융정보
입력·외부 저장 기능은 넣지 않고, 기본 실험은 가상 데이터만으로 동작시킨다.

## 6. 첫 구현 배치: 01~03만

다음 세션에서는 첫 권의 소개와 **01 돈의 지도 / 02 돈의 이동 / 03 예산과 목적별 돈**을 만든다.
다른 책·04~10·거시경제·주식 거래·세금 계산기를 동시에 구현하지 않는다.

### 01~02 공통 거래 실험

- 처음에 현금·다른 자산·부채·순자산의 관계를 쉬운 숫자로 설명한다.
- 관계 그림에서 자산과 부채의 차이가 순자산임을 직접 보이게 한다. 합계를 조작하면
  그림의 크기와 수치가 함께 변하고, 음수 순자산도 의미가 왜곡되지 않게 표현한다.
- 급여 입금, 소비, 계좌 이체, 카드 구매/결제, 대출 원금·이자 상환을 한 거래씩 선택한다.
- 독자가 “현금·부채·순자산 중 무엇이 바뀔까?”를 예측한 뒤 결과를 확인한다.
- 거래 전/거래 발생/거래 후를 단계 애니메이션으로 보여 주고, 전후의 잔액·부채·순자산을
  나란히 비교한다. 같은 모델의 표·막대도 함께 제공하며 색만으로 증감을 구분하지 않는다.
- 계좌 간 이체는 한 계좌에서 다른 계좌로 금액이 이동하되 총자산이 보존되는 모습을,
  카드 구매와 결제는 다른 시점에 소비와 채무·현금이 바뀌는 모습을 보여 준다.
- 계좌 간 이체가 수입·소비가 되지 않고, 카드 구매와 결제 때 소비를 두 번 세지 않게 한다.
- 대출 원금 상환은 현금과 부채가 함께 감소한다. 수수료·이자·평가 변동을 제외한 단순 사례에서는
  원금 상환 자체가 즉시 순자산을 늘리지는 않는다는 점을 설명한다.
- 현금흐름과 비용·소비 분류는 별개임을 밝힌다. 생활 가계부의 목적별 기준과 기업 회계 기준을 혼용하지 않는다.

### 03 예산 실험

- 가상의 월급·고정 지출·변동 지출·연간 비정기 지출을 사용한다.
- 월별 달력·현금 잔액 선·목적별 적립 그림을 연동한다. ‘한 달 진행’, 재생/정지,
  처음부터 보기를 통해 돈이 부족해지는 시점을 관찰하고 입력을 바꿔 비교한다.
- 월평균과 실제 월별 출금을 비교해 특정 달의 현금 부족을 확인한다.
- 목적별 적립을 바꾸면 지출 시점에 쓸 수 있는 돈이 어떻게 달라지는지 보여 준다.
- 별도 통장으로 옮긴 것과 새 소비를 구분한다. 적립했다고 돈이 소멸하거나 순자산이 늘지 않는다.
- 비상자금은 고정 개월 수를 모든 사람에게 정답처럼 제시하지 않고 지출·소득 중단 기간 등 가정을 조작한다.

첫 배치의 사례는 순수 소비·현금·카드채무·대출채무에 집중한다. 주택·증권의 평가 변동과
복잡한 할부·중도상환·세법 판정은 가정을 늘리기 전에 후속 장으로 넘긴다.

### 첫 배치의 시각 설명 설계

| 장 | 독자가 그림으로 확인할 핵심 | 시각 자료·상호작용 | 정적·모바일 대안 |
| --- | --- | --- | --- |
| 01 | 자산이 커져도 부채가 같이 늘면 순자산은 그대로일 수 있음 | 자산/부채/순자산 관계 그림, 대출 유입 전후 비교와 짧은 변화 애니메이션 | 직접 라벨을 붙인 세로 비교 그림과 전후 숫자 표 |
| 02 | 같은 현금 감소라도 소비·이체·원금 상환의 의미는 다름 | 거래 경로 그림, 예측 후 단계 진행, 이체/카드/원금/이자 사례 전환 | 거래 전·변화·후의 고정 프레임과 표, 버튼으로 단계 이동 |
| 03 | 월평균 흑자여도 지출 시점에 현금이 부족해질 수 있음 | 일정 표시 달력, 잔액 그래프, 목적별 적립, 한 달 진행·재생/정지·조건 비교 | 월별 세로 목록과 잔액 표, 부족한 달을 직접 표시 |

표는 장면의 기능을 정의한 것이며 최종 화면 배치를 고정한 디자인 시안은 아니다.
다음 세션에서 데스크톱·모바일의 핵심 장면을 먼저 구상한 뒤 본문·모델과 함께 구체화한다.
입력 폼과 결과 숫자만으로 위 장면을 대체하지 않는다.

## 7. 계산과 시각화의 정확성 기준

1. **잔액과 기간 흐름을 구분한다.** ‘월말 순자산’과 ‘이번 달 수입/지출’을 같은 지표로 취급하지 않는다.
2. **납입과 수익을 구분한다.** 계좌 잔액 증가나 순자산 증가 전부를 투자 수익이라고 표시하지 않는다.
3. **원금·이자·수수료·세금을 구분한다.** 생략한 비용이 있으면 가정을 명시한다.
4. **시간·단위를 명시한다.** 월/연 금리, 단리/복리, 납입 시점, 세전/세후, 명목/실질,
   원/만원과 원화/외화를 구분한다. 연이율의 월 환산 방식은 정의 없이 섞지 않는다.
5. **반올림과 경계값을 검증한다.** 금리 0, 거래 0, 상환 완료, 잔액 부족을 포함한다.
   화면 반올림과 내부 계산의 차이로 합계가 맞지 않는 문제를 관리한다.
6. **시나리오는 예측이 아니다.** 임의 수익률·물가·금리 경로에 따른 조건부 결과로 표시한다.
   입력 하나를 움직이면 실제 경제가 정해진 방향으로 반드시 움직이는 것처럼 표현하지 않는다.
7. **가정과 실제 계약을 구분한다.** 제품별 일수 계산·변동금리 재산정·수수료·세금이 생략된
   교육 모델을 실제 은행의 청구 금액 계산기처럼 소개하지 않는다.
8. **투자 성과의 비교 조건을 맞춘다.** 수익률 정의, 입출금, 배당·재투자, 비용·세금,
   통화·환율, 기간과 데이터 출처를 함께 관리한다. 백테스트는 미래 성과 보장으로 표시하지 않는다.

그래프에는 기간·단위·범례와 원금/기여금·부채·비용 등의 구성 요소를 표시한다.
큰 금액의 작은 변화나 음수 순자산도 읽을 수 있게 한다. 상호작용 결과는 텍스트·표로도 제공한다.
확률 실험을 만들 때는 고정 시드·재실행 방식과 분포 가정을 명시하고 재현 가능한 검증을 마련한다.

애니메이션과 그림도 같은 계산 모델을 사용한다. 이동하는 기호가 금액을 뜻하는지,
거래 한 건을 뜻하는지 명시하고, 이동 속도나 기호 개수가 실제 수익률·위험 확률을
뜻하는 것처럼 오해시키지 않는다. 중간 프레임과 확정된 거래 결과를 구분하고 재생·정지·
초기화 때문에 거래가 중복 적용되지 않게 한다. reduced-motion과 정적 화면에서도
핵심 관계와 변화 전후를 읽을 수 있어야 한다.

## 8. 원리와 한국 제도·공식 자료의 관리

참고 교과서는 학습 구성 참고다. 금융·경제·세무·계약상의 사실을 그 사이트 하나만으로 확정하지 않는다.
실제 집필 시 해당 내용에 맞는 공식 자료를 확인하고 장별 출처와 확인일을 남긴다.

| 분야 | 우선 확인할 공식 자료 |
| --- | --- |
| 화폐·금리·통화·경제 원리 | 한국은행 경제교육·ECOS, 필요한 국제기구의 공식 자료 |
| 물가·고용·가계 통계 | 통계 작성 기관과 KOSIS, 통계 정의·기준 시점·개정 정보 |
| 금융상품·보험·소비자 정보 | 금융감독원·금융위원회, 해당 계약의 공식 약관·설명서 |
| 시장·주식·ETF·공시 | 한국거래소·DART, 발행사·운용사 공식 문서 |
| 세금·공제·연말정산 | 국세청·현행 법령과 부칙, 해당 귀속연도 공식 안내 |

| 부동산·주거·대출 | 국토교통부·한국부동산원·등기/주택금융/보증 관련 공식 기관 |

이 목록은 조사 착수처이며 이번 기획에서 모든 자료를 검토했다는 뜻은 아니다.
정책·법령·상품 수치를 실제 사용할 때 다시 확인한다.

- 원리 설명과 연도별 수치·제도 규칙을 파일/데이터에서 분리한다.
- 세금은 귀속연도·거주자·소득 종류 등 적용 조건을, 규정은 시행일·적용 대상을 표시한다.
- 법 개정의 발표·확정·시행을 구분한다. 확인되지 않은 수치를 ‘현재’ 기본값으로 넣지 않는다.
- 교육용 단순 세율은 실제 법정 계산과 구분하고, 아직 검증하지 않은 실세법 계산기는 제공하지 않는다.
- 통계는 기간·비교 기준·단위·명목/실질·계절조정 여부 등 해석에 필요한 조건을 남긴다.
- 개별 상품·종목 추천이나 개인별 가입·매매·대출 결정을 자동으로 내리는 기능은 이번 범위가 아니다.

## 9. 구현·호환 기준

[콘텐츠 작성 기준](CONTENT-AUTHORING.md)을 따른다.

- **본문은 MDX**, 실험 상태·조작은 React/TypeScript, 계산·판정은 별도 모델로 작성한다.
- 기존 React·Vite·GitHub Pages 구조를 유지한다. 이 콘텐츠를 위해 Next.js·백엔드·로그인을 도입하지 않는다.
- `bookId`와 `chapterId`로 카탈로그에 추가하고 읽음 ID는 책 이름으로 구분한다.
- 기존 컴퓨터·네트워크 책, 해시 링크, `my-books:read:v1`과 저장된 읽음 ID를 유지한다.
- 제안 경로는 `src/content/money/`, `src/components/money/`, `src/simulations/money/`다.
  실제 공개할 bookId·chapterId는 첫 구현에서 확정한 후 안정적으로 유지한다.
- 장별 숫자·거래 예제는 모델과 본문에서 불일치하지 않게 관리한다. 범용 계산 엔진을 먼저 크게 만들지 않는다.
- 입력·예측·확인·초기화를 키보드로 사용할 수 있게 하고, 입력 변경 시 오래된 결과가 남지 않게 한다.
- 모바일은 복잡한 도표를 축소하지 말고 읽을 수 있는 표·세로 패널로 구성한다.
- 그림·그래프를 조작부보다 먼저 또는 가까이 배치해 바뀐 결과를 즉시 볼 수 있게 한다.
  설명용 장면은 SVG/HTML을 우선 고려하고, 복잡도·성능상 필요할 때 Canvas 등을 선택한다.
  삽화는 적극 활용하되 수치·거래 관계의 정확성은 코드 기반 시각 요소로 검증한다.

## 10. 제작 순서와 완료 조건
