# 육아 3권 배치 실행 계획

후속 사용자 요청으로 소개·01–02 구현을 시작했다. 후속 배치는 선행 소스·화면 게이트를 지키며, 게시 검증은 직렬 창에서 별도로 진행한다.

## 배치 A: 먹는 일과 시작 준비
Middleages/my-books 최신 main과 AGENTS.md, CONTENT-AUTHORING.md, HOME-INFORMATION-ARCHITECTURE.md, FEEDING-TEXTBOOK-PLAN.md, FEEDING-SOURCES.md와 선행 검증 기록을 읽어 실제 상태를 확인한다. 이번 범위는 소개·01–02이며 다른 권/배치 변경을 섞지 않는다.

각 장의 핵심 질문·관계 그림·조작·반례를 구현하고 공식 근거의 연령·국가·적용 조건을 유지한다. 미확인 수치/월령 기준을 만들지 않는다. 합성 예제만 사용하고 실제 아이의 체중·사진·의료정보 입력/전송은 제외한다. 알레르기 재도전, 개인 영양/약 용량, 응급 술기 자동화, 정상 점수는 제공하지 않는다. 제시량·흘림·섭취·모름을 구분한다.

MDX 본문/UI/모델을 분리하고 그림·표·상태를 하나의 모델로 연결한다. 320/390/850/1440 원본을 직접 확인해 음식 그림의 위험한 오해·라벨·크기·조작 인접성을 검토한다. reduced-motion·키보드·정지·초기화·정적 대안 동등성을 확인한다. 전체 unit/build와 영향책/홈 검사를 하며 최초등록/마감 넓은회귀는 기존정책을 따른다. 임상 유효성을 소프트웨어검사로 주장하지 않는다.

기존 책·권차·readId·미지의 읽음 기록 보존, 장별 출처 확인일·검증SHA·실행/미실행·감수유무를 기록한다. 공개/배포가 별도 승인된 세션에서는 선행 책/배치 순서를 지키고 직렬 게시 담당을 통해 Actions·Pages·실제 자산/화면을 확인한 뒤 완료로 보고한다.
