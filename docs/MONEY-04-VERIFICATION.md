## 화면 검증 환경

Browser 플러그인 실행 도구가 노출되지 않았고 cloud browser의 localhost 접속은
`ERR_CONNECTION_REFUSED`였다. 로컬 테스트 브라우저 설치도 내려받은 ZIP 오류로 실패했다.
개발 서버의 인터페이스 조회 오류는 127.0.0.1 명시 실행으로 해결했고 소스 설정은 변경하지 않았다.
