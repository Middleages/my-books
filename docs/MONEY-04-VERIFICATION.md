## 확인하지 못한 범위

모바일 검증용 data URL 화면은 cloud browser의 URL 보안 정책에 의해 차단됐다.
이를 우회하지 않았다. 이 세션에는 viewport 변경 API가 없으므로 실제 모바일 폭의
렌더·터치·모바일 Safari, OS reduced-motion 에뮬레이션·스크린리더 실행은 **미검증**이다.
모바일 단일 열 배치, 네이티브 버튼/슬라이더, 정적 표, reduced-motion에서 animation/transition을
끄는 CSS는 코드로 점검했다. 재생 자체가 정적 연말 상태 전환이므로 움직임을 기다릴 필요 없이
단계 버튼과 관찰 시점으로 같은 모델의 모든 상태를 읽을 수 있다.
