# 5권 근거·국내 적용 경계
확인일: 2026-10-20. 한국 자료를 먼저 조사했다. 일부 국내 세부 자료의 현행 내용은 미확인이므로 숫자·술기·제품 설치도를 확정하지 않는다. 전문가 감수 미실행.

## 열람·확인한 자료
- S1 한국소비자원, 2024년 소비자 위해정보 동향 관련 보도자료, 2025-03-25. https://ciss.go.kr/DATA/bbs/85/20250325090214787.pdf
  PDF 텍스트의 가정 내 사고·추락 항목과 연령 구분을 확인. 영유아는 0–5세이며 0–36개월 전용 통계가 아니다. CISS 접수 자료를 전체 인구의 사고 확률로 쓰지 않는다. 01·02·03·12의 문제 설정 근거다. 문서의 침대 난간 등 일반 조언을 영아 안전 수면 지침으로 자동 채택하지 않는다. PDF 시각 도표 검수는 하지 않았으며 수치 도표 재현 없음.
- S2 행정안전부 어린이안전관리 제도 안내. https://www.mois.go.kr/frt/sub/a06/b10/childSafety/screen.do
  공식 페이지에서 시설 종사자 교육·응급조치 체계의 존재를 확인. 모든 가정 보호자의 법적 의무나 자격으로 확대하지 않는다. 09·11·12는 전문 교육과 제도 확인의 연결만 사용하며 이 자료가 가정용 응급술기 매뉴얼이라는 뜻은 아니다.
- S3 한국교통안전공단 교통안전TV, 카시트 실험 영상, 2020-11-11 게시. https://www.youtube.com/watch?v=oABCpOl70jc
  검색 결과에 제공된 공식 채널의 설명문만 확인. 영상 전체·현재 규정·모델별 설치법은 미검증. 08장의 제품별 설명 확인 필요성을 보조하며, 오래된 뒤보기 전환 기준이나 고정 각도를 확정하지 않는다.
- S4 NHS, Baby and toddler safety, 2026-02-19 검토 표시. https://www.nhs.uk/baby/first-aid-and-safety/safety/baby-and-toddler-safety/
  영국, 영아·유아 대상의 작은 물체·추락·중독·화상·물 주변 예방 항목을 열람. 01–07의 위험 경로를 생각하는 보조 자료다. 영국 제품 인증·난간 간격·수심 숫자·소방 및 응급 연락 체계는 국내 규정으로 이식하지 않는다. 이 자료만으로 제품 안전성·응급처치 세부 절차를 확정하지 않는다.
- S5 소방청 119 구급신고 요령. https://www.nfa.go.kr/nfa/safetyinfo/emergencyservice/119emergencydeclaration/
  직접 열기는 방문자 확인 화면이었다. 공식 검색 색인에 나온 위치·관찰 상태·나이/주요 정보·연락처 전달 및 의료지도 안내를 확인했다. 직접 페이지 전체 검증은 미완료이며 10–12의 정보 범주에만 사용한다. 예시의 성인 응급술기를 영아에 옮기지 않는다. 119 공식 창구는 https://www.119.go.kr/Center119/main.jsp 에서 별도 열람했다. 학습 앱에서 실제 신고나 개인정보 등록은 하지 않는다.

## 찾았지만 채택하지 않은 자료
https://www.ciss.go.kr/DATA/bbs/83/20190819012254674.pdf 는 검색 발췌를 찾았으나 직접 열람이 실패했다. 오래된 어린이 안전 가이드의 세부 규격·수면 조언을 현재 영아 지침으로 채택하지 않았다. 접근 실패는 권고 검증 완료가 아니다.

## 구현 전 필수 확인
- 국내 물 안전·생활화학제품/전지/자석 경고의 현행 원문과 정확한 대상 연령.
- 한국 도로교통·제품 안전의 현행 규정, 카시트 제조사와 차량 설명서의 조합별 조건. 법정 최소요건과 안전 권고를 분리.
- 최신 국내 영아/유아 응급 교육과 전문가 검토. 본 책은 술기 구현을 하지 않으며 응급 신호의 예시를 넣는 경우도 별도 공식 근거·감수 필요.
- 건물·화재 조건별 공식 행동요령. 보편 탈출 알고리즘이나 해외 긴급번호를 국내 기본값으로 제공하지 않음.

본문 구현·응급 술기 검증·의학 감수·제품 시험·브라우저 검증·원격 게시는 하지 않았다. 이 계획은 일반 예방 교육이며 개인 응급도/처치 판단 도구가 아니다.
