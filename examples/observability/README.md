# 관측 교재 선택 실습: 먼저 모형 재현

이 폴더는 **제품 스택 실행 패키지가 아니다.** 교재와 같은 순수 모델의 조건·결과를 CLI에서 대조하는 선택 실습이다. 실제 계정·로그·주소·credential은 입력받지 않고 네트워크·파일 쓰기·프로세스 설치를 하지 않는다.

## 실행 위치와 선행 조건

검토한 저장소 checkout의 루트에서 기존 Node.js로 `node examples/observability/replay.mjs`를 실행한다. 새 패키지 설치는 필요 없다. 모델 버전은 함께 체크아웃한 Git tree와 동일하다. 기준 구현은 F tree `3b61d1be6d34a92f7a864893f3017fc664ab960a`다. 실행한 Node 버전은 G 검증 문서에 기록한다.

예상 관측: 수집 중단에도 앱 응답 성공, 앱 인스턴스 교체 후 기존3+신규2, volume 소실 시 신규2만, 조회 필터 문제의 한정된 증거, dashboard no-data의 null과 빈 표본의0 분모를 확인한다. 성공하면 합성 비교 결과와 `synthetic checks passed`를 출력한다. 이것은 실제 Alloy/Loki/Tempo/Mimir/Grafana 호환성이나 성능 시험이 아니다.

정리: 실행은 파일/volume/container를 만들지 않으므로 삭제 명령이 없다. 출력에 비밀이나 실제 식별자가 없다. 다른 프로젝트·실제 저장소를 정리 대상으로 삼지 않는다.

## 이후 실제 스택 실습 설계, 미실행

- 위치: 별도 승인한 격리된 비운영 Compose 환경에서 먼저 검증하고 Kubernetes는 별도 단계로 옮긴다. 설치·네트워크 변경은 이 문서로 실행하지 않는다.
- 버전/tag/digest: Alloy, Loki, Grafana, Tempo, Mimir, OTel SDK 및 Compose/Kubernetes 버전은 **미선정·미검증**이다. `latest`나 가짜 digest를 넣지 않는다. 실제 진행 전 공식 지원 조합·라이선스·이미지 digest를 실습 manifest에 확정해야 한다.
- 반입: 이미지와 설정·의존성·공식 문서·검증 정보·내부 registry 경로를 함께 준비한다. 실제 내부 주소·CA·인증 자료는 공개 교재에 추가하지 않는다.
- 입력: 개인정보 없는 합성 요청과 고정 fixture만 사용한다. 실제 로그를 복사하지 않는다.
- 예상 검증: 하나의 요청에서 생성→수집→저장→조회 증거를 각각 확보하고, no-data·중복·지연·재시도를 구분한다. 의도적 장애는 승인한 범위에서만 주입한다.
- 복구/정리: 새 실습 전용 자원 이름과 백업·복구 조건을 먼저 정한다. 보관이 필요한 volume은 삭제하지 않는다. 실제 정리 명령은 자원 목록과 보존 범위를 확인한 뒤 작성한다.

현재 완료: 순수 모형 CLI. 현재 미완료: 실제 제품 설치·전송·저장·인증·장애 주입·복구·호환성 검증. 둘을 같은 실습 결과로 기록하지 않는다.
